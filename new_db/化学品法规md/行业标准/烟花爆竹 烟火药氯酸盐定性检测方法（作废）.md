# 烟花爆竹 烟火药氯酸盐定性检测方法

# 1 范国

本标准规定了烟花爆竹用烟火药及原材料中氯酸盐的定性检测方法,

本标准适用于烟花爆竹用烟火药及原材料中氯酸盐的定性检测

# 3 测定原理

盐酸苯胺在酸性条件下与氯酸盐反应后变成紫色,判定有氯酸盐。

# 4 检测

# 4.1 试样制备

4.1.1 将待测烟花爆竹产品割开,将药剂取出,混匀待测。

4.1.2 烟花产品烟火药中粒状、柱状等成型药剂需碾碎,混匀。

# 4.2 试剂配制

4.2.1 除非另有说明,在分析中仅使用确认为分析纯的试剂和GB/T6682中规定的至少3级的水。

4.2.2 盐酸(GB/T622)。

4.2.3 盐酸苯胺(AR,分析纯)。

4.2.4 硫酸亚铁铵(GB/T661)。

4.2.5 检测试剂配制:称取  $4 \mathrm{~g}$  盐酸苯胺(4.2.3)加入  $50 \mathrm{~mL}$  盐酸(4.2.2),或按该比例配制,搅拌,贮于棕色试剂瓶中(此试剂有效期为7d)。

# 4.3 分析步骤

4.3.1 方法一:取约  $0.05 \mathrm{~g}$  样品置于滤纸中心,加水两滴,待水扩散开后,滴加  $3 \sim 5$  滴盐酸苯胺溶液,如滤纸上出现紫色环,判定被测样品中有氯酸盐。

4.3.2 方法二:称取  $0.1 \mathrm{~g}$  样品试样于烧杯中,加水加热搅拌、过滤,取  $1 \mathrm{~mL}$  滤液于试管中,加入  $1 \mathrm{~mL}$  盐酸苯胺溶液,摇动试管,溶液出现粉红色,后变为紫色,最后变为蓝色,判定被测样品中有氯酸盐。
