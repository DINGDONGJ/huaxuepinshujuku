# 上海市应急管理局关于推动建立本市危险化学品企业行业安全联盟的通知

沪应急危化[2024]14号

各区应急管理局、各有关危险化学品和工贸安全责任保险机构、各有关企业：

为持续提升本市危险化学品企业自治、开放和行业自律水平，以高水平安全保障化工产业高质量发展，推动建立本市危险化学品企业行业安全联盟，现就有关工作通知如下。

# 一、工作目标

以“整体谋划、协同推进、以点带面”为原则，以规制创新、管理创新为引领，以破解危险化学品企业安全管理水平不平衡、同行业交流分享机制不健全等难题为导向，以危险化学品和工贸安全生产责任保险企业事故预防服务为载体，推动建立危险化学品企业行业安全联盟，搭建同行业企业交流平台，创新安全治理模式，充分发挥先进企业的示范引领效应，深入推动危险化学品企业安全文化建设，切实提升化工行业安全水平。

# 二、企业范围

取得安全生产许可的危险化学品生产、经营（带有储存设施、仓储、加油站）、使用企业和有关化工医药企业。

# 三、工作方式

# （一）成立联盟

根据本市危险化学品企业不同类型，分别成立石油化工、精细化工、油气储存、化工医药、油漆涂料、工业气体、仓储经营、加油站、化学试剂等9个行业安全联盟。支持上海市危险化学品及工贸行业领域安全生产责任保险各承保机构（以下简称：安责险承保机构）统筹建立工作机制，将服务保障行业安全联盟运行纳入事故预防服务范畴。按照“企业类型相近，资源优势相融”的原则，综合企业规模、安全管理水平等因素，确定各行业安全联盟牵头企业和成员企业。各成员企业由主要负责人或指定专人参加安全联盟相关活动，落实具体工作要求。

# (二) 交流研讨

各安全联盟定期组织召开安全工作交流会，组织开展实地调研、问题研讨、经验分享等活动。坚持问题导向，针对行业类型和典型事故特点，深入分析研究本行业主要安全风险和重点任务，着力破解工作推进过程中的难点问题（建议重点研究课题详见附件）。分享各企业在化工过程安全管理、安全风险智能化管控平台建设和应用、设备完好性管理、变更管理、检维修作业安全风险管控等方面的先进管理理念、制度和实践，商讨研究本行业安全治理提升方案。

# （三）安全培训

各安全联盟每年至少组织一次安全培训，采取线上线下等方式，组织专家、专业人士解读安全生产法律法规、标准规范和最新安全要求，对典型事故案例进行剖析研究，对共性问题提出整改建议，及时跟进专项工作落实进度。

# （四）总结提炼

各安全联盟要加强对研讨成果的归纳汇总，在风险分级管控、本质安全水平提升、隐患排查治理、应急联动机制和队伍建设等方面发挥专业指导作用，帮助企业“通堵点”“破难点”，提炼一批可复制、可推广的安全治理模式和实践应用案例，推动形成具有示范引领作用的地方标准。

# （五）其他工作

鼓励各安全联盟企业自行开展隐患互查、交流互学等活动，市、区应急管理局可结合工作实际，组织专家指导服务。

# 四、工作要求

# （一）加强组织领导

建立行业安全联盟是转变安全生产治理方式，提升企业本质安全管理能力的创新举措。各区应急管理局要深刻认识此项工作的重要意义，督促企业落实安全生产主体责任，采取有力措施推动工作机制建立健全，助力行业安全联盟有效运行。鼓励安责险承保机构落实专人负责制，加强资源共享，推动行业安全联盟落地见实效。各企业主要负责人要提高认识，变被动接受为主动出击，积极参加行业安全联盟各项活动，切实对标先进，全面提升安全管理能力和水平。

# （二）统筹推动落实

安责险承保机构要发挥统筹协调作用，切实配合行业安全联盟牵头企业和成员企业做好有关活动的宣传发动，平台搭建等工作，维护安全联盟高效运转。提倡行业安全联盟的牵头企业积极践行社会责任，在保护知识产权和商业秘密的前提下，积极分享最佳实践，为提升行业安全管理水平作出贡献。各区应急管理局要加强与安责险承保机构的沟通交流，督促指导辖区内成员企业踊跃参加活动，建立基于信用

的新型监管执法模式和正向激励机制，对积极参加安全联盟活动、认真落实安全联盟要求的企业，减少行政执法、安全检查的频次。

# （三）提升工作实效

安责险承保机构要及时梳理典型经验做法，加大宣传力度，通过官方网站、微信公众号、短视频等方式，多渠道、全方位宣传，扩大影响力。行业安全联盟要充分发挥专业优势，及时汇总研讨成果，推动政策宣贯、技术创新、技能培训、辅助决策等方面的成果转化。各区应急管理局要善于借力，将安责险承保机构事故预防服务与各类专项工作同频共振、同步实施、同步推进，创新安全生产社会共治模式，构建共商、共治、共享的安全命运共同体，持续提升安全治理能效，助力本市制造业高质量发展。

# 化工行业安全联盟建议重点研究课题(2024年)

1. 石油化工安全联盟：化工过程安全管理实践应用；2. 精细化工安全联盟：生产装置全流程自动化控制改造；3. 医药化工安全联盟：医药合成工艺风险管控和变更管理；4. 油气储存安全联盟：深化油气储存企业安全风险智能化管控平台建设和应用；5. 油漆涂料安全联盟：静电安全风险研究及防控；6. 工业气体安全联盟：设备完好性管理；7. 仓储经营安全联盟：仓储信息化系统功能优化；8. 加油站安全联盟：加油站安全生产标准化管理；9. 化学试剂安全联盟：危险化学品“一企一品一码”推广应用。
