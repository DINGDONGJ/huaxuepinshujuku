# 危险化学品编码与标识技术规范

# 1范围

1 范围本文件规定了危险化学品编码对象、编码原则、编码结构和解析、信息标识，以及编码与标识使用要求。本文件适用于危险化学品编码及在生产、储存、运输、经营、使用等阶段的标识。

# 2规范性引用文件

下列文件中的内容通过文中的规范性引用而构成本文件必不可少的条款。其中，注日期的引用文件，仅该日期对应的版本适用于本文件；不注日期的引用文件，其最新版本（包括所有的修改单)适用于本文件。

# 3术语和定义

下列术语和定义适用于本文件。

3.1

危险化学品安全信息hazardouschemicalsafetyinformation

危险化学品的名称、危害分类、管控要求、安全操作、应急处置等安全管理相关信息，可根据需要增加供应商、种类、批次、包装规格、有效期等相关信息。

3.2

危险化学品安全信息码hazardouschemicalsafetyinformationcode

危险化学品登记综合服务系统生成的用于标识化学品安全信息的二维码。

3.3

# 可追溯性 traceability

通过记录标识的方法回溯某个实体生产、经营、流通和使用情况的能力。

# 4编码对象

本文件规定的编码对象是危险化学品，可通过扩展对应于危险化学品具体的包装件或运输工具。

# 5编码原则

# 5.1 唯一性原则

不同企业登记的相同或不同种类危险化学品安全信息码均不同，危险化学品安全信息码具有唯一性。

# 5.2 扩展性原则

5.2 扩展性原则危险化学品安全信息码留有后备容量，以适应不断扩充的需要。可与产品种类、生产批次、包装等信息对应，实现一企一品一码、一企一批一码或一企一物一码。

# 5.3 兼容性原则

5.3 兼容性原则危险化学品安全信息码可通过编码融合技术与其他信息码、电子运单等融合，不同系统扫码时显示不同内容，但能保证公众和监管部门通过扫码获取危险化学品安全信息。

# 6 编码结构和解析

# 6.1 编码结构

6.1.1危险化学品编码由固定信息码与扩展码组成。固定信息码由登记网址、危险化学品登记号组成，扩展码包括编码前缀、包装代码、日期代码、顺序代码等，扩展码具体信息可由企事业单位自定义。

危险化学品编码应包括：编码前缀  $+$  登记网址  $+$  危险化学品登记号  $+$  包装代码  $+$  日期代码  $+$  顺序代码十·…

6.1.2登记网址是企业登记的危险化学品在危险化学品登记综合服务系统中的唯一指定网址。

6.1.3危险化学品登记号是企业办理危险化学品登记时在危险化学品登记综合服务系统中生成的登记号。

6.1.4编码前缀用于识别编码进行解码规则查询的前缀地址。

6.1.5包装代码用于标明危险化学品的外包装类型、材质、级别和最大净含量及其单位，可采用8位阿拉伯数字或英文字母表示。其中，外包装类型、材质、级别各1位，净含量单位2位，最大净含量数3位（整数），具体定义见附录A。

6.1.6日期代码表示危险化学品的生产或进口日期，由8位阿拉伯数字组成。其表示方法应符合GB/T7408的规定，采用"YYYYMMDD"（年、月、日)格式表示。

6.1.7顺序代码表示企业在同一生产日期内的危险化学品顺序号，用于识别危险化学品在同一批次、同一包装形式下的单一产品，由6位阿拉伯数字表示。

6.1.8编码分隔符用于分割不同编码内容的分隔符号，在编码规则中自定义，可用“/”“|”等。

6.1.9在保证危险化学品安全信息码正确流通使用的基础上，可自主定义所有编码在编码结构中的内容和排列顺序。

6.1.10可使用编码融合技术，对编码进行替换、加密、缩减、隐藏等简化操作。

# 6.2 编码解析

6.2 编码解析可通过扫码直接获取或通过特定APP扫码查询接口获取编码内容，编码示例见附录B，使用融合编码方式的编码示例见附录C。

# 7信息标识

7 信息标识7.1 为实现追溯信息的自动或人工采集，追溯信息要以标签、标记或标注等标识载体来标识。7.2 标识载体分为二维码和射频标签（RFID电子标签）两类。

# 8 编码与标识使用要求

8.1 所承载信息应包含确保危险化学品可追溯性的固定信息码。8.2 具有防伪功能，展现形式简单、统一，易于识读。8.3 危险化学品编码可使用明文进行加载，或者根据要求对危险化学品编码进行加密后加载。8.4 当使用二维码时印制的质量等级至少应满足 GB/T 23704 规定 2.0 级的要求，短边长度不宜小于  $1\mathrm{~cm}$ ，与化学品安全标签结合样例见附录 D。
