# 全球化学品统一分类和标签制度(GHS)第2部分:标签和安全数据单的可理解性测试方法

# 1范围

SN/T3083的本部分规定了全球化学品统一分类和标签制度(GHS)中的标签和安全数据单的可理解性测试方法。

本部分适用于对全球化学品统一分类和标签制度(GHS)中的标签和安全数据单可理解性的测试评估。

# 2方法概述

2.1本方法分为多个不同的模块。对每个模块的用法的详细说明参见附录A。通常情况下,本方法包括以下五个组成部分:

a)模块1(核心模块):其主要目的是确保在模块  $2\sim 11$  中所用的方法适合各种不同文化和背景。建议在所有类别的目标群体中使用这种模块(见表1),但其在文化不同于制定标签和安全数据单背景的工人和社区成员群体中,应首先使用这种模块。

b)模块  $2\sim 8$  :这些模块包括普通问卷(模块2)和一组关于标签及安全数据单的问题和练习(模块 $3\sim 8$  )。根据调查对象是否是工人,是否使用安全数据单,这些模块中的某些元素可能不适用。

c)模块9:这是一种模拟练习。拟用于工人,适用于生产领域中的绝大多数人。

d)模块10:包括一份最终的测试后问卷。它适用于问卷调查(模块  $2\sim 8$  )和模拟练习(模块9)的所有参加人。也可用于分组练习的参加人(模块11)。调查问卷的重点是培训和过去的经验,并提供机会,让人们就测试过程提出没有任何限制的反馈和意见。

e)模块11:这是供工人使用的分组练习。它吸收了上述模块中的所有元素,目的是在分组学习中测试可理解性。其宗旨是补充模块2至模块10,但测试的对象与模块  $1\sim$  模块9有所不同。

2.2建议在可理解性测试后的1个月和12个月,进行后续测试。这种测试应采用参加首次测试的测试对象重复进行。重复测试对于深入了解危险信息接触的保持力和实际益处十分重要。

# 3方法的使用

3.1 每个模块都足为了一组特定的可理解性测试目的测试的实示测试问卷。问卷中清楚地表明了针对进行可理解性测试者的使用说明。伴随者每个模块但分别提出的是一组详细的指导性说明,它们构成了特定模块的使用手册。使用手册还概述了在每个模块中使用的不同标签和/或安全数据单,以及每个模块的产生和时间要求。

3.2 为避免模块过于冗长,模块使用说明在模块中文中经写在最短限度,而在使用手册中给出了详细的说明。如果模块3~模块11中有关键说明,它可在阴幕框中用黑体字列出,以便于实行。在整个模块中,用斜体字标出需要读给测试对象要听的所有案文。

3.3 某些模块(模块3、4、6~9)要求随即选择标签和/或安全数据单。为测试者提供了一盒卡片以提高一个随机标签/安全数据单或一组标签/安全数据单的选择速度。测试者将获得一个特定卡片盒,上面标有每个有关模块。

3.4 所提供的标签和安全数据单应符合我国所采用的标准风格和表述方式。尽管努力简化测量危险公示可理解性所需要的相对比较复杂的测试程序,但测试方法需要谨慎实行,需要进行质量控制。因此,对测试者的培训十分重要。模块1和模块2的使用手册对此作了更为详细的说明。

3.5 同意:在使用本方法中的任何一个模块之前,参加人均应首先在已了解情况的基础上表示同意。为此,应向参见人员说明练习的目的,以及将要求他们遵循的程序。不得强迫参加人参与,应让他们知道,他们有权在任何时候退出,在同意程序中提供的信息非常普通,不会泄露所测试的明确假设。

3.6 同意程序在模块1(核心小组)、模块2(测试开始)和模块10(模拟练习)的开始部分作了概述。不论同一受检者是否完成所有的模块,都应在需要时进行所有这三项同意程序。模拟练习的同意程序在很大程度上是一种解释,旨在通过向受检者讲明练习目的,消除将会产生的明显偏见。

# 4 样本采集

# 4.1 目标群体

目标群体在表1中列出。他们大多数是成年工作人员,属于直接或间接使用,销售或管理化学品的典型群体。儿童是另一个重要的潜在受众。然而,虽然向儿童提供可理解的安全信息的能力被认为是极重要的,但本标准未涉及此类问题。

# 4.2 核心小组

4.2.1 考虑到核心小组的宗旨是提供娱乐,保持团队的合法合不同的文化和背景,核心小组的参加者应在被评估的目标群体中,才能具有代表性,重点应放在文化与标签和安全数据单产生背景不同的工人和社区成员群体上。这需要对职业从业人员、职业和社区/居民/消费者群体,不论他们有没有文化,这些群体的文化和语言背景有可能避免险会小的传达复杂化。表1就核心小组的类别提出了建议。

4.2.2 建议每个类别至少有两个核心小组。然而,如果某一类别(例如,没有文化的农业工人)的核心小组的结果看起来非常类似于某一个,以对(例如,没有文化的农业工人),则或许有可能省去下面的小组。只有当测试人相信另外的试验不会出现不同的结果后,才能采取一种做法。通常情况下,当不同核心小组的结果基本一致时,建议直接进入下评估,从模块2起,如如果测试结果出现显著差异,或者已经得到的用于告知其他人员的信息并不充分,则建议继续组注核心小组,直到获得这样的信息为止。在此种情况下,应继续进行测试,直到结果一致或得到澄清为止。如果这样,测试可能需要多组建几个小组,要比所建议的每个类别两个小组多。

# 4.3 问卷和试验设计

# 4.3.1 概述

4.3.1 概述有工作和无工作者的不同子群体拥有不同的经历,这会影响他们对危险公示的理解性。模块2~模块8,以及模块10将用于测试不同风险条件下的理解程度。根据样本包计算以及对后勤支持的考虑,测试的最少人数见表1。模块9(标签字体和布局对可理解性的影响)和模块9(模拟试验)包括不同标签形式的比较(分别为8和11层)。因此,对于这些模块来说,需要较多的参加人,以便在每一层内产生足够多的案例。其他测试模块(3、4、5、7和8)则拥有较少的层(最少1层,最多4层不等),因此只需要较少的受检人。本方法的使用者可选择将所有的模块用于所有的受检人,在此种情况下,建议的最少受检人数量见表1的模块6和模块9。模块2和模块10则应按照规定,由所有的参加人完成。

# 4.3.2 模块选择

4.3.2 模块选择考虑到全部试验的长度(见表2),并出于后勤方面的原因,或许有必要将试验方法进行分解,让不同的受检人只完成某些模块。采取这种方法,则会有更多的人参加试验,但他们只完成评估的某些部分。如果采用这种模式,则所有的受检人应完成模块2和模块10,不论他们已经完成多少个其他模块。比如,全部模块可进一步细分以下几组:a) 模块2、3、8和模块10;b) 模块2、4和模块10;

# 4.3.3 随机性

4.3.3.1 只要可能,在选择各分小组时,应采用随机取样的方法选择参加人,以尽可能使他们具有代表性。这对于确保结果的普遍性至关重要。即使从同一个分组选择不同的参加人,来完成试验的不同部分,由于整个试验长度的原因,参加人的选择应突出代表性。然而,业已认识到,在实际使用中,要做到随机选择是十分困难的。尽管如此,无论采用什么样的选择方法,都应尽可能使样本具有代表性。

4.3.3.2 在模块内,组内受检人的随机性至关重要,对此不能将就。随机性对于确保内部比较的有效性也不可缺少,它不同于样本的随机选择,这是确保研究结果具有普遍性所必需的。

# 4.3.4 模拟研究

由于模拟研究是一种动用资源相对较多的工作,因此建议模拟研究只能在有限的目标群体内进行,可以是农业和非农业工人,也可以是运输人员和消费者。但只要资源允许,这样的模拟研究可根据需要方便的应用于其他层。

# 4.3.5 感染和共同介入

4.3.5.1 测试设计要求控制环境。为此,应避免出现参加者能够看到或听到另一位参加者的试验资料。当独立变量的管理是评估的关键环节时,这种情况将使所做的比较无效。出现在试验环境中的这种情况称为感染。

4.3.5.2 为避免出现感染,在测试进行过程中,参加者应避免相互接触。这可能需要测试小组付出相当大的努力,以确保受检人不会碰到一起。

4.3.5.3 共同介入是指两个试验组都遇到在试验情况之外发生的介入。例如,工厂中的每名工人在测试开始前一周接受详细的危险安全培训时会发生共同介入。这有可能导致不同危险公示要素的影响受到掩盖,并有可能导致对标签和安全数据单不同形式的影响估计不足。如果这种情况无法阻止,则应注意出现共同介入的可能性。

# 4.3.6 分组学习

模块 11 旨在检测在分组学习条件下的可理解程度。它只适用于工人(表 1 中的群体 3~6),而且需要单独取样,与参加模块 2~模块 8 的工人分开。总共需要对 10 个小组进行测试,其中包括由工厂工人组成的 5 个小组和由农业工人组成的 5 个小组。各个小组应尽可能做到文化水平均衡,小组人数大致相等。每个小组均不应超过 10 人,不少于 6 人。

# 4.3.7 关联信息

4.3.7.1 进行可理解性测试时的关联情形对于含义的准确把握和理解至关重要。对于那些只接受过一点正规教育、全靠关联提示来提高他们对危险公示理解的工人来说,更是如此。为此,在用本方法进行的大多数测试中,应使用完整的标签而不是标签或安全数据单中的部分内容。对于接受过良好教育的受检者来说,他们可能更容易从概念上理解各种孤立内容,但对这些内容的解释可能也与现实世界的学习情景没有多少的联系。正是由于这个原因,在所有的测试中都应该使用真正的标签和安全数据单。4.3.7.2 为尽可能提高真实性,应使用容器上粘贴的标签。要将不同的标签分别贴在各个容器上可能会增加测试者的不必要负担,因此建议将标签贴在一种标签容器上,测试完后即可取下。应将每一种视

觉提示提供给受检人,以最大限度地提高他们的理解可能性,特别是那些没有受过多少正规教育的工人,他们对关联信息的依赖性更大。因此,不论在任何时间,都应在容器上贴上标签。

4.3.7.3 为使理解机会标准化,标签上标识的实际化学品应是假的,虽然他们看上去如同真的一样。这样做的目的是保持关联性,同时又不使不熟悉特定化学品的人处于不利的境地。

4.3.7.4 鼓励标准使用者在试验设计要求的范围内对试验材料进行修改,使材料让实际受检者看上去尽可能可信一些,从而最大限度地提高关联性。

# 4.3.8 子项研究的样本量

子项研究的样本量是根据双侧阿尔法误差0.1和0.8的倍率计算得出的,但也根据后勤的可行性进行了调整。对本方法的初步试验已经证实这种估计。特别是,对于少数受检人和目标组,模拟练习是有选择性的考虑,这在很大程度上由于预期的后勤限制。

# 4.3.9 测试和核心小组的时间安排

在进行测试和组建核心小组时,应选择对被测试者和他们的雇主(如果适用的话)都方便的时间。在关键时段和农忙季节(如播种、耕地、喷洒,以及收割时期),不应要求农业工人参加测试。如果工人同意在午餐期间参加测试,时间长短应合适,并应给予适当的补偿。可理解性测试的大致时间见表2。

# 4.3.10 回答评分和代码

4.3.10.1 可理解性测试的回答评分要求专家对回答的正确性作出判断。本部分要求有一组专家在场,以便对理解程度进行所需要的评分。专家小组应在开始研究之前按照下列步骤确定:

a) 选择一组拥有各种经验的专家,包括(一名或多名)雇员、雇主和从业者,以及在代码和评分方面技能熟练的研究人员;

b) 召集一次由专家小组参加的讲习班,对所列每个模块问题的可能回答性质进行审查。此外,还需审查GHS制度的程序和目的文件,就什么样的回答可归为以下类别达成一致意见:

1) 正确:意见与GHS结构的构想相同或者完全一致。这包括并不与GHS的意思100%一样,但却足以作为安全措施或防范基础的回答;

2)部分正确:某些意思是正确的,但还不足以确保适当的安全措施或防范;

3)不正确:给出的意思完全错误,或者与GHS要表达的意思不相干;

4)意思相反(严重混淆):给出的意思不仅不正确,而且理解与GHS的意图恰好相反。这种严重混淆有可能导致危险的行为或行动;

5)不能回答/不知道;

c)在5或10名受检人中试行本问卷。对照所选择的标准检查结果;

d)如果结果表明存在显著差异,重复上述过程,直到就标准达成一致为止。

4.3.10.2对不同模块中问题的回答进行进一步编码的问题在每一模块下讨论。

# 4.3.11 分析

针对这些模块建议进行的分析是对不同层进行所对应的比例和办法的简单计算。也可进行更为复杂的分析,这些分析见各个模块。可空试对可理解性进行总体估计,办法是将不同层的每个受检人的结果综合在一起,但也应根据不同层的权重和已知影响可理解性的其他人口统计学因素的权重进行调整。

# 4.3.12 反馈和后续步骤

应为所有的受检人提供机会,让他们能够看到可理解性评估结果,并对采访和测试程序做出反馈。

# 4.3.13 后续评估

应在一个月和一年以后对参和这些评估的受检人进行回访,以考察他们对当时接触到GHS危险公示还能记住多少,以及所产生的中长期影响。
