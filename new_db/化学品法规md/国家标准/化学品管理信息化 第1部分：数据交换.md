# 引言

信息化是实现化学品管理现代化的重要手段。随着物联网及大数据应用技术的发展，现代信息技术的应用为提升管理效率、促进信息共享、消除管理盲区、有效遏制化学品事故发生提供了技术支撑。在这方面，我国已经建立了化学品管理信息化的国家标准体系。

在该标准体系中，GB/T40640《化学品管理信息化》是规范我国相关机构从事化学品管理信息化系统建设开发活动时的方法和依据，拟由五部分构成，目的在于确立实施化学品管理信息数据交换、维护信息安全、电子标签应用、定位系统应用以及化学品数据中心建设时的方法和依据。

第1部分：数据交换；第2部分：信息安全；第3部分：电子标签应用；第4部分：化学品定位系统通用规范；第5部分：化学品数据中心。

本文件是GB/T40640《化学品管理信息化》的第1部分。数据交换是实现各类化学品管理信息化系统数据交互与数据复用的基础。本次制定对化学品管理信息化进行数据交换时的通用要求、交换规范、交换过程、交换技术、应用接口和服务进行了详细的规定，以更好的规范和促进化学品管理信息化系统相关建设。

# 4通用要求

# 4.1 时间和日期

4.1 时间和日期应采用公历时期和时间的表示法的基本格式“YYYYMMDDThhmms”并使用24小时计时方式，其中YYYY、MM、DD分别表示年、月、日，T用于分隔日期与时间，hh、mm、ss分别表示小时、分、秒。系统粒度不到秒时，时间字段应补零处理。数据交换中日期和时间的表示法应符合GB/T7408的规定。

# 4.2 数据封装

应采用JSON格式进行封装。

# 4.3 信息安全

应符合GB/T40640.2的规定。

# 4.4 化学品信息

4.4 化学品信息化学品名称及分类，应符合GB/T23955和GB30000（所有部分）的规定。化学品编号由企业编号（统一社会信用代码）和序列号连接构成。序列号使用《危险化学品目录》或《中国现有化学物质名录》内相应化学品的序号，字符长度不足12位的，在有效字符前加“0”表示。其他化学品信息按附录A执行。

# 5 数据交换要求

# 5.1 化学品危险说明数据

5.1 化学品危险说明数据数据交换中的化学品危险说明信息代码应以“W- nnn”的形式进行建立，并与GB30000（所有部分）给出的危险说明编码逐一对应。化学品危险说明信息代码按附录B执行。

# 5.2 化学品防范说明数据

5.2 化学品防范说明数据数据交换中的化学品防范说明信息代码应以“F- nnn”的形式进行建立，并与GB30000（所有部分）给出的防范说明编码逐一对应。化学品防范说明信息代码按附录B执行。

图1 数据交换过程框架

# 6.2 数据采集/请求

6.2 数据采集/请求由数据需求方对数据源发起，包括发起数据采集或请求的功能实体。数据源宜采用统一的数据格式。

# 6.3 数据传输

6.3 数据传输在数据采集/请求过程之后，宜通过不同功能的数据传输接口满足数据需求方的数据传输需求，包括调用数据传输服务接口、接口格式校验、数据加密和传输等功能实体。数据传输接口宜分类制定，并与特定数据传输需求相适应。

# 6.4 数据管理

6.4 数据管理对获取的数据进行清洗、标准化、存储以及权限分配等进行管理。数据管理宜通过功能化的数据接口实现。

# 6.5 数据服务（使用）

6.5 数据服务（使用）响应数据需求方的具体要求，对拟传输的数据进行处理，使其满足服务/使用需要，宜包括权限认证、增删改查、日志记录等功能实体。数据服务/使用宜通过功能化的数据接口实现，在保障信息安全的前提下，提升同类型的数据使用/服务需求的响应速度。

# 7 数据交换技术要求

# 7.1 接口分类

7.1.1数据接口类型包括四类：数据采集接口、对内服务接口、数据库接口、对外服务接口。各类接口交换实体关系见图2。

![](images/3056b27413aa40abfac7a87f65b7ae3a61b8c9ffb4078199f619b5df7ee37f1a.jpg)  
图2 接口交换实体关系图

标引序号说明：1 数据采集接口；2 对内服务接口；3 数据库接口；4 对外服务接口。

7.1.2数据采集接口，用于主管部门化学品数据管理平台与数据采集平台、数据采集设备及其他外部数据源之间的数据交换。

7.1.3对内服务接口，用于主管部门化学品数据管理平台与内部业务各系统之间的数据交换。

7.1.4数据库接口，用于数据管理平台和数据库间的数据交换，提供数据增、删、改、查功能。

7.1.5对外服务接口，用于数据管理平台和其他主管部门数据或业务平台间的数据交换。

# 7.2 基本协议

7.2 基本协议应采用HTTP1.1协议作为数据交换基本协议，通过GET、POST或DELETE发起HTTP请求。

其中接口字符集应符合GB/T2312的规定。数据交换过程中数据实体采用JSON格式进行封装和解析。
