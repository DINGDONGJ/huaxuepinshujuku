# 如何添加法规PDF关联

本文档说明如何为MSDS第15部分的法规名称添加PDF文件关联，实现点击跳转和自动搜索功能。

---

## 📋 功能说明

当在MSDS第15部分看到法规名称（如"《易制爆危险化学品名录（2011年版）》"）时：
- 如果该法规已关联PDF文件，会显示为**蓝色可点击链接**，并带有📄图标
- 点击后会自动打开PDF查看器，并搜索当前化学品的**CAS号**或**名称**
- 在右侧侧边栏显示所有匹配位置，可快速跳转

---

## 🚀 快速上手（3步添加）

### 步骤1：准备PDF文件

将你的PDF法规文件放到以下目录：

```
new_db/pdf/
```

**示例**：
```
new_db/pdf/
  ├── 易制爆危险化学品名录.pdf      （已存在）
  ├── 危险化学品目录2015.pdf        （新增）
  └── 高毒物品目录.pdf               （新增）
```

---

### 步骤2：修改代码配置

打开文件：`new_db/templates/index.html`

找到 **`regulationPdfMap`** 配置（约在第2612行）：

```javascript
// 法规PDF映射表（法规名称关键词 -> PDF文件名）
// 只添加实际存在的PDF文件！
const regulationPdfMap = {
    '易制爆危险化学品名录': '易制爆危险化学品名录.pdf',
    // 其他法规PDF待添加后再取消注释：
    // '危险化学品目录': '危险化学品目录2015.pdf',
    // '高毒物品目录': '高毒物品目录.pdf',
};
```

**修改为**（取消注释并添加新的映射）：

```javascript
const regulationPdfMap = {
    '易制爆危险化学品名录': '易制爆危险化学品名录.pdf',
    '危险化学品目录': '危险化学品目录2015.pdf',         // ✅ 新增
    '高毒物品目录': '高毒物品目录.pdf',                   // ✅ 新增
    '重点环境管理危险化学品': '重点环境管理目录.pdf',     // ✅ 新增
};
```

**配置规则**：
- **键**：法规标题中的**关键词**（用于匹配）
- **值**：PDF文件的**完整文件名**（包括扩展名）

---

### 步骤3：刷新浏览器测试

1. 保存修改后的 `index.html`
2. 刷新浏览器（`Ctrl + F5` 强制刷新）
3. 搜索任意化学品，查看第15部分
4. 点击新添加的法规名称，测试是否能打开PDF

## 🔍 关键词匹配规则

系统使用**模糊匹配**来识别法规名称：

### 示例1：完整匹配
```javascript
'易制爆危险化学品名录': '易制爆危险化学品名录.pdf'
```
可以匹配：
- ✅ 《易制爆危险化学品名录（2011年版）》
- ✅ 《易制爆危险化学品名录》

### 示例2：关键词匹配
```javascript
'危险化学品目录': '危险化学品目录2015.pdf'
```
可以匹配：
- ✅ 《危险化学品目录（2015年版）》
- ✅ 《危险化学品目录》

### 示例3：避免过于宽泛
```javascript
// ❌ 不推荐：太宽泛，会匹配多个法规
'化学品': 'xxx.pdf'

// ✅ 推荐：使用具体关键词
'重点监管的危险化学品': '重点监管目录.pdf'
```

## 🎯 自动搜索功能

### 默认行为

打开PDF后，系统会自动：
1. 使用当前化学品的**CAS号**搜索（优先）
2. 如果没有CAS号，使用**化学品中文名**搜索
3. 跳转到第一个匹配页面
4. 在右侧侧边栏显示所有匹配位置

### 示例

查看"乙醇"的法规信息：
- CAS号：`64-17-5`
- 点击PDF后自动搜索 `64-17-5`
- 找到所有包含该CAS号的页面

## 🛠️ 高级功能：分析PDF并生成索引

如果你的PDF文件很大，想要更精确的定位，可以使用分析工具。

### 使用 `analyze_pdf.py` 工具

在 `new_db` 目录下已有分析工具，可以提取PDF中所有化学品的位置：

```bash

```

**功能**：
- 扫描PDF文件中的所有CAS号
- 记录每个CAS号出现的页码
- 生成JSON索引文件

**生成文件示例**：
```
new_db/pdf/易制爆危险化学品名录_analysis.json
```

**未来扩展**：可以利用这个索引实现更精确的跳转功能。

## 📝 完整配置示例

假设你有以下法规PDF需要添加：

```
new_db/pdf/
  ├── 易制爆危险化学品名录.pdf
  ├── 危险化学品目录2015版.pdf
  ├── 高毒物品目录2003版.pdf

const regulationPdfMap = {

    '高毒物品目录': '高毒物品目录2003版.pdf',

    '消耗臭氧层物质名录': '消耗臭氧层物质名录.pdf',
};
```

## ⚠️ 常见问题

### Q1: 添加PDF后点击没反应？

**检查清单**：
1. ✅ PDF文件是否放在 `new_db/pdf/` 目录下？
2. ✅ 文件名是否与配置中的完全一致（包括扩展名和大小写）？
3. ✅ 是否刷新了浏览器缓存（`Ctrl + F5`）？
4. ✅ 检查浏览器控制台是否有错误信息（按F12查看）

### Q2: 关键词匹配不上？

**解决方法**：
1. 查看MSDS第15部分中法规的完整名称
2. 提取其中最具特征性的关键词
3. 使用**包含关系**而非完全匹配

**示例**：
```
法规全称："《危险化学品目录（2015年版）》，安监总局2015年第5号公告"
关键词：   "危险化学品目录"
```

### Q3: PDF文件太大加载慢？

**优化建议**：
1. 压缩PDF文件（推荐使用PDF压缩工具）
2. 优化PDF内部图片质量
3. 如果可能，将大型PDF拆分成章节

### Q4: 如何删除PDF关联？

**方法**：
1. 在 `regulationPdfMap` 中注释掉或删除对应行
2. 保存文件并刷新浏览器

```javascript
const regulationPdfMap = {
    '易制爆危险化学品名录': '易制爆危险化学品名录.pdf',
    // '危险化学品目录': '危险化学品目录2015.pdf',  // ← 注释掉
};
```
