# 3术语和定义

《关于危险货物运输的建议书试验和标准手册》和SN/T1828.1界定的以及下列术语和定义适用于本文件。

3.1

腐蚀性物质 corrosive substances

通过化学作用在接触生物组织时造成严重损伤或在渗漏时会严重损害甚至毁坏其他货物或运输工具的物质。

3.2

皮肤腐蚀性 skin corrosion

化学物引起的皮肤严重的不可逆性损伤,表现为4h内出现的表皮至真皮的坏死。腐蚀性反应主要表现为溃疡、出血、血痴,以及在14d观察期末出现的皮肤脱色变白、大面积脱发、疤痕。

3.3

金属腐蚀性 corrosion to metals

不引起皮肤组织全厚度毁损,但在55℃的试验温度下对钢或铝表面的腐蚀率超过6.25mm/s的物质。

# 4试验

# 4.1体外评估

为减少和避免腐蚀试验给动物带来的痛苦,可采取体外评估的方法进行腐蚀性判定。体外方法主

要有两种:

——体外皮肤腐蚀,经皮电阻试验,按照SN/T2246进行试验。

——体外皮肤腐蚀,人体皮肤模型试验,按照SN/T2245进行试验。

根据SN/T2246或SN/T2245确定无腐蚀性的物质,可无需进一步的试验即视为对皮肤无腐蚀性。如根据SN/T2246或SN/T2245确定有腐蚀性的物质,可进一步通过生物腐蚀性试验确定腐蚀性危险等级。

# 4.2 生物腐蚀性试验

# 4.2.1 试验样品

4.2.1.1 液态试验样品应用原液或预计人的实际应用浓度,染毒量为  $0.5\mathrm{mL}$ 。

4.2.1.2 固体试验样品应粉碎研磨,用水或适宜的赋形剂按  $1:1$  比例调制,保证与皮肤充分接触。固体或半固体试验样品的染毒量为  $0.5\mathrm{g}$ 。

注:所用的赋形剂对皮肤无刺激作用,已知强酸(pH<2)或强碱(pH>11.5)的化学物质无需进行本项实验。

# 4.2.2 试验动物

健康白色家兔三只,实验前  $24\mathrm{h}$ ,动物背部脊柱两侧的受试区皮肤去毛,脱毛范围  $3\mathrm{cm} \times 3\mathrm{cm}$ ,不损伤皮肤。

# 4.2.3 试验步骤

4.2.3.1 取受试物  $0.5\mathrm{mL}(\mathrm{g})$  直接涂在  $2.5\mathrm{cm} \times 2.5\mathrm{cm}$  大小的皮肤上,仔细、缓慢涂布,不使药液流失。涂毕用四层纱布敷在其上,用无刺激性胶布或绷带固定。当受试物为液体或溶状物时,需先将其置于纱布上,然后再接触皮肤。

4.2.3.2 当受试物质可能具有腐蚀性时,最多使用三块试验贴连续作用于动物皮肤。第一块试验贴作用  $3\mathrm{min}$  后移去,如未见严重的皮肤反应,使用第二块试验贴,  $1\mathrm{h}$  后移去,如观察结果显示暴露于受试物的时间可以延长至  $4\mathrm{h}$ ,则可以使用第三块试验贴,于  $4\mathrm{h}$  后移去并将出现的皮肤反应分级。其中任何一步观察到腐蚀性反应时,均应立即结束实验。如果你疑受试物质具有强烈的刺激性而无腐蚀性,则使用一块试验贴作用于动物皮肤  $4\mathrm{h}$ 。

4.2.3.3 为了确定观察反应的可逆性,动物需要被观察到移去试验贴的第  $14\mathrm{d}$ 。如果第  $14\mathrm{d}$  前出现可逆反应,或出现剧烈疼痛、衰竭的表现,应停止试验。

# 4.3 金属腐蚀性试验

# 4.3.1 试验条件

经生物组织腐蚀性试验证明无腐蚀性作用的物质,进行金属腐蚀性试验。

# 4.3.2 试验步骤

方法按GB/T21621进行试验。

# 5 类别判定

# 5.1 危险特性判定

满足下列条件之一,则判定为第8类腐蚀性物质:

——在  $14\mathrm{d}$  的观察期内造成试验动物皮肤全厚度破坏的物质;

不引起完整皮肤组织全厚度破坏,在  $55^{\circ} \mathrm{C}$  的试验温度下对钢或铝表面的腐蚀率超过一年  $6.25 \mathrm{~mm}$  的物质。
