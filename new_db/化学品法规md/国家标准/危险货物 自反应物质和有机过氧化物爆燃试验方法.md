# 3 术语和定义

GB19521.12、GB/T21535、GB30000.9、GB30000.16界定的以及下列术语和定义适用于本文件。

3.1

# 爆炸 explosion

在极短时间内，释放出大量能量，产生高温，并放出大量气体，在周围造成高压的化学反应或状态变化的现象。

[来源：GB/T21535—2008，2.14]

3.2

# 爆燃 deflagration

以接近爆炸性反应速率进行猛烈燃烧的现象。[来源：GB/T21535—2008，2.10，有修改]

3.3

# 有机过氧化物 organic peroxides

可发生放热自加速分解、热不稳定的物质或混合物。注：有机过氧化物也是含有二价的O- O- 结构、可视为过氧化氢的一个或两个氢原子已被有机基团所取代的衍生物的液态或固态有机物，包括有机过氧化物配制品（混合物）。

[来源：GB30000.16—2013，3.1，有修改]

3.4

自反应物质或混合物 self- reactive substances or mixtures即使没有氧(空气)也容易发生激烈放热分解的热不稳定液态或固态物质或者混合物。[来源：GB30000.9—2013，3.1，有修改]

3.5

自加速分解温度 self- accelerating decomposition temperature物质装在运输所用的容器里可能发生自加速分解的最低环境温度。[来源：GB19521.12—2004，3.3]

# 4 试验原理

4 试验原理用  $14 \mathrm{mm}$  玻璃管、  $28 \mathrm{mm}$  玻璃管和杜瓦瓶对有机过氧化物和自反应物质或混合物样品进行试验。按接近储存运输过程中的密度装填样品，从顶部加热样品至点燃（或在  $5 \mathrm{min}$  内没有点燃），使用热电偶监测固定点的温度，获得2个热电偶输出值剧增的时间差，将2个热电偶的间距除以时间差进一步获得爆燃速度。通过观察试验现象、分析爆燃速度评判有机过氧化物和自反应物质或混合物样品是否能够传播爆燃以及传播爆燃的能力。

# 5 仪器与设备

# 5.1 杜瓦瓶

5 仪器与设备5.1 杜瓦瓶使用内径为  $48 \mathrm{mm} \pm 1 \mathrm{mm}$  、外径为  $60 \mathrm{mm}$  、长度为  $180 \mathrm{mm} \sim 200 \mathrm{mm}$  、容积为  $300 \mathrm{mL}$  的杜瓦瓶。在离杜瓦瓶顶端  $50 \mathrm{mm}$  和  $100 \mathrm{mm}$  处标有水平刻度，且杜瓦瓶瓶身热损失率不大于  $0.1 \mathrm{W} /(\mathrm{kg} \cdot \mathrm{K})$  。杜瓦瓶示意图如图1所示。

标引符号说明：A——装填高度在容器口下  $20 \mathrm{mm}$ ；B——供爆燃形成的  $30 \mathrm{mm}$  区；C——供测量爆燃速度的  $50 \mathrm{mm}$  区。

# 5.2 热电偶

5.2 热电偶应符合GB/T30429的规定，量程覆盖室温至  $1200^{\circ}C$  ，测温精度优于  $0.1^{\circ}C$  ，最大采样频率不小于 $10\mathrm{Hz}$  0

# 5.3 温度数据采集仪

对温度数据采集仪的具体要求如下：

a) 测量通道不少于2个；b) 采样频率不低于  $10\mathrm{Hz}$  .c) 数据连续采集时间不小于  $12h$  0

# 5.4 点火装置

气体点火器：能产生长度不小于  $20~\mathrm{mm}$  的火焰。

# 5.5 防爆通风柜

5.5 防爆通风柜材质应符合GB/T11251的规定。试验应在防爆通风柜或通风良好的试验室中进行；抽风机的排风量应不小于  $12 \mathrm{m}^3 /\mathrm{min}$ ，以便将分解产物稀释至与空气的混合物不会达到爆炸浓度。

# 5.6 防护屏障

5.6 防护屏障试验人员和杜瓦瓶之间应放置防护屏障，可选用厚度为  $5 \mathrm{mm}$  左右且尺寸不小于  $1 \mathrm{m} \times 2 \mathrm{m}$  的钢板，防止试验试样发生爆炸或爆燃，保障试验人员人身安全。

# 5.7 计时器

用于记录时间，分辨率优于  $1\mathrm{~s~}$  0

# 6 试验程序

# 6.1 热损失校准

在进行试验之前，对杜瓦瓶的热损失率进行校准。在杜瓦瓶中充填  $90^{\circ}C$  以上的蒸馏水（或其他与试样物性类似的惰性材料)至杜瓦瓶顶端以下  $20~\mathrm{mm}$  处进行冷却，记录瓶身温度从  $90^{\circ}C$  开始下降至 $45^{\circ}C$  所用的时间。按公式(1)对单位质量的热损失进行计算：

$L = \ln 2(C_{\mathrm{P}} / t_{0.5})$  (1)

式中：

$L$  ——单位质量的热损失，单位为瓦特每千克开尔文  $\left[\mathrm{W} / (\mathrm{kg}\cdot \mathrm{K})\right]$ ； $C_{\mathrm{P}}$  ——物质的比热，单位为焦耳每千克开尔文  $\left[\mathrm{J} / (\mathrm{kg}\cdot \mathrm{K})\right]$ ； $t_{0.5}$  ——瓶身温度下降一半所用的时间，单位为秒(s)。

# 6.2 小当量筛选试验

6.2.1 先用直径为  $14~\mathrm{mm}$  的玻璃管进行试验，若爆燃速度超过  $5\mathrm{mm / s}$ ，则归类为爆燃物质，无需进行杜瓦瓶试验。

6.2.2 若爆燃速度未超过  $5\mathrm{mm / s}$ ，则用直径为  $28~\mathrm{mm}$  的玻璃管进行试验，当爆燃速度超过  $5\mathrm{mm / s}$  时，同样归类为爆燃物质，无需进行杜瓦瓶试验。

# 6.3 杜瓦瓶试验

# 6.3.1 试验准备

热电偶安装按以下要求：

a）将2个热电偶分别固定在距杜瓦瓶顶端  $50~\mathrm{mm}$  和  $100~\mathrm{mm}$  处；b）接入温度数据采集仪。

# 6.3.2 试样装填

记录试样的质量和温度，同时试样装填按以下要求。

a）将试样充填至杜瓦瓶瓶口以下  $20~\mathrm{mm}$  处。b）颗粒试样在杜瓦瓶中的装填密度应接近试样运输过程中的密度，并且没有团聚结块。糊状试样在装填杜瓦瓶过程中不能存在气泡。

# 6.4 试验步骤

6.4.1 将杜瓦瓶放进置于防护屏障后的防爆通风柜中。

6.4.2 加热使杜瓦瓶和试样，使温度达到界定的危急温度（当物质自加速分解温度不大于  $35^{\circ}C$ ，危急温度比物质自加速分解温度低  $10^{\circ}C$ ；当物质自加速分解温度大于  $35^{\circ}C$ ，危急温度比物质自加速分解温度低  $5^{\circ}C$ ）。如果物质十分稳定，则没有危急温度要求，试验在  $50^{\circ}C$  下进行。

6.4.3 用气体点火器从顶端将试样加热，在观察到点燃时（或在  $5\mathrm{min}$  内没有点燃），将气体点火器移开并熄灭。

6.4.4 连续监测温度数据采集仪输出值，反应锋面通过热电偶时会使输出值急剧增加，确定2个输出值剧增的时间差，记为  $t$ 。

6.4.5 如果反应在杜瓦瓶  $100~\mathrm{mm}$  刻度前停止，试样即被视为未发生爆燃。

6.4.6 平行试验2次，以最短的反应时间来计算试样爆燃速度。

# 7 数据处理和结果评定

# 7.1 数据处理

爆燃速度  $(v)$  按公式（2）进行计算：

$$
v = l / t
$$

（2）

式中： $v$  ——爆燃速度，单位为毫米每秒  $(\mathrm{mm} / \mathrm{s})$ ； $l$  ——两个热电偶的间距，单位为毫米  $(\mathrm{mm})$ ； $t$  ——两个热电偶输出值剧增的时间差，单位为秒（s）。

# 7.2 结果评定

若试验爆燃速度  $\mathcal{U}$  大于  $5.0 \mathrm{mm / s}$  ，则试验结果为“是，很快”；若试验爆燃速度  $\mathcal{U}$  不小于  $0.35 \mathrm{mm / s}$  ，同时不大于  $5.0 \mathrm{mm}$  ，则试验结果为“是，很慢”；若试验爆燃速度  $\mathcal{U}$  不大于  $0.35 \mathrm{mm / s}$  ，则试验结果为“否”。
