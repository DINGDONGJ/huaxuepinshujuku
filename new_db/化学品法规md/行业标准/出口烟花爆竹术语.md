# 前言

本标准由国家认证认可监督管理委员会提出并归口。本标准起草单位：中华人民共和国江西出入境检验检疫局。本标准主要起草人：桂家祥、吴劲松、刘捷光。本标准系首次发布的出入境检验检疫行业标准。

# 出口烟花爆竹术语

# 1 范围

本标准规定了烟花爆竹的有关术语和定义。

本标准适用于出口烟花爆竹时相关术语和概念的统一理解和使用，编写标准、技术文件、出版书刊以及学术交流及业务往来中也可参照使用。

# 2 术语和定义

2.1

民用爆炸品 explosive for civil use

用于矿山、工程爆破、娱乐等各种非军用火药、炸药及其制品和点火、起爆器材。民用爆炸品包括：

- 爆破器材，包括各类炸药、雷管、导火索、导爆索、非电导爆系统、起爆药的爆破药；- 黑火药、烟火药、民用信号弹和烟花爆竹；- 公安部认为需要管理的其他爆炸物品。

2.2

# BE号BENumber

由美国爆炸品管理局指定给新的烟火产品的号码，以示此新产品经过测试，其火药含量符合规定。

2.3

# EX号码 EXnumber

美国运输部使用的识别号码，用以在运输系统及紧急反应中追踪爆炸物质。

2.4

# 线香类sparkler

用装饰纸或薄纸筒裹装烟火药，或在铁丝、竹杆、木杆或纸片上涂敷烟火药形成的线状烟花产品。

2.5

# 升空类 aerial devices

燃放时，主体上升至空中产生效果的烟花产品。

2.6

# 地面礼花类 multipleshots

燃放时放置在地面，从主体内发射并在空中爆发出珠花、响炮、笛音或飘动等效果的烟花产品。

2.7

# 吐珠类 roman candle

燃放时从同一筒体有规律地发射出多颗彩珠、彩花、响炮等的烟花产品。

2.8

# 钉挂类 spinner

产品设计为以其中心与柱子或吊绳相连，并由驱动装置产生旋转效果，当点燃后，会产生动作及视觉和听觉效果。

2.9

# 小礼花弹类 small shell

弹体从发射筒中发射到空中后，能爆发出各种花型图案或其他效果，弹体直径不大于  $76 \mathrm{mm}$  的烟

花产品。

2.10

礼花弹类 display shell

弹体从专用发射工具发射到高空后能爆发出各种光色、花型图案或其他效果，弹体直径大于等于 $76~\mathrm{mm}$  的烟花产品。

2.11

硝酸盐炮类 firecracker with nitrate composition

以硝酸盐为氧化剂的爆响药制成的爆竹产品。

2.12

氯酸盐炮类 firecracker with chlorate composition

含有氯酸盐为氧化剂的爆响药制成的爆竹产品。

2.13

高氯酸盐炮类 firecracker with perchlorate composition

以高氯酸盐为氧化剂的爆响药制成的爆竹产品。

2.14

摩擦类 frictional type

用撞击、摩擦等方式引燃或引爆主体的烟花产品。

2.15

造型玩具类 toy firework

产品外壳制成各种形状，燃放时或燃放后能模仿所造成形象或动作；或产品外表无造形，但燃放时或燃放后能产生某种形象的产品。

2.16

烟雾类 smoke

燃放时以产生烟雾效果为主的产品。

2.17

旋转升空类 aerial spinner

燃放时，自身旋转升至空中的烟花产品。

2.18

旋转类 ground spinner

燃放时，自身旋转但不升空的烟花产品。

2.19

喷花类 fountain

燃放时以喷射火苗、火花为主的产品。

2.20

烟花爆竹 firework and firecracker

以烟火药为原料，经过工艺制作形成的，燃放时能产生声、光、色、烟、雾等效果之一或其组合的娱乐产品。

2.21

烟花 firework

燃放时能形成色彩、图案、产生音响效果，以视觉效果为主的产品。

2.22

爆竹 firecracker

燃放时主体爆炸并能产生爆音、闪光等效果，以听觉效果为主的产品。

2.23

普通烟火 consumer firework

《美国》适合大众使用的烟花产品，在结构、性能、火药成分和燃放说明方面，符合美国联邦法规汇编第16条所列美国消费者产品委员会之规定以及美国运输部BOE—6000—G.173.100条例的规定。普通烟火的设计上能产生视觉及（或）听觉效果。

2.24

一级花炮 category1fireworks

《英国》适应于室内燃放的花炮称一级花炮或室内花炮。当使用者按照说明燃放时，站在离花炮 $1\mathrm{m}$  或  $1\mathrm{m}$  以外的人或财产将不会受到伤害。对于手持类一级花炮，手持者不应受到伤害。

2.25

二级花炮 category2fireworks

《英国》适应于室外相对封闭的空间燃放的花炮称二级花炮，又称花园花炮。当使用者按照说明燃放时，站在离花炮  $5\mathrm{m}$  或  $5\mathrm{m}$  以外的人或财产将不会受到伤害。对于手持类二级花炮，落下的热渣及喷射的火花不能伤害手持者。

2.26

三级花炮 category3fireworks

《英国》适应于室外大的开放空间燃放的花炮称三级花炮，又称表演花炮。当使用者按照说明燃放时，站在离花炮  $25\mathrm{m}$  或  $25\mathrm{m}$  以外的人或财产将不会受到伤害。三级花炮的燃放者要求穿防护衣。

2.27

玩具烟花 novelty

小型烟花产品，通常具有似玩具、动物等的形状。

2.28

手持线香 hand- heldsparkler

沿着线的一端涂有药物，设计成握在手中，点燃后发出火花等效果的烟花产品。

2.29

非手持线香 nonhanded- heldsparkler

线上部分涂有药物，设计成插在地上或固定在底座上，点燃后发出火花等效果的烟花产品。

2.30

电光花 dippedsparkler

金属条或其他棒状产品，外表覆以火药成分，在点燃后可产生火花等效果的烟花产品。

2.31

飞弹 missile

用尾翼稳定方式飞行的一种升空烟花产品。

2.32

火箭 rocket

自推进的烟花产品，带有稳定飞行的稳定杆，点燃后升空，伴随有爆炸声和（或）烟火效果，并产生声响效果。

2.33

火炬 torch

由含有火药成分的圆柱形筒子组成，点燃时产生彩色火焰的烟花产品。

2.34

礼花弹 display shell

设计为从发射管中发射，包含有发射药、延时引线、绽放药、烟火效果件，点燃后升空，爆炸，抛射烟

火效果件，产生视听效果的烟花产品。

2.35

圣诞炮 party popper

由拉线点火的手持烟花产品，拉响后发射出飘带或伴随响声。

2.36

小青蛇 black snake

火药成分压缩成一小弹丸，燃烧时会产生大片长蛇状造型的烟花产品。

2.37

甩炮 snap bomb

小型烟花产品，其总火药量在  $1\mathrm{mg}$  以下，涂抹在砂上。把甩炮丢到地面时，会因撞击地面而爆炸，并产生轻微爆炸声。

2.38

桌弹 table bomb

由引火线点火的烟花产品，点燃之后发射出飘带和（或）玩具，并伴随响声。

2.39

黑药炮 black powder firecracker

含有黑火药的单管，燃放后产生爆炸声。

2.40

拉炮 pull bomb

两块涂有摩擦感度较高的药物组分的纸块或卡片，通过粗糙表面滑动而爆炸，拉开时，发出爆炸声的烟花产品。

2.41

摔炮 snap

包含有撞击感度较高的药物组分，扔地时，发出响声的烟花产品。

2.42

砂炮 snap

一种含有少量附在砂子上的化学成分并裹在纸中，摔到地面后产生爆炸效果的烟花产品。

2.43

樱桃炮 cherry bomb

一种非法爆竹的俗称，美国从1966年起禁用。这类非法爆竹含有超量火药成分，造成多起严重受伤事件。

2.44

地雷炮 mine

在地面点火的烟花产品，其中含有单个的发射药以及烟火药，点燃后在一声爆炸声中，发出所有的烟火效果，同时产生大范围的视听效果。

2.45

地老鼠 ground mouse

设计中能在地面上不规则地移动，带有哨音的各式烟花产品。

2.46

反复装填小炮弹 aerial shell kit wite reloadables tube

可以从发射筒多次装填发射小炮弹的烟花产品。

2.47

吐珠筒 roman candle

〈中国〉冲天式烟花产品，可连续发射最多十个火球至上空。

2.48

罗马蜡烛 roman candle

〈国外〉单管中交替装有烟火药和发射药，点燃后连续地发射出烟火球，产生视听和（或）听觉效果，或远离花炮产品产生一系列类似效果的烟花产品。

2.49

快乐烟花 happy firework

小型塑料或纸的烟花产品，会有少量的对摩擦敏感的化学成分。拉动从装置上引出的绳子去点燃这个装置，产生一个小的炸子声和喷出纸花等饰品。

2.50

花筒 fountain

由含有药物的单管组成的烟花产品，点燃后发出火花和火焰，伴随着声响效果，而不是爆炸声，或者没有任何声响效果。

2.51

火帽 cap

非金属物包含着撞击感度较高的药物组分所形成的小圆包，燃放后产生响声。

2.52

纸火帽 paper cap

用纸包含炸药的小圆包，并将其卷成圈的烟花产品。

2.53

塑料胶囊火帽 plastic capsule cap

将炸药完全密封在塑料材料中形成的火帽。

2.54

塑料杯式火帽 plastic cup cap

将炸药放在塑杯中用圆盘将其密封形成的火帽。

2.55

直升机 helicopter

装有烟火药剂的筒子，带有螺旋桨或桨叶，点燃后，迅速地旋转并升上空中的烟花产品。

2.56

玩具火柴 toy match

通过摩擦点火的手持烟花产品，擦燃后发出声响和（或）视觉效果。

2.57

蛇 snake

含预先设计成形的烟火药剂或含烟火药剂的完整容器，燃烧时产生膨胀的残渣。

2.58

组合烟花 combination firework

由燃放时产生多种欣赏效果的半成品组成一个整体的烟花产品。

2.59

架子烟花 rack firework

架子烟花是通过框架固定烟花位置、方向、燃放的产品。

2.60

烟火药 pyrotechnic powder

由氧化剂与还原剂等组成的混合物，燃烧(爆炸)时能产生声、气、光、色、烟等效果。

2.61

烟火药剂 pyrotechnic composition

由氧化剂和可燃剂等组成的混合物，并在燃烧或爆炸时能产生烟火效应。

2.62

响声药 sound powder

烟火产品中能产生听觉效果的化学药粉或混合物。

2.63

白药 flash powder

高氯酸钾、硫磺及铝的混合粉末，主要用以产生爆炸声。爆炸时产生亮光及响声。

2.64

黑火药 black powder

木炭或其他碳和硝酸钾或硝酸钠的均匀混合物，含硫或不含硫。

2.65

上升药 ascending powder

由黑火药或等效黑火药组成的化学成分，其作用是推动一个或多个视觉或听觉效果的装置升空。

2.66

2.67

爆炸药 burst charge

受到高热、摩擦、冲击等外力作用或受其他因素激发，能在很短时间内发生剧烈化学反应，放出大量气体和热量，同时伴有巨大声响而爆炸的烟火药剂。

2.68

响子 cracher

颗粒状烟火药剂，燃烧炸裂时产生火花伴随着哗啪的响声。

2.69

亮珠 star

通过机械或手工制作而能产生色光效应的颗粒状烟火药剂。

2.70

点火装置 igniting device

用于点火的，含有缓慢燃烧的药物，并且放出小火花的手持装置。

2.71

2.75

由黑药粉末制成的引线。

2.76

鞭炮引线的一部分，为一串鞭炮的初始引燃点。

2.77

# 主引燃烧 main fuse combustion

前端引线在着火后能迅速燃烧，而在引火线尚未燃尽之际，花炮的其他化学反应不应发生。

2.78

# 引火时间 fuse delay time

记录从点燃引火线至引燃主体的时间间隔。

2.79

# 引线燃烧时间 fuse delay time

从点燃引线顶端到烟火产品初次效果的时间。

2.80

# 花炮护引纸 fuse cover

为保护引火线等作用而设计粘牢在筒体上的保护纸。

2.81

# 烟火效应 pyrotechnic effect

当烟花爆竹燃烧（爆炸）时，伴随产生光、声、色、气、烟等效果及构成各种花色图案的现象。

2.82

# 发射偏斜角 launch declining angle

升空产品发射时，偏离水平面垂线的角度。

2.83

# 花炮筒 firework tube

用于填充除点火线外，所有花炮爆炸药物的容器。

2.84

# 药筒 powder tube

含有烟火药剂的筒子，在运输、保管、搬动及使用的情况下，都能防止火药漏出。

2.85

# 发射筒 launch tube

用以控制烟花升空方向的装置，如管筒和底座。

2.86

# 手柄 handle

手持类烟花中，为保证燃放时人员的安全而设计安装的手握部件。

2.87

导带 guide paper

一卷纸火帽的一部分，位于纸火帽的最外端，不含任何炸药。

2.88

主体 main body

装有烟火药或涂敷有烟火药的筒体、芯杆或粘贴标纸的整体。

2.89

净药量 nef pyrotechnic weight

烟花爆竹中烟火药剂的质量。

2.90

垂直滴落 distortion length

为稳定产品在运动中的方向而设计安装在尾部的翼片。

2.92

底塞 bottom stuff

为防止烟火药剂燃烧、发射、速燃时，火焰、气体等从底部喷出而设计筑填在底部(或中间)的泥土、纸板、塑料(包括水泥、木粉)等。

2.93

柄 handle

在玩具烟花中，用纸或塑料等制造的筒管或木、竹和铁丝等制成的，支撑主体的部分。

在花炮点燃后所不能看到的内部引线的燃烧过程。
