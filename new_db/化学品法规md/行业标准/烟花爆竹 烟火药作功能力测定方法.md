# 烟花爆竹 烟火药作功能力测定方法

# 1 范国

本标准规定了烟花爆竹用烟火药作功能力测定原理、仪器和材料、测定准备、爆炸扩张铅播中心孔试验、测量扩张后铅播中心孔容积和烟火药作功能力的计算。本标准适用于烟花爆竹用烟火药作功能力的测定。

# 3 术语和定义

下列术语和定义适用于本标准。

3.1

烟火药作功能力 pyrotechnics strength

烟火药作功能力是指烟火药爆炸时对周围介质所作的总的机械功。

# 4 测定原理

在规定参量(质量、密度和几何尺寸)的条件下,烟火药爆炸时对铅播中心孔进行扩张,以铅播中心孔扩张的容积来衡量烟火药的作功能力。烟火药不具备爆炸条件时的作功能力为  $0 \mathrm{~mL}$ 。

5.1铅播,如图1所示,应符合WJ/T9030要求。

图1 铅塔

5.2 滴定管: 容量为  $50 \mathrm{~mL}$ , 精度  $+0.1 \mathrm{~mL}$  。

5.3 石英砂: 经风干的石英砂, 粒度为  $425 \mu \mathrm{m} \sim 710 \mu \mathrm{m}$ , 维积密度为  $1.35 \mathrm{~g} / \mathrm{cm}^{3} \sim 1.37 \mathrm{~g} / \mathrm{cm}^{3}$  。

5.4 纸袋纸: 符合 GB/T 2968 要求, 选用  $80 \mathrm{~g} / \mathrm{m}^{2}$  的纸袋纸。

5.5 带孔图纸板: 外径  $23.75 \mathrm{~mm} + 0.25 \mathrm{~mm}$ , 中心孔径  $7.5 \mathrm{~mm} + 0.1 \mathrm{~mm}$  (中心孔径应按 8 号联发金属壳电雷管外径调整, 以保证电雷管刚好能穿过中心孔), 薄纸板厚度  $1.5 \mathrm{~mm} \sim 2.0 \mathrm{~mm}$  。

5.6 电雷管: 符合 GB 8031 要求, 选用 8 号联发金属壳电雷管。

5.7 起爆器。

# 6 测定准备

# 6.1 加工纸筒

将纸袋纸  $(80 \mathrm{~g} / \mathrm{m}^{2})$  纸裁或如图 2 所示的直角梯形, 从直角边开始用直径  $24 \mathrm{~mm}$  的光滑图棒卷成圆筒, 下底应突出图棒端面  $15 \mathrm{~mm} \sim 20 \mathrm{~mm}$ , 将突出部分向内折好, 形成筒底, 并将接缝粘牢。

单位为毫米

图2 直角梯形纸

# 6.2 测量扩张前的铅塔中心孔容积

以水作介质用滴定管测量铅塔中心孔的容积,擦干铅塔及中心孔内的水分,用  $V_{0}$  表示(精确到  $0.1 \mathrm{~mL}$ ),对铅塔编号备用。

# 6.3 烟火药预处理

发射药不进行研磨和筛选。

粉状烟火药不进行研磨,使烟火药通过孔径  $425 \mu \mathrm{m}$  的标准筛,如有不能通过的铝渣、钛粉等硬质颗粒,将硬质颗粒一同放入筛过的烟火药中,混合均匀。

块状或粒状烟火药,不论是否含有外层的引燃药,均不剥离,直接在铜钵内碾碎、研磨(如有大块的纸屑、稻壳应剔除)混合,使烟火药通过孔径  $425 \mu \mathrm{m}$  的标准筛,如有不能碾碎的铝渣、钛粉等硬质颗粒,将硬质颗粒一同放入筛过的烟火药中,混合均匀。

# 6.4 称取烟火药

称量已预处理的烟火药  $10.0 \mathrm{~g} + 0.1 \mathrm{~g}$ ,放入干燥器中待用。

# 7 爆炸扩张铅塔中心孔试验

# 7.1 确定警戒线

在爆炸洞内进行爆炸扩张铅塔中心孔试验时,设置的警戒线距爆炸洞应  $\geqslant 2 \mathrm{~m}$  (在野外试验时,设置的警戒线距爆炸点应  $\geqslant 65 \mathrm{~m}$ ),起爆器应放置在警戒线以外,清理警戒线内的无关人员,提醒爆炸点附近的所有人员注意,并派专人进行警戒。

# 7.2 安装爆炸扩张铅塔中心孔的装置(如图3所示)

![](images/74199edf82ad3120ef4e70d30a9d0e3c553fa906f391a58c6636070e01bd4eda.jpg)  
图3 爆炸扩张铅塔中心孔装置示意图

将称量好的烟火药缓慢倒入纸筒中,自然堆集,轻轻振动使药面平整。

将铅桶水平放置在坚硬的基础上,将装烟火药和电雷管的纸筒放入铅桶中心孔内,并小心地用木棒将它送到孔的底部,铅桶中心孔内剩余的空间用石英砂填满、刮平。石英砂应自由倒入,不得振动或捣固。

# 7.3 安装电雷管

除接线员外的所有检验人员撤离到警戒线外。

将电雷管脚线短路,轻轻将电雷管穿过带孔图纸板中心孔并穿出  $12 \mathrm{~mm}$ ,再将电雷管和带孔图纸板一起放入纸筒中,保证电雷管相对垂直药面并把其穿出的  $12 \mathrm{~mm}$  完全插入烟火药中,轻轻压平带孔图纸板(避免试样外泄到带孔图纸板上)。

# 7.4 接线

由接线员控制起爆器,在确认起爆线另一端短路且与起爆器处于断开状态下,将电雷管线与起爆线连接,再关闭爆炸洞的门并扣紧后撤离到起爆器处(在野外试验时,接线员将电雷管线与起爆线连接好后,再撤离到起爆器处)。

# 7.5 爆炸试验

确认所有人员都已在警戒线之外后,检查确认起爆线、电雷管线、电雷管导通良好,将起爆线与起爆器连接,根据现场指挥人员指令起爆。

打开爆炸洞抽风机进行排烟,排烟完全后再进入爆炸洞,取出爆炸扩张后铅桶并整理现场(在野外试验时,爆炸后完成后取回爆炸扩张后铅桶并整理现场)。

# 8 测量扩张后的铅塔中心孔容积

擦拭爆炸后铅桶表面上的脏物,将铅桶倒置,用毛刷清除铅桶中心孔内的残留物,再放平铅桶,以水作介质用滴定管测量铅桶中心孔的容积,用  $V_{1}$  表示(精确到  $0.1 \mathrm{~mL}$  )。

每种烟火药做2次试验,容两次试验  $\Delta V$  的差值  $\leqslant 20 \mathrm{~mL}$  时,两次试验结果平行,取2次试验结果的平均值  $\Delta V_{\text {烟火气}}$  作为烟火药爆炸扩张铅塔中心孔容积,按本标准的9.2条计算烟火药作功能力。

若两次试验  $\Delta V$  的差值  $>20 \mathrm{~mL}$  时,重新再做1次试验,第3次试验的  $\Delta V$  值与前2次试验之一的  $\Delta V$  的差值  $\leqslant 20 \mathrm{~mL}$  时,取最相近的两次试验结果的平均值  $\Delta V_{\text {烟火气}}$  作为烟火药爆炸扩张铅塔中心孔容积,按本标准的9.2条计算烟火药作功能力。

若第3次试验的  $\Delta V$  值与前2次试验的  $\Delta V$  的差值均  $>20 \mathrm{~mL}$  时,应查找原因后,重新试验。
