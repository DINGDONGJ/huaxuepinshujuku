========================================================
        MSDS Database System - Quick Start Guide       
========================================================

STEP 1: Install Dependencies
------------------------------------------------------------
Double click: install_deps.bat

This will install:
  - Python packages (Flask, PyMySQL, requests, etc.)
  - Playwright browser (for web scraping)


STEP 2: Setup Database
------------------------------------------------------------
Method A: Using MySQL command line (Recommended)

  mysql -u root -p1234
  source C:\Users\Administrator.DESKTOP-URBQKM0\Desktop\huaxuepinshujuku\new_db\init_simple_db.sql
  source C:\Users\Administrator.DESKTOP-URBQKM0\Desktop\huaxuepinshujuku\new_db\sample_data.sql
  exit

Method B: Using cmd

  cd new_db
  mysql -u root -p1234 < init_simple_db.sql
  mysql -u root -p1234 < sample_data.sql


STEP 3: Scrape Chemical Data
------------------------------------------------------------
Double click: run_scraper.bat

  [1] Scrape only (save as JSON)
  [2] Scrape and import to database  <-- Select this

Enter URL: http://www.hgmsds.com/weixin/msds-list-details?decrypt=xxx
Enter password: 1234 (or press Enter for default)


STEP 4: Start Web Application
------------------------------------------------------------
Double click: start_web.bat

Open browser: http://localhost:5001


========================================================
        File Description                                
========================================================

install_deps.bat    - Install all dependencies
run_scraper.bat     - Scrape MSDS data from website
start_web.bat       - Start web query application

scrape_to_json.py   - Main scraper script
app.py              - Web application backend
templates/          - Web interface files

init_simple_db.sql  - Database schema
sample_data.sql     - Sample data (formaldehyde)
query_examples.sql  - SQL query examples


========================================================
        Command Line Usage                              
========================================================

Scrape only:
  python scrape_to_json.py "URL"

Scrape and import:
  python scrape_to_json.py "URL" --import

Custom password:
  python scrape_to_json.py "URL" --import --password YOUR_PASSWORD

Help:
  python scrape_to_json.py --help


========================================================
        Troubleshooting                                 
========================================================

Problem: Cannot find MID
Solution: 
  - Make sure Playwright is installed
  - Run: python -m playwright install chromium

Problem: Database connection error
Solution:
  - Check MySQL service is running
  - Verify database password
  - Make sure database is created

Problem: Import failed
Solution:
  - The JSON file is still saved in msds_json/
  - You can manually upload it via web interface
