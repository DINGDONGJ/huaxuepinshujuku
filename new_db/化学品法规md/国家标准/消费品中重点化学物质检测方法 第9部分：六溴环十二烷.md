# 引言

近年来，随着新材料新工艺在消费品领域的广泛应用，产品中潜在的化学物质安全问题逐渐凸显，引起了国内外社会各界的高度关注。我国针对消费品中化学物质管控需求制定了一系列标准，同时与之配套的科学、高效、精准检测方法是管控化学物质的关键。GB/T44165%消费品中重点化学物质检测方法》系列标准旨在针对消费品中高风险化学物质，提供规范的检测方法，拟由9个部分构成。

第1部分：短链氯化石蜡。目的在于提供消费品中短链氯化石蜡含量的测定方法。第2部分：苯乙烯迁移量。目的在于提供消费品中苯乙烯迁移量的测定方法。第3部分：氯代乙烷。目的在于提供消费品中氯代乙烷含量的测定方法。第4部分：1，4- 二氯苯。目的在于提供消费品中1，4- 二氯苯含量的测定方法。第5部分：苯酚。目的在于提供消费品中苯酚含量的测定方法。第6部分：丙烯酰胺。目的在于提供消费品中丙烯酰胺含量的测定方法。第7部分：多氯萘。目的在于提供消费品中多氯萘含量的测定方法。第8部分：全氟辛烷磺酸（PFOS）和全氟辛酸（PFOA）。目的在于提供消费品中全氟辛烷磺酸（PFOS）和全氟辛酸（PFOA）含量的测定方法。第9部分：六溴环十二烷。目的在于提供消费品中六溴环十二烷含量的测定方法。

# 消费品中重点化学物质检测方法第9部分：六溴环十二烷

# 1范围

1 范围本文件描述了消费品中六溴环十二烷  $(\alpha , \beta , \gamma$ - 六溴环十二烷) 高效液相色谱- 质谱测定方法。本文件适用于含以下材料的消费品（除电子电气产品、纺织品、玩具外）中六溴环十二烷  $(\alpha , \beta , \gamma$ - 六溴环十二烷）的测定：- 塑料；- 橡胶；- 粘合剂、胶水等液体材料。消费品中其他材质产品经过验证后参照本文件进行测定。

# 3术语和定义

3.1

# 消费品 consumer product

主要但不限于为个人使用而设计、生产的产品。注：包含产品的组件、零部件、附件、使用说明和包装。消费品分类详见GB/T36431。[来源：GB/T35248—2017，2.2，有修改]

3.2

# 六溴环十二烷 hexabromocyclododecanes；HBCDDs

一类由12个碳原子构成的环状烷烃，其中6个氢原子被溴原子所取代的化合物，化学式为 $\mathrm{C_{12}H_{18}Br_6}$  0

注：六溴环十二烷存在多种立体异构体，主要包括  $\alpha ,\beta ,\gamma$  - 六溴环十二烷三种同分异构体。

# 4原理

4 原理粉碎混匀后的试样经丙酮- 正己烷进行快速溶剂萃取，经固相萃取柱净化，浓缩定容后，利用高效液相色谱- 质谱法进行测定，外标法定量。

# 5 试剂或材料

除另有说明外，本文件所用试剂均为色谱纯，所用水应符合GB/T6682中的一级水规定。

5.1 甲醇  $\mathrm{CH_3OH}$  。

5.2 丙酮  $\mathrm{C_3H_6O}$  。

5.3 正己烷  $\mathrm{C_6H_{14}}$  。

5.4 二氯甲烷  $\mathrm{CH_2Cl_2}$  。

5.5 丙酮- 正己烷溶液  $(1:1)$  ：将丙酮（5.2）和正己烷（5.3）按等体积比混合均匀。

5.6 酸性硅胶  $(44\%)$  ：称取  $100\mathrm{g}$  活化硅胶，逐滴滴入  $43\mathrm{mL}$  浓  $\mathrm{H_2SO_4}$  。

5.7  $10\mathrm{mmol / L}$  醋酸铵  $\mathrm{C_2H_7NO_2}$  溶液：  $0.77\mathrm{g}$  醋酸铵溶于  $1000\mathrm{mL}$  水中，超声  $15\mathrm{min}$  ，现用现配。

5.8  $\alpha$  - 六溴环十二烷  $\mathrm{C_{12}H_{18}Br_6}$  ，CAS号：134237- 50- 6）标准储备液：  $100\mathrm{mg / L}$  ，使用经国家颁发的一级/二级标准物质或样品证书的标准物质或样品的标准溶液。

5.9  $\beta$  - 六溴环十二烷  $\mathrm{C_{12}H_{18}Br_6}$  ，CAS号：134237- 51- 7）标准储备液：  $100\mathrm{mg / L}$  ，使用经国家颁发的一级/二级标准物质或样品证书的标准物质或样品的标准溶液。

5.10  $\gamma$  - 六溴环十二烷  $\mathrm{C_{12}H_{18}Br_6}$  ，CAS号：134237- 52- 8）标准储备液：  $100\mathrm{mg / L}$  ，使用经国家颁发的一级/二级标准物质或样品证书的标准物质或样品的标准溶液。

5.11 微球状硅藻土。

5.12 注射器：  $2\mathrm{mL}$  。

5.13 针头过滤器：  $0.22\mu \mathrm{m}$  ，有机相。

5.14 刻度离心管：  $10\mathrm{mL}$  ，玻璃材质。

5.15 硅胶固相萃取柱：  $500\mathrm{mg},6\mathrm{mL}$  ，活化后使用。

5.16 氮气：纯度  $>99.999\%$  。

5.17 氩气：纯度  $>99.999\%$  。

# 6 仪器设备

6.1 高效液相色谱- 质谱仪（HPLC- MS）：应配备电喷雾离子源  $\mathrm{ESI}^{- }$  。

6.2 破碎机：破碎粒径  $\leq 1\mathrm{mm}$  。

6.3 天平：精度为  $0.1\mathrm{mg}$  。

6.4 快速溶剂萃取仪。

6.5 旋转蒸发仪。

6.6 氮吹仪。

6.7 旋涡混匀器。

6.8 离心机：转速不小于  $12000\mathrm{r / min}$  。

# 7 样品前处理

# 7.1 试样制备

样品经液氮冷冻后，使用破碎机（6.2）粉碎，若样品具有韧性不易粉碎，可使用干净的剪刀等工具将其尽可能剪碎，混合均匀，置于洁净、干燥的容器中，室温下保存，备用。

# 7.2 提取净化

# 7.2.1 溶剂萃取

称取经粉碎混匀的试样  $0.5\mathrm{g}$ ，精确到  $0.1\mathrm{mg}$ ，将样品与微球状硅藻土（5.11）混合均匀后置于萃取罐内，进行快速溶剂萃取。以丙酮- 正己烷溶液（5.5）为萃取剂，样品池温度为  $120^{\circ}\mathrm{C}$ ，压力为  $10\mathrm{MPa}$ ，热平衡时间  $5\mathrm{min}$ ，静态萃取时间  $10\mathrm{min}$ ，淋洗体积为  $50\%$ ，氮气吹扫时间  $1\mathrm{min}$ ，循环次数为3次。待溶液冷却后，用旋转蒸发仪（6.5）浓缩萃取液至  $1\mathrm{mL}$ 。

# 7.2.2 净化

向硅胶固相萃取柱（5.15）上层装填约  $100\mathrm{mg}44\%$  酸性硅胶（5.6），依次用  $4\mathrm{mL}$  正己烷和  $4\mathrm{mL}$  二氯甲烷活化萃取柱，取浓缩后的萃取液过柱，用  $8\mathrm{mL}$  正己烷淋洗萃取柱，弃掉淋洗液，再用  $8\mathrm{mL}$  二氯甲烷洗脱萃取柱，接取洗脱液，将其氮吹浓缩至近干，加入甲醇定容至  $1\mathrm{mL}$ ，涡旋振荡  $1\mathrm{min}$ ，经注射器（5.12）和针头过滤器（5.13）过滤或  $12000\mathrm{r / min}$  离心  $5\mathrm{min}$ ，取过滤液或上清液，待测。

# 7.3 空白试验

除不加试样外，其他步骤同样品试液的制备及测定一致。

# 8.2 定量分析

# 8.2.1 标准曲线绘制

用甲醇(5.1)逐级稀释标准便备溶液  $(5.8\sim 5.10)$  ，配制成  $\alpha ,\gamma$  - 六溴环十二烷质量浓度依次为 $0.1\mathrm{mg / L}$  ，  $0.2\mathrm{mg / L}$ $0.5\mathrm{mg / L}$ $1\mathrm{mg / L}$ $2\mathrm{mg / L}$ $5\mathrm{mg / L}$ $10\mathrm{mg / L}$ $\beta$  - 六溴环十二烷质量浓度依次为 $0.02\mathrm{mg / L}$ $0.04\mathrm{mg / L}$ $0.1\mathrm{mg / L}$ $0.2\mathrm{mg / L}$ $0.4\mathrm{mg / L}$ $1\mathrm{mg / L}$ $2\mathrm{mg / L}$  的系列混合标准工作溶液，现用现配。

按8.1高效液相色谱- 质谱仪分析条件，由低到高依次测定标准工作溶液，以定量离子峰面积和浓度绘制标准工作曲线，得到标准工作曲线回归方程，标准工作曲线的线性相关系数应不小于0.990。

注：根据不同仪器灵敏度、待测目标物含量调整标准曲线的质量浓度。

# 8.2.2 定量测定

按照建立标准工作曲线的高效液相色谱- 质谱分析条件，测定按7.2制备的试样溶液，根据峰面积，从标准曲线上计算出相应六溴环十二烷的质量浓度  $(\mathrm{mg / L})$  。

试液中目标化合物响应值应在标准曲线的线性范围内，超出标准工作曲线最大浓度点，用甲醇稀释后再进行测定。当六溴环十二烷含量过低时，可适当增加称样量，至少达到3倍的检出限。样品测定时，应增设标线质量控制点，同时测定平行样和空白试液，且数量不少于待测试样的  $5\%$  ，平行样不少于2份。

# 9 结果计算

试样中六溴环十二烷的含量以质量分数计，单位为毫克每千克  $(\mathrm{mg / kg})$  ，按式(1)分别计算样品中 $\alpha ,\beta ,\gamma$  - 六溴环十二烷的含量，按式(2)计算样品中六溴环十二烷总量  $(\alpha ,\beta ,\gamma$  - 六溴环十二烷之和)。

$$
X_{i} = \frac{(\rho_{i} - \rho_{i0})\times V\times D}{m} \tag{1}
$$

$$
X = X_{\alpha} + X_{\beta} + X_{\gamma} \tag{2}
$$

式中：

$X_{i}$  ——样品中各六溴环十二烷同分异构体的含量，其中  $X_{\alpha}$  为样品中  $\alpha$  - 六溴环十二烷的含量、  $X_{\beta}$  为样品中  $\beta$  - 六溴环十二烷的含量、  $X_{\gamma}$  为样品中  $\gamma$  - 六溴环十二烷的含量，单位为毫克每千克  $(\mathrm{mg / kg})$  ； $\rho_{i}$  ——试液中六溴环十二烷同分异构体的含量，单位为毫克每升  $(\mathrm{mg / L})$  ； $\rho_{i0}$  ——空白试液中六溴环十二烷同分异构体的含量，单位为毫克每升  $(\mathrm{mg / L})$  ； $V$  ——定容体积，单位为毫升  $(\mathrm{mL})$  ； $D$  ——稀释倍数； $m$  ——样品质量，单位为克  $(\mathrm{g})$  ； $X$  ——样品中六溴环十二烷的总量，单位为毫克每千克  $(\mathrm{mg / kg})$  。计算结果保留3位有效数字。

# 10 方法检出限及定量限

本方法对消费品中  $\alpha ,\beta ,\gamma$  - 六溴环十二烷的测定时，三种同分异构体的检出限为  $10.0\mu \mathrm{g / kg}$  ，定量限为  $30.0\mu \mathrm{g / kg}$  。

# 11 精密度

在重复性条件下获得的2次独立测定结果的绝对差值不应超过算术平均值的  $15\%$ 。
