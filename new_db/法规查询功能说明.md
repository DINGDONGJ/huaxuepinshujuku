# 法规查询功能说明 ⚖️

## 📋 功能概述

在化学品详情页面新增了**法规查询按钮**，点击后自动跳转到[化学品安全法规网站](https://law.chemicalsafety.org.cn)，查询该化学品相关的法律法规信息。

---

## ✨ 功能特点

### 1. 一键查询
- 🔘 点击"法规查询"按钮
- 🌐 自动在新窗口打开法规查询网站
- 🔍 自动填充当前化学品名称进行搜索

### 2. 智能匹配
- ✅ 自动URL编码化学品名称
- ✅ 支持中文化学品名称
- ✅ 支持特殊字符（如括号、方括号等）

### 3. 用户体验
- 💫 渐变紫色按钮，美观专业
- 🎯 新窗口打开，不影响当前操作
- 📱 响应式设计，支持移动端
- 💡 操作提示，实时反馈

---

## 🎯 使用方法

### 步骤1：查询化学品
在搜索框输入化学品名称（如"乙醇"、"甲苯"），点击"查询"按钮。

### 步骤2：点击法规查询
在化学品详情页面，化学品名称右侧有两个按钮：
- **法规查询**（紫色渐变按钮）
- **删除化学品**（红色按钮）

点击"法规查询"按钮。

### 步骤3：查看法规信息
系统会自动在新窗口打开化学品安全法规网站，并显示该化学品的相关法规信息。

---

## 🌐 关于化学品安全法规网站

### 网站信息
- **网址**：https://law.chemicalsafety.org.cn
- **主办单位**：中国化学品安全协会
- **功能**：提供化学品相关法律法规查询服务

### 可查询的法规类型
1. **危险化学品管理**
   - 危险化学品目录
   - 危险化学品安全管理条例
   
2. **易制爆危险化学品**
   - 易制爆危险化学品名录
   - 管理规定

3. **易制毒化学品**
   - 易制毒化学品管理条例
   - 分类管理目录

4. **重点监管化学品**
   - 首批、第二批重点监管危险化学品名录
   
5. **进出口管理**
   - 进出口许可要求
   - 海关监管规定

6. **环保法规**
   - 污染物排放标准
   - 危险废物管理

## 💻 技术实现

### 前端代码

#### HTML按钮
```html
<button class="regulation-query-btn" onclick="queryRegulation('化学品名称')">
    <i class="fas fa-gavel"></i> 法规查询
</button>
```

#### JavaScript函数
```javascript
function queryRegulation(chemicalName) {
    // 对化学品名称进行URL编码
    const encodedName = encodeURIComponent(chemicalName);
    
    // 构建法规查询网站URL
    const regulationUrl = `https://law.chemicalsafety.org.cn/compliance/guild/customer/SearchAllCustomer.jsp?moduleId=2&type=all&keyContent=${encodedName}`;
    
    // 在新窗口打开法规查询页面
    window.open(regulationUrl, '_blank');
    
    // 显示提示信息
    showNotification(`正在查询"${chemicalName}"的相关法规...`, 'info');
}
```

#### CSS样式
```css

    gap: 6px;
}

.regulation-query-btn:hover {
    transform: translateY(-2px);
    box-shadow: 0 4px 12px rgba(102, 126, 234, 0.4);
}
```

## 🔧 自定义配置

### 修改查询参数

如果需要修改查询参数，可以在`queryRegulation`函数中调整URL：

```javascript
// 修改moduleId参数
const regulationUrl = `https://law.chemicalsafety.org.cn/compliance/guild/customer/SearchAllCustomer.jsp?moduleId=1&type=all&keyContent=${encodedName}`;

// 修改type参数
const regulationUrl = `https://law.chemicalsafety.org.cn/compliance/guild/customer/SearchAllCustomer.jsp?moduleId=2&type=exact&keyContent=${encodedName}`;
```

### 修改按钮样式

可以在CSS中调整按钮颜色、大小等：

```css
.regulation-query-btn {
    background: linear-gradient(135deg, #4CAF50 0%, #45a049 100%); /* 绿色渐变 */
    padding: 10px 20px; /* 更大的按钮 */
    font-size: 14px; /* 更大的字体 */
}
```

## ⚠️ 注意事项

1. **网络连接**
   - 需要互联网连接才能访问法规网站
   - 建议在良好的网络环境下使用

2. **浏览器兼容性**
   - 支持所有现代浏览器（Chrome、Firefox、Safari、Edge等）
   - 需启用JavaScript和弹出窗口

3. **查询结果**
   - 法规网站可能需要登录才能查看详细信息
   - 部分法规可能需要付费订阅
   - 查询结果的准确性和时效性以官方网站为准

4. **数据保护**
   - 仅传输化学品名称信息
   - 不涉及用户隐私数据
   - 符合数据安全规范
