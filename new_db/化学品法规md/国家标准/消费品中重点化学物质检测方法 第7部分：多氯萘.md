# 引言

近年来，随着新材料新工艺在消费品领域的广泛应用，产品中潜在的化学物质安全问题逐渐凸显，引起了国内外社会各界的高度关注。我国针对消费品中化学物质管控需求制定了一系列标准，同时与之配套的科学、高效、精准检测方法是管控化学物质的关键。

GB/T44165《消费品中重点化学物质检测方法》旨在针对消费品中高风险化学物质，提供规范的检测方法，拟由9个部分构成。

——第1部分：短链氯化石蜡。目的在于提供消费品中短链氯化石蜡含量的测定方法。——第2部分：苯乙烯迁移量。目的在于提供消费品中苯乙烯迁移量的测定方法。——第3部分：氯代乙烷。目的在于提供消费品中氯代乙烷含量的测定方法。——第4部分：1，4- 二氯苯。目的在于提供消费品中1，4- 二氯苯含量的测定方法。——第5部分：苯酚。目的在于提供消费品中苯酚含量的测定方法。——第6部分：丙烯酰胺。目的在于提供消费品中丙烯酰胺含量的测定方法。——第7部分：多氯萘。目的在于提供消费品中多氯萘含量的测定方法。——第8部分：全氟辛烷磺酸（PFOS）和全氟辛酸（PFOA）。目的在于提供消费品中全氟辛烷磺酸（PFOS）和全氟辛酸（PFOA）含量的测定方法。——第9部分：六溴环十二烷。目的在于提供消费品中六溴环十二烷含量的测定方法。

# 消费品中重点化学物质检测方法第7部分：多氯萘

# 1范围

本文件描述了消费品中多氯萘的同位素稀释高分辨气相色谱- 高分辨质谱法测定方法。

本文件适用于含纺织、塑料等材料的消费品中25种多氯萘同类物的测定，分别为CN2、CN3、CN5、CN6、CN9、CN13、CN27、CN28、CN31、CN36、CN42、CN46、CN48、CN50、CN52、CN53、CN54、CN66、CN67、CN68、CN69、CN70、CN72、CN73、CN75。

消费品中其他材质产品经过验证后参照本文件进行测定。

# 2 规范性引用文件

本文件没有规范性引用文件。

# 3术语和定义

下列术语和定义适用于本文件。

3.1

# 消费品 consumer product

主要但不限于为个人使用而设计、生产的产品。注：包含产品的组件、零部件、附件、使用说明和包装。消费品分类详见GB/T36431。[来源：GB/T35248—2017，2.2，有修改]

3.2

# 多氯萘 polychlorinated naphthalenes;PCNs

一类基于萘环上的氢原子被氯原子所取代的化合物的总称。

# 4原理

用正己烷- 二氯甲烷混合溶剂提取样品中的多氯萘，浓缩、净化后，采用高分辨气相色谱- 高分辨质谱分离检测，根据保留时间和监测离子丰度比定性，采用同位素稀释法定量。

5.18 二氯甲烷- 正己烷混合溶液  $(1:19)$  ：用二氯甲烷(5.4)和正己烷(5.5)按  $1:19$  的体积比混合。

5.19 活化硅胶：层析用硅胶，粒径为  $74\mu \mathrm{m}\sim 150\mu \mathrm{m}$  (100目  $\sim 200$  目)，使用前，置于马弗炉内在  $550^{\circ}$  烘烤  $6\mathrm{h}$  ，冷却至室温后，放入三角瓶中保存于干燥器中备用，使用期限不超过一周为宜。

5.20 酸性硅胶  $(44\%)$  ：取  $43\mathrm{mL}$  浓硫酸缓慢均匀滴加到  $100\mathrm{g}$  活化硅胶中，每次取约  $5\mathrm{mL}$  逐滴加入，快速振荡摇匀至无颗粒团聚，密封保存于干燥器中。

5.21 碱性硅胶  $(33\%)$  ：取  $1.0\mathrm{g}$  氢氧化钠溶于  $25\mathrm{mL}$  试验用水中，缓慢加入到  $50\mathrm{g}$  活化硅胶(5.19)中，每次取约  $5\mathrm{mL}$  逐滴加入，快速振荡摇匀至均匀无颗粒团聚，平衡  $0.5\mathrm{h}$  后可用，或密封保存于干燥器中。

5.22 碱性氧化铝：使用前将碱性氧化铝置于干净坩埚中，置于马弗炉内在  $660^{\circ}$  烘烤  $6\mathrm{h}\sim 7\mathrm{h}$  ，待温度冷却到  $150^{\circ}$  时，转移到干燥器中自然冷却，待完全冷却至室温后，密封保存于干燥器。

5.23 硝酸银硅胶：将  $5.6\mathrm{g}$  硝酸银(5.3)溶解在  $21.5\mathrm{mL}$  去离子水中，逐滴加入到  $50\mathrm{g}$  活化硅胶(5.19)中，充分振荡均匀，置于  $30^{\circ}$  烘箱烘烤  $5\mathrm{h}$  后，升温至  $180^{\circ}$  至少烘烤  $12\mathrm{h}$  ，密封保存，使用前制备。

5.24 无水硫酸钠  $\mathrm{(Na_2SO_4)}$  ：优纯级，使用前将无水硫酸钠置干净坩埚中，置于马弗炉内  $600^{\circ}$  下烘烤  $6\mathrm{h}$  以上，冷却至室温后，密封保存于干燥器中。

5.25 石英棉：  $1\mu \mathrm{m}\sim 3\mu \mathrm{m}$  石英纤维棉。

5.26 滤膜：石英纤维滤膜，可直接购买市售商品。

# 6 仪器设备

6.1 高分辨气相色谱仪- 高分辨质谱仪：配电子轰击离子源(EI)源。6.2 加速溶剂萃取仪：具备加热、加压等功能，加热温度、萃取时间、萃取压力等参数可调节，或具有同等功能的其他提取装置。6.3 索氏提取器：用于提取固态样品(非粉末状)中的多氯萘，容积  $500~\mathrm{mL}$ 。6.4 玻璃层析柱： $30.0\mathrm{cm}\times 1.5\mathrm{cm}$  内径玻璃柱和  $20.0\mathrm{cm}\times 0.8\mathrm{cm}$  内径玻璃柱。6.5 浓缩装置：旋转蒸发仪，氮气浓缩仪。或其他性能相当浓缩装置。6.6 储液器：容积  $500~\mathrm{mL}$ 。6.7 茄型瓶： $250~\mathrm{mL}$ 。所有的玻璃器皿在使用前均需用去离子水冲洗，置于烘箱中在  $120^{\circ}\mathrm{C}$  下烘干，再依次用无水甲醇(5.8)、丙酮(5.7)和二氯甲烷(5.4)分别润洗3次。6.8 抽提纸筒： $2.5\mathrm{cm}\times 9\mathrm{cm}$ 。6.9 超声波清洗器：功率为  $250\mathrm{W}$ ，频率为  $53\mathrm{kHz}$ ，或相当者。6.10 电子天平：精度  $0.1\mathrm{mg}$ 。6.11 粉碎设备：粉碎机、剪刀或其他合适的粉碎设备。6.12 烘箱：调温范围为  $50^{\circ}\mathrm{C}\sim 200^{\circ}\mathrm{C}$ 。

# 7 样品前处理

# 7.1 试样制备

# 7.1.1 纺织品类试样制备

取代表性试样剪成约  $5\mathrm{mm}\times 5\mathrm{mm}$  的小片混合。称取约  $10.0\mathrm{g}$ ，精确至  $0.001\mathrm{g}$ 。

# 7.1.2 塑料类试样制备

取代表性试样剪成约  $5\mathrm{mm}\times 5\mathrm{mm}$  的小片混合。试样研磨机粉碎样品至最大粒径不大于  $1\mathrm{mm}$ 。称取约  $10.0\mathrm{g}$ ，精确至  $0.001\mathrm{g}$ 。

研磨步骤的选择取决于样品的物理性质。如果样品在剪成小片后已满足分析要求，或者研磨可能会改变样品的某些性质（如化学组成、结构等），则可以选择不进行研磨。

# 7.1.3 空白试样制备

将  $10.0\mathrm{g}$  无水硫酸钠(5.24)代替实际样品，置于样品容器中并按照与实际样品一致的程序进行测定。

# 7.2 提取净化

# 7.2.1 萃取

# 7.2.1.1 塑料类样品

7.2.1.1.1 提取前将加速溶剂萃取仪配套的萃取池用二氯甲烷- 正己烷混合溶液  $(1:1)$  进行清洗。

7.2.1.1.2 根据估计的污染水平，称取  $10.0\mathrm{g}$  经过预处理的样品(7.1)（精确到  $0.001\mathrm{g}$ ）置于研钵中，加入硅藻土以  $1 / 3$  或者  $1 / 4$  混匀，装入装有滤膜的萃取池中，在萃取池中加入  $10\mu \mathrm{L}^{13}\mathrm{C}$  同位素标记提取内标(5.14)，密闭后，放于萃取仪上进行萃取，加速溶剂萃取仪提取温度为  $120^{\circ}\mathrm{C}$ ，提取压力为

10.34 MPa(约1500 psi)，静态提取时间为  $15\mathrm{min}$ ，加热时间为  $6\mathrm{min}$ ，提取溶剂为二氯甲烷- 正己烷混合溶液  $(1:1)$ ，溶剂提取量为  $70\%$ ，循环次数为3次，吹扫捕集时间为  $100\mathrm{s}$ 。每个样品所对应的硅藻土用量取决于所应用的萃取池体积和所称取的该样品研磨后的体积。

7.2.1.1.3 将提取液转移至茄形瓶中，旋转蒸发至近干，加入少量正己烷(5.5)溶解以备下一步净化。

# 7.2.1.2 纺织品类样品

7.2.1.2.1 组装索氏提取装置，使用  $250\mathrm{mL}$  甲苯(5.10)空提  $8\mathrm{h}$ ，润洗整套索提装置。

7.2.1.2.2 称取  $10.0\mathrm{g}$  经过预处理的样品(7.1)（精确到  $0.001\mathrm{g}$ ）放入抽屉纸筒中，加入  $10\mu \mathrm{L}$  “C”同位素标记提取内标(5.14)。将抽屉纸筒装入索氏提取器的提取管。接收瓶加入  $250\mathrm{mL}$  甲苯(5.10)溶液。提取管上下部分分别于冷凝管和接收瓶链接好，接入冷却水，在加热套中加热样品和溶剂，使溶剂蒸发并冷凝回流以确保提取过程的连续性。索提时间为  $8\mathrm{h}$ 。

7.2.1.2.3 将提取液转移至茄形瓶中，旋转蒸发至近干，加入少量正己烷(5.5)溶解以备下一步净化。

# 7.2.2 净化

# 7.2.2.1 酸性硅胶柱净化

7.2.2.1.1 取规格为  $30.0\mathrm{cm}\times 1.5\mathrm{cm}$  内径玻璃柱，自下至上依次填充：适量石英棉(5.25)、 $1\mathrm{g}$  活化硅胶(5.19)、 $8\mathrm{g}44\%$  酸性硅胶(5.20)、 $1\mathrm{g}$  活化硅胶(5.19)、高度为  $1\mathrm{cm}\sim 2\mathrm{cm}$  的无水硫酸钠(5.24)。

7.2.2.1.2 用  $70\mathrm{mL}$  正己烷(5.5)预淋洗层析柱，上样，润洗3次，用  $90\mathrm{mL}$  正己烷(5.5)洗脱。将洗脱液旋转蒸发至  $1\mathrm{mL}\sim 2\mathrm{mL}$ 。

# 7.2.2.2 复合硅胶柱净化

7.2.2.2.1 取规格为  $30.0\mathrm{cm}\times 1.5\mathrm{cm}$  内径玻璃柱，自下至上依次填充：适量石英棉(5.25)、 $1\mathrm{g}$  活化硅胶(5.19)、 $2\mathrm{g}$  硝酸银硅胶(5.23)、 $1\mathrm{g}$  活化硅胶(5.19)、 $3\mathrm{g}$  碱性硅胶(5.21)、 $1\mathrm{g}$  活化硅胶(5.19)、 $8\mathrm{g}44\%$  酸性硅胶(5.20)、 $1\mathrm{g}$  活化硅胶(5.19)、高度为  $1\mathrm{cm}\sim 2\mathrm{cm}$  的无水硫酸钠(5.24)。7.2.2.2.2 用  $70\mathrm{mL}$  正己烷(5.5)预淋洗，加入7.2.2.1处理后样品，润洗3次，用  $90\mathrm{mL}$  正己烷(5.5)洗脱。将洗脱液旋转蒸发至  $1\mathrm{mL}\sim 2\mathrm{mL}$ 。

# 8.3.3.2 色谱峰检出

在色谱图上，高度为基线振幅3倍以上的色谱峰视为有效峰。在峰的附近（半高宽的10倍以内）测量噪声，测量值标准偏差的2倍作为噪声值  $N$  ，一般经验认为噪声最大值和最小值的差约为噪声值标准偏差的5倍，因此也可以取噪声最大值和最小值之差的2/5作为噪声值  $N$  。以噪声中线为基准，到峰顶的高度为峰高（信号  $S$  ）。对信噪比  $S / N = 3$  以上的色谱峰进行定性，10倍以上的色谱峰进行定量。

# 9 结果计算

# 9.1 相对响应因子的计算

提取内标的相对响应因子（  $\mathrm{RRF_{cs}}$  )按照公式（1)计算。

$$
\mathrm{RRF_{cs}} = \frac{(A_{1s} + A_{2s})Q_{cs}}{(A_{1cs} + A_{2cs})Q_s} \tag{1}
$$

式中：

$\mathrm{RRF_{cs}}$  提取内标的相对响应因子； $A_{1s}$  和  $A_{2s}$  标准溶液中目标化合物的定量和定性离子的峰面积； $A_{1cs}$  和  $A_{2cs}$  标准溶液中提取内标的定量和定性离子峰面积； $Q_{cs}$  标准溶液中提取内标的质量，单位为纳克  $(\mathrm{ng})$  ； $Q_{s}$  标准溶液中目标化合物的质量，单位为纳克  $(\mathrm{ng})$  。

进样内标的相对响应因子（  $\mathrm{RRF_{rs}}$  )按照公式（2）计算。

$$
\mathrm{RRF_{rs}} = \frac{(A_{1cs} + A_{2cs})Q_{rs}}{(A_{1rs} + A_{2rs})Q_{cs}} \tag{2}
$$

式中：

$\mathrm{RRF_{rs}}$  进样内标的相对响应因子； $A_{1cs}$  和  $A_{2cs}$  标准溶液中提取内标的定量和定性离子峰面积； $A_{1rs}$  和  $A_{2rs}$  标准溶液中进样内标的定量和定性离子峰面积； $Q_{rs}$  标准溶液中进样内标的质量，单位为纳克  $(\mathrm{ng})$  ； $Q_{cs}$  标准溶液中提取内标的质量，单位为纳克  $(\mathrm{ng})$  。

# 9.2 提取内标回收率的计算

提取内标回收率按照公式（3）计算。

$$
R_{\mathrm{c}} = \frac{(A_{\mathrm{1csi}} + A_{\mathrm{2csi}})}{(A_{\mathrm{1rs}} + A_{\mathrm{2rs}})}\times \frac{Q_{\mathrm{rs}}}{\mathrm{RRF}_{\mathrm{rs}}}\times \frac{100}{Q_{\mathrm{csi}}}
$$

式中：

$R_{c}$  试样中提取内标  $i$  的回收率，  $\%$ $A_{\mathrm{1csi}}$  和  $A_{\mathrm{2csi}}$  试样中提取内标  $i$  的定量和定性离子的峰面积； $A_{\mathrm{1rs}}$  和  $A_{\mathrm{2rs}}$  试样中进样内标  $i$  定量和定性离子峰面积； $Q_{\mathrm{rs}}$  试样中进样内标的质量，单位为纳克  $(\mathrm{ng})$ $Q_{\mathrm{csi}}$  试样中提取内标  $i$  的质量，单位为纳克  $(\mathrm{ng})$ $\mathrm{RRF}_{\mathrm{rs}}$  进样内标的相对响应因子。

# 9.3 目标化合物质量计算

试样中被检出的多氯萘同类物的质量按照公式（4）计算。

$$
Q_{i} = \frac{(A_{1i} + A_{2i})}{(A_{1csi} + A_{2csi})}\times \frac{Q_{csi}}{\mathrm{RRF}_{cs}}
$$

式中：

$Q_{i}$  试样中多氯萘同类物  $i$  质量，单位为纳克  $(\mathrm{ng})$ $A_{\mathrm{1i}}$  和  $A_{\mathrm{2i}}$  多氯萘同类物  $i$  的定量和定性离子的峰面积； $A_{\mathrm{1csi}}$  和  $A_{\mathrm{2csi}}$  相应提取内标  $i$  的定量和定性离子的峰面积； $Q_{\mathrm{csi}}$  相应提取内标  $i$  的质量，单位为纳克  $(\mathrm{ng})$ $\mathrm{RRF}_{\mathrm{cs}}$  提取内标的平均相对响应因子。

# 9.4 消费品中目标化合物含量计算

消费品中多氯萘同类物  $i$  的含量按照公式（5）计算。

$$
C_i = \frac{Q_i}{M}
$$

（5）

式中：

$C$  消费品中多氯萘同类物  $i$  含量，单位为纳克每克  $(\mathrm{ng} / \mathrm{g})$ $Q_{i}$  消费品中多氯萘同类物  $i$  质量，单位为纳克  $(\mathrm{ng})$ $M$  消费品质量，单位为克  $(\mathrm{g})$  。计算结果保留3位有效数字。
