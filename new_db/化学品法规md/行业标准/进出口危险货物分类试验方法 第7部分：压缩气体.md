# 进出口危险货物分类试验方法第7部分:压缩气体

警告:由于自身危险性,测试试验室应对法规要求的健康和安全要求,引起特别的重视。

# 1范围

SN/T1828的本部分规定了进出口压缩气体危险货物的试验和类别判定。

本部分适用于临界温度小于或等于  $- 50^{\circ}\mathrm{C}$  的进出口压缩气体危险货物危险特性的试验。

# 3术语和定义

《关于危险货物运输的建议书规章范本》界定的以及下列术语和定义适用于本文件。

3.1

压缩气体 compressed gases

在  $- 50^{\circ}\mathrm{C}$  下加压包装供运输时完全是气态的气体,包括临界温度小于或等于  $- 50^{\circ}\mathrm{C}$  的所有气体。

试验方法见SN/T1828.12的规定。

# 4.2 毒性试验

试验方法见SN/T1828.10的规定。

# 4.3 压缩气体的判别

判别流程见附录A图A.1。

# 5类别判定

根据SN/T1828.5的规定,将压缩气体分类为2.1项易燃气体、2.2项非易燃无毒气体和2.3项毒性气体,其中2.3项优于其他项别,2.1项优于2.2项。
