# 前言

工业炸药爆炸后的有毒气体含量是保障采矿安全作业的重要指标，需要实行严格的试验和检测。本标准是在WJ1977—1990《工业炸药爆炸后有毒气体含量测定法》和MT60—1995《煤矿许用炸药爆炸后有毒气体量测定方法和判定规则》的基础上，按GB/T1系列标准的要求制定的。

本标准由国防科学技术工业委员会提出。

本标准由中国兵器工业标准化研究所归口。

本标准起草单位：国家民用爆破器材质量监督检验中心、全国民用爆破器材产品长沙质量监督检验站、煤炭工业淮北爆破器材产品质量监督检验中心、国家煤矿防爆安全产品质量监督检验中心、中国兵器工业标准化研究所。

本标准主要起草人：吴维勤、李建湘、倪欧琪、夏斌、段贤、杨金侠、郑秀英。

# 3 方法提要

在一定的条件下,使一定量的炸药在一定容积的爆炸弹筒中爆炸,制得炸药爆炸后的气体试样,分别测定其中一氧化碳和氮氧化物的含量,再换算成有毒气体的总含量。

# 4 气体试样的制备

# 4.1 方法一(仲裁法)

4.1.1 试剂和材料

a) 雷管: GB/T 8031, 8 号金属壳瞬发电雷管;

b) 石英砂: 二氧化硅含量不低于  $90\%$ , 粒度为  $0.40 \mathrm{mm} \sim 0.63 \mathrm{mm}$ 。

4.1.2 仪器、装置

4.1.2.1 仪器

a) 动槽水银压力计: 测量精度为  $0.04 \mathrm{kPa}$ ;

b) 温度计: 分度值为  $0.2^{\circ} \mathrm{C}$ ;

c) 天平: 感量为  $0.5 \mathrm{~g}$ ;

d) 采样器: 采样瓶、球胆等。

4.1.2.2 制备装置

气体试样制备装置(1) 示意图见图 1。

a) 爆炸弹筒: 外径为  $600 \mathrm{~mm}$  、内径为  $350 \mathrm{~mm}$  、内部深度为  $550 \mathrm{~mm}$  的钢制圆筒;

b) 钢炮: 外径为  $240 \mathrm{~mm}$  、高为  $300 \mathrm{~mm}$  的圆柱体, 其中心孔直径为  $45 \mathrm{~mm}$  、深度为  $200 \mathrm{~mm}$ ;

c) 真空泵;

d) 压力表: 测量范围为  $0 \mathrm{MPa} \sim 0.1 \mathrm{MPa}, 1.5$  级;

e) 真空表: 1.5 级;

f) U 型水银压差计: 分度值为  $0.133 \mathrm{kPa}$ 。

4.1.3 制备步骤

4.1.3.1 检查制备装置, 爆炸弹筒内壁应洁净, 接线柱上应无灰尘和锈垢, 各阀门应通畅。

4.1.3.2 称取  $110.0 \mathrm{~g} \pm 0.5 \mathrm{~g}$  原装药卷 (直径大于  $35 \mathrm{~mm}$  的, 应改装成直径为  $35 \mathrm{~mm}$  ), 将雷管插入药卷中央, 插入深度为雷管全长的  $2 / 3$ , 然后装入钢炮内孔中。再称取  $300.0 \mathrm{~g} \pm 0.5 \mathrm{~g}$  石英砂, 自然充填在药卷周围与上部, 雷管脚线分别接在两个接线柱上。

4.1.3.3 盖紧爆炸弹筒盖, 启动真空泵抽气, 至爆炸弹筒内剩余压力不大于  $4.0 \mathrm{kPa}$  时, 停止抽气。

# 5 有毒气体含量的测定

5.1 一氧化碳含量的测定

5.1.1 化学吸收法(仲裁法)

5.1.1.1 原理

气体试样中,二氧化碳用氢氧化钾溶液吸收,氧气用焦性没食子酸溶液吸收,一氧化碳用氯化亚铜氮溶液吸收,测定其前后的体积变化即可计算出一氧化碳的体积分数。

5.1.1.2 试剂和材料

a)铜屑:紫铜屑;

b)液体石蜡;

c)焦性没食子酸;

d)甲基橙;

e)氢氧化钾溶液:用氢氧化钾(GB/T2396)配制成质量分数为  $25\% \sim 33\%$  的溶液;

f)氯化亚铜氨溶液:称取约  $250\mathrm{g}$  氯化铵(GB/T658)溶于  $750~\mathrm{mL}$  水中,加入约  $200\mathrm{g}$  氯化亚铜(HG/T3—1287)充分搅拌后,加入约等于溶液体积  $1 / 8$  的氨水(GB/T631),再加入  $2\mathrm{g} \sim 3\mathrm{g}$  铜屑和一层厚  $2\mathrm{cm} \sim 3\mathrm{cm}$  的液体石蜡;

g)焦性没食子酸钾溶液:称取约  $28\mathrm{g}$  焦性没食子酸,溶于  $50~\mathrm{mL}$  热水中,冷却后,加入  $130~\mathrm{mL}$  氢氧化钾溶液;

h)硫酸溶液:用硫酸(GB/T625)配制成质量分数为  $10\%$  的溶液;

i)甲基橙溶液:用甲基橙配制成质量分数为  $0.2\%$  的溶液;

j)封闭液:用硫酸溶液加氯化钠(GB/T1266)配制成饱和溶液,再加几滴甲基橙溶液。

5.1.1.3 仪器和设备

气体分析仪示意图见图3。

5.1.1.4 试验步骤

5.1.1.4.1 在吸收瓶1中注满氢氧化钾溶液,吸收瓶2中注满焦性没食子酸钾溶液,吸收瓶3中注满氯化亚铜氨溶液,吸收瓶4中注满硫酸溶液,并在各吸收瓶液面上放入液体石蜡。在水准瓶中注入封闭液,双臂量气管的水套中注入蒸馏水。

5.1.1.4.2 按气体分析仪操作说明,检查测定系统是否漏气。

5.1.1.4.3 向双臂量气管中通入  $100.0\mathrm{mL}\pm 0.1\mathrm{mL}$  气体试样。

5.1.1.4.4 将双臂量气管中的气体试样依次压入吸收瓶1和吸收瓶2中,分别进行反复吸收,直至将二氧化碳和氧气吸收完全后,再压入吸收瓶3中吸收一氧化碳,压入吸收瓶4中除去氨气,测量吸收后剩余气体的体积。

5.1.1.5 试验结果的表述

气体试样中一氧化碳含量按式(1)计算。

$$
\phi_{1} = \frac{V_{1} - V_{2}}{V_{0}^{\prime}}\times 100 \tag{1}
$$

式中:  $\phi_{1}$  ——气体试样中一氧化碳的体积分数,  $\%$

$V_{1}$  ——通过吸收瓶3前的气体体积,  $\mathrm{mL}$

$V_{2}$  ——通过吸收瓶4后的气体体积,  $\mathrm{mL}$

$V_{0}^{\prime}$  ——气体试样的体积,  $\mathrm{mL}$

平行测定二次,允许差应不大于  $0.5\%$  ,取算术平均值作为结果,结果精确至  $0.1\%$

5.1.2 红外线气体分析器法

5.1.2.1原理

5.1.2.1 原理根据一氧化碳对一定波长红外光有特征吸收, 且一氧化碳含量与能量损失符合比耳定律, 用一氧化碳标准气校正, 直接测得结果。

5.1.2.2 试剂和材料

5.1.2.2 试剂和材料一氧化碳标准气: 标准气中一氧化碳含量应与被测组分中一氧化碳含量接近。

5.1.2.3 仪器和设备

红外线气体分析器: 精度应不低于  $0.1\%$  。

5.1.2.4 试验步骤

5.1.2.4.1 启动红外线气体分析器, 待其稳定后, 校正零点, 通入一氧化碳标准气校正满度。

5.1.2.4.2 向红外线气体分析器中通入一定量的气体试样, 测出一氧化碳的体积分数。

5.1.2.5 试验结果的表述

5.1.2.5 试验结果的表述平行测定二次, 允许差应不大于  $0.5\%$  , 取算术平均值作为结果, 结果精确至  $0.1\%$  。

5.1.3 气相色谱法

5.1.3.1 原理

5.1.3.1 原理不同物质在不同的两相(气、固或液)中具有不同的分配系数, 当两相作相对运动时, 这些物质在两相中反复进行多次分配, 从而使那些分配系数只有微小差异的组分产生很大的分离效果。

5.1.3.2 试剂和材料

5.1.3.2 试剂和材料a) 固定相:  $13\mathrm{X}$  分子筛, 孔径为  $0.15\mathrm{mm} \sim 0.20\mathrm{mm}$ ;b) 载气: 氩气, 纯度为  $99.99\%$ ;c) 一氧化碳标准气: 标准气中一氧化碳含量应与被测组分中一氧化碳含量接近。

5.1.3.3 仪器和设备

a）气相色谱仪；

b）色谱柱：内径为  $3\mathrm{mm}$  ，长为  $2\textrm{m}$  ，装填13X分子筛；

c）检测器：热导检测器；

d）色谱数据处理机：专用微机。

5.1.3.4 色谱条件

a）柱温：  $50^{\circ}C$

b）检测器温度：  $100^{\circ}C$

c）载气流量：  $20~\mathrm{mL / min}\sim 40~\mathrm{mL / min}$

d）柱前压：  $0.1\mathrm{MPa}$  0

5.1.3.5 试验步骤

5.1.3.5.1 按仪器说明书中的步骤开动气相色谱仪, 按色谱条件把气相色谱仪调到可用状态, 基线稳定后, 设置色谱数据处理机的工作参数。

5.1.3.5.2 向气相色谱仪中通入一氧化碳标准气三次, 求一氧化碳的校正因子(色谱数据处理机自动计算)。

5.1.3.5.3 向气相色谱仪中通入一定量的气体试样, 测出一氧化碳的含量及测定误差。

5.1.3.6 试验结果的表述

5.1.3.6 试验结果的表述平行测定三次, 允许差应不大于  $0.5\%$  , 取三次平行测定的算术平均值作为结果, 结果精确至  $0.1\%$  。

5.2 氮氧化物含量的测定

5.2.1 容量分析法(仲裁法)

5.2.1.1 原理

炸药爆炸气体中所含的氮氧化物主要是一氧化氮和二氧化氮。用过氧化氢将其中的一氧化氮氧化成二氧化氮,二氧化氮被水吸收形成酸,用标准碱溶液滴定。根据碱溶液消耗量,可计算出产物中氮氧化物的含量。

5.2.1.2 试剂和材料

a) 无水乙醇:GB/T678;

b) 十二烷基苯磺酸钠溶液:十二烷基苯磺酸钠的质量分数为  $1\%$

c) 过氧化氢溶液:质量分数为  $3\%$  ,用  $30\%$  过氧化氢(GB/T6684)配制;

d) 溴甲酚绿乙醇溶液:用溴甲酚绿(GB/T15349)配制成质量分数为  $0.1\%$  的溴甲酚绿乙醇溶液;

e) 甲基红乙醇溶液:用甲基红(HG/T3—95)配制成质量分数为  $0.2\%$  的甲基红乙醇溶液;

f) 氢氧化钠标准溶液:用氢氧化钠(GB/T629)配制成浓度为  $0.1\mathrm{mol / L}$  的氢氧化钠标准溶液;

g) 混合指示剂:由溴甲酚绿乙醇溶液和甲基红乙醇溶液按体积比  $3:1$  混合。

5.2.1.3 仪器和设备

采样瓶:  $1000\mathrm{mL}\sim 3000\mathrm{mL}$

5.2.1.4 试验步骤

5.2.1.4.1 在采样瓶中装入  $100\mathrm{mL}$  过氧化氢溶液和  $2\mathrm{mL}$  十二烷基苯磺酸钠溶液,将采样瓶抽真空至剩余压力不大于  $4.0\mathrm{kPa}$  时,充以  $1000\mathrm{mL}\sim 3000\mathrm{mL}$  气体试样,剧烈摇动  $10\mathrm{min}$  ,静放  $5\mathrm{min}\sim 10\mathrm{min}$  。

5.2.1.4.2 将采样瓶中的吸收液转移到  $500\mathrm{mL}$  锥形瓶中,用水冲洗采样瓶三次,加热煮沸,冷却到室温,加入  $2\sim 3$  滴混合指示剂,用  $0.1\mathrm{mol / L}$  氢氧化钠标准溶液滴定至绿色为终点。

5.2.1.5 试验结果的表述

气体试样中氮氧化物的含量按式(2)计算。

$$
\phi_{2} = \frac{22.4\times c_{1}\times V_{3}}{V_{0}^{\prime\prime}}\times 100\quad \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \tag{2}
$$

式中:  $\phi_{2}$  ——氮氧化物体积分数,  $\%$

$c_{1}$  ——氢氧化钠标准溶液的浓度,  $\mathrm{mol / L}$

$V_{3}$  ——滴定消耗的氢氧化钠标准溶液的体积,  $\mathrm{mL}$

$V_{0}^{\prime \prime}$  ——标准状况下气体试样的体积,  $\mathrm{mL}$

平行测定二次,允许差应不大于  $0.2\%$  ,取算术平均值作为结果,结果精确至  $0.01\%$  。

5.2.2 分光光度法

5.2.2.1 原理

炸药爆炸时,生成的氮氧化物是一氧化氮和二氧化氮。其中一氧化氮被空气中的氧氧化成二氧化氮,二氧化氮被氢氧化钠溶液吸收生成硝酸盐和亚硝酸盐,加入显色剂,显现出桃红色,根据显色程度与二氧化氮含量成正比,采用分光光度法可测得二氧化氮含量。

5.2.2.2 试剂和材料

a) 氢氧化钠溶液:用氢氧化钠(GB/T629)配制成浓度为  $0.1\mathrm{mol / L}$  的溶液;

b) 吸收液:将氢氧化钠溶液与无水乙醇(GB/T678)按  $1:2$  体积比混合配制;

c) 亚硝酸钠贮备溶液:称取  $0.1500\mathrm{g}\pm 0.0010\mathrm{g}$  亚硝酸钠(GB/T633),放入容积为  $1000\mathrm{mL}$  的容量瓶中,用蒸馏水稀释至刻度,摇匀,作为溶液A;用移液管吸取  $100\mathrm{mL}$  溶液A,转入另一容积为  $1000\mathrm{mL}$  的容量瓶中,再用蒸馏水稀释至刻度,摇匀,作为溶液B;

d) 亚硝酸钠标准溶液(  $1\mathrm{mL}$  该溶液含  $0.0015\mathrm{mg}\mathrm{NaNO}_{2}$  ,相当于  $0.002\mathrm{mg}\mathrm{NO}_{2}$  ):用移液管吸取  $10\mathrm{mL}$  亚硝酸钠贮备溶液(溶液B)转入  $100\mathrm{mL}$  容量瓶中,用吸收液稀释至刻度,摇匀;

e) 显色剂:将萘基盐酸二氨基乙烯(化学纯)、对氨基苯磺酰胺和酒石酸(GB/T1294)按  $1:4:95$  的质量比混合,在乳钵中研磨并混合均匀,装入棕色瓶中,置于干燥器内备用;

f) 显色剂溶液: 称取约  $30 \mathrm{~g}$  显色剂溶于  $100 \mathrm{~mL}$  质量分数为  $4 \%$  的磷酸(GB/T 1282)溶液中, 用时现配。

5.2.2.3 仪器和设备

a) 分析天平: 感量  $0.1 \mathrm{mg}$ ;

b) 移液管:  $10 \mathrm{~mL}, 25 \mathrm{~mL}$ ;

c) 刻度吸管:  $1 \mathrm{~mL}$  (最小分度值为  $0.01 \mathrm{~mL}$  )、  $5 \mathrm{~mL}$  (最小分度值为  $0.05 \mathrm{~mL}$  )、  $10 \mathrm{~mL}$  (最小分度值为  $0.1 \mathrm{~mL}$  );

d) 分光光度计;

e) 采样瓶。

5.2.2.4 试验步骤

5.2.2.4.1 工作曲线的绘制

用刻度吸管分别吸取亚硝酸钠标准溶液0,0.5,1.0,1.5,2.0,2.5,3.0,4.0,6.0,7.0mL于比色管中(其对应的二氧化氮质量为0,0.001,0.002,0.003,0.004,0.005,0.006,0.008,0.010,0.012,0.014 $\mathrm{mg}$ ), 分别加入吸收液至  $15 \mathrm{~mL}$  刻度。

再用移液管分别吸取  $5 \mathrm{~mL}$  显色剂溶液加入比色管中。然后, 将比色管置于  $25^{\circ} \mathrm{C} \pm 1^{\circ} \mathrm{C}$  恒温水浴中, 保温约  $30 \mathrm{~min}$ , 使其完全显色。在分光光度计上, 用  $1 \mathrm{~cm}$  比色皿, 以零标准溶液作参比, 于波长  $545 \mathrm{~nm}$  处测定每一标准溶液的吸光度。

以二氧化氮的质量为横坐标, 吸光度为纵坐标绘制工作曲线。

5.2.2.4.2 二氧化氮的测定

分别取  $40 \mathrm{~mL}$  气体试样, 注入装有  $15 \mathrm{~mL}$  二氧化氮吸收液的两个真空采样瓶中。将气体试样经  $24 \mathrm{~h}$  氧化和吸收后, 用于测定。

准确吸取  $5 \mathrm{~mL}$  显色剂溶液于采样瓶中, 按 5.2.2.4.1 所述方法以试剂空白溶液作参比测定吸光度。根据吸光度在工作曲线上查得该试样所对应的二氧化氮的质量, 然后换算成二氧化氮体积分数。

5.2.2.5 试验结果的表述

气体试样中氮氧化物的含量按式(3)计算。

$$
\phi_{2} = \frac{a \times 6.4 \times 10^{-5}}{V_{0}^{\prime \prime}} \times 100
$$

式中:  $\phi_{2}$  ——气体试样中氮氧化物的体积分数,  $\%$

$a$  ——从工作曲线上查得的  $\mathrm{NO}_{2}$  的质量,  $\mathrm{mg}$

$6.4 \times 10^{- 5}$  ——换算系数,  $\mathrm{L} / \mathrm{mg}$

$V_{0}^{\prime \prime}$  ——标准状况下气体试样的体积,  $\mathrm{L}$

平行测定二次, 允许差应不大于  $0.3 \%$ , 取算术平均值作为结果, 结果精确至  $0.01 \%$

5.3 有毒气体总量的计算

5.3.1 标准状况下, 每千克炸药爆炸后气体的总体积按式(4)计算。

$$
V_{0} = \frac{V_{\mathrm{r}} \times (P_{4} + P_{1} - P_{2} - P_{3}) \times 273 \times 1000}{101.3 \times (273 + t) m} \tag{4}
$$

式中:  $V_{0}$  ——标准状况下, 每千克炸药爆炸后产生的气体体积,  $\mathrm{L} / \mathrm{kg}$

$V_{\mathrm{r}}$  ——气体试样制备方法一为减去钢炮所占体积后爆炸弹筒内的实际容积,  $\mathrm{L}$ ; 气体试样制备方

法二为爆炸弹筒的实际容积,  $\mathrm{L}$

$P_{4}$  ——U型水银压差计的压差值,  $\mathrm{kPa}$

$P_{1}$  ——测定时的大气压力,  $\mathrm{kPa}$

$P_{2}$  ——抽真空时, 弹筒内剩余压力,  $\mathrm{kPa}$

$P_{3}$  ——温度为  $t$  时空气饱和水蒸汽压力,  $\mathrm{kPa}$

273——绝对温度和摄氏温度换算常数;

1000——千克和克的换算系数;

101.3——毫米汞柱与千帕斯卡的换算系数0.1333与标准状况大气压力  $760\mathrm{mmHg}$  的乘积。

$t$  ——测定时的室温,  $\mathrm{C}$  ;

$m$  ——测定用药卷质量,  $\mathrm{g}$  。

5.3.2 每千克炸药爆炸后, 生成的一氧化碳和氮氧化物的体积分别按式(5)、(6)计算。

\[ V^{\prime} = V_{0} \times \varphi_{1} \] (5)

\[ V^{\prime \prime} = V_{0} \times \varphi_{2} \] (6)

式中:  $V^{\prime}$  ——每千克炸药爆炸后生成的一氧化碳体积,  $\mathrm{L} / \mathrm{kg}$  ;

$V_{0}$  ——标准状况下, 每千克炸药爆炸后产生的气体体积,  $\mathrm{L} / \mathrm{kg}$  ;

$\varphi_{1}$  ——气体试样中一氧化碳的体积分数,  $\%$  ;

$V^{\prime \prime}$  ——每千克炸药爆炸后生成的氮氧化物体积,  $\mathrm{L} / \mathrm{kg}$  ;

$\varphi_{2}$  ——气体试样中氮氧化物的体积分数,  $\%$  。

5.3.3 每千克炸药爆炸后生成的有毒气体总量(按标准状况下折算成一氧化碳计)按式(7)计算。

\[ V = V^{\prime} + 6.5V^{\prime \prime} \] (7)

式中:  $V$  ——每千克炸药爆炸后生成的有毒气体总量,  $\mathrm{L} / \mathrm{kg}$  ;

$V^{\prime}$  ——每千克炸药爆炸后生成的一氧化碳体积,  $\mathrm{L} / \mathrm{kg}$  ;

6.5——将氮氧化物折算成一氧化碳时的毒性系数;

$V^{\prime \prime}$  ——每千克炸药爆炸后生成的氮氧化物体积,  $\mathrm{L} / \mathrm{kg}$  。

平行测定二次, 允许差应不超过  $10 \mathrm{~L} / \mathrm{kg}$ , 取较大值作为最终结果, 并修约到个数位。
