# 3设备和材料

# 3.1试验设备

试验设备示意图参见图A.1

# 3.2支撑架

支撑架示意图参见图A.2

# 3.3起爆器

电压大于6V的直流电源。

# 3.4点火装置

点火装置用电点火头:桥丝电阻  $1.7 \Omega \sim 2.3 \Omega$ ,药量  $9 \mathrm{mg} \sim 12 \mathrm{mg}$ 。

# 3.5压力传感器

量程:  $0 \mathrm{MPa} \sim 20 \mathrm{MPa}$ ,精度不低于  $0.2\%$ ,接口为  $\mathrm{M}20 \times 1.5$ 。

# 3.6压力采集系统

采样速率不低于  $200 \mathrm{kHz}$ ,能准确记录压力从  $690 \mathrm{kPa}$  升至  $2070 \mathrm{kPa}$  的变化。

# 3.7活塞式压力计

应符合JJG59的要求,准确度级别为0.05级。

# 4 试验准备

# 4.1 压力传感器标定

利用活塞式压力计和压力采集系统对试验用压力传感器进行静态标定。

# 4.2 试样准备

按照GB/T15813的规定进行样品分离,取所需部分药剂作为待测样品,待测样品应保持其在烟花爆竹中的原始形态,如粒状发射药、带谷壳或棉籽开爆药、粉状开爆药等。

# 5 试验步骤和结果

5.1 称取  $0.5\mathrm{g}$  待测样品待用。

5.2 将装上压力传感器但无铅防爆盘的试验设备以点火塞一端朝下架好,将称好的  $0.5\mathrm{g}$  试样放进设备中并使之与点火系统接触。

5.3 装上铅垫圈和铝防爆盘并将夹持塞拧紧。将已装填试样的容器移到点火支撑架上,防爆盘朝上,并置于适当的防爆通风橱或点火室中,点火塞外接头接上起爆器。

5.4 设置压力采集系统的采样速率和触发压力。

5.5 将试样点火,压力采集系统记录压力传感器所测得的压力随时间变化曲线。

5.6 试验进行三次,记下表压从  $690\mathrm{kPa}$  上升至  $2070\mathrm{kPa}$  所需的时间,取其中最短的时间作为测试结果。
