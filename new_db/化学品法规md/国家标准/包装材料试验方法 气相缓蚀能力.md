# 包装材料试验方法 气相缓蚀能力

# 1范围

本文件描述了气相防锈材料气相缓蚀能力的试验方法。

本文件适用于测定气相防锈纸、气相防锈塑料薄膜和气相防锈剂的气相缓蚀能力。其他气相防锈材料的气相缓蚀能力试验可参考本文件。

# 3术语和定义

GB/T11372及GB/T55491界定的以及下列术语和定义适用于本文件。

3.1

# 试验表面 test surface

经过专门加工供试验后要检查锈蚀情况的材料表面。

3.2

# 空白试验 blank test

试验装置中仅装有试片而无气相防锈材料的试验。

3.3

# 气相防锈剂 volatile rust preventive inhibitor

主要成分为气相缓蚀剂的气相防锈材料。注：按状态主要有粉末、颗粒、片状或液体。

# 4原理

4 原理控制密闭空间内的温度、相对湿度和结露条件，创造一个加速锈蚀环境，将气相防锈材料和金属试片置于该环境中并且相互不接触，通过试片表面锈蚀状态表征气相防锈材料的气相缓蚀能力。

# 5 实验室环境条件

试验应在  $20^{\circ}C\sim 30^{\circ}C$  和相对湿度不大于  $80\%$  的环境中进行。

# 6试剂和材料

6 试剂和材料6.1 砂纸：400号的氧化铝砂纸。6.2 无水乙醇：GB/T678，分析纯。6.3 丙三醇：GB/T687，分析纯。6.4 试验用水：GB/T6682，三级。6.5 试片：符合GB/T699要求，直径为  $16\mathrm{mm}$ ，高  $12\mathrm{mm}\sim 13\mathrm{mm}$  的10号钢柱，一端面的中央钻有底部平坦、直径为  $10\mathrm{mm}$ 、深为  $10\mathrm{mm}$  的孔，另一面为试验表面。6.6 橡胶塞：13号橡胶塞，其尺寸大面直径  $68\mathrm{mm}\pm 2\mathrm{mm}$ 、小面直径  $54\mathrm{mm}\pm 2\mathrm{mm}$ 、高为  $40\mathrm{mm}\pm 2\mathrm{mm}$ ；9号橡胶塞，其尺寸大面直径  $46\mathrm{mm}\pm 2\mathrm{mm}$ 、小面直径  $36\mathrm{mm}\pm 2\mathrm{mm}$ 、高为  $31\mathrm{mm}\pm 2\mathrm{mm}$ 。6.7 铝管：外径  $16\mathrm{mm}$ 、壁厚  $1.5\mathrm{mm}$ 。6.8 玻璃容器：内径  $40\mathrm{mm}\pm 2\mathrm{mm}$ 、高  $10\mathrm{mm}\sim 20\mathrm{mm}$ 。6.9 培养皿：直径为  $120\mathrm{mm}$ 。6.10 橡胶管：内径  $16\mathrm{mm}$ 、外径  $21\mathrm{mm}$ 、长度  $15\mathrm{mm}\pm 1\mathrm{mm}$ 。6.11 硅胶干燥剂：符合BB/T0049—2021中5.1.5.1的要求。6.12 广口瓶：符合GB/T11414要求，容积  $1000\mathrm{mL}$ ，瓶口内径（磨口尺寸） $60\mathrm{mm}$ 。

# 7仪器设备

7 仪器设备7.1 干燥箱：符合GB/T30455要求，温度波动度  $\pm 2^{\circ}C$ 。7.2 培养箱：符合GB/T28851要求，温度波动度  $\pm 1^{\circ}C$ 。7.3 电子天平：感量  $0.1\mathrm{mg}$ 。

# 8样品

8 样品样品应有代表性，开始试验前样品应密封保存，试验前及试验过程中应防止样品受到污染。

# 9试验步骤

# 9.1 试片的准备

9 试验步骤9.1 试片的准备试验前用砂纸打磨试片表面，使其表面平坦，无凹坑、划伤或锈蚀。用镊子夹取脱脂棉或脱脂纱布在无水乙醇中依次清洗3遍。再用热风吹干后使用。处理好的试片不能赤手接触。暂时不投入试验的放入盛有硅胶干燥剂的干燥器中保存，在  $8\mathrm{h}$  以内使用，超过  $8\mathrm{h}$  重新打磨清洗。每组试验需4片试

片，其中一片为空白试验用。

# 9.2 试验装置使用之前的处理

试验装置组装前，广口瓶、橡胶塞、图钉、曲别针、玻璃容器、培养皿均应进行仔细清洗，并用蒸馏水清洗两遍后烘干或热风吹干。试验装置在组装前在实验室环境温度条件下放置，使其温度与环境温度一致。

# 9.3 试片的组装

9.3.1 将一个13号橡胶塞和两个9号橡胶塞在端面中心部位打一直径  $15\mathrm{mm}$  的通孔。

9.3.2 将按9.1处理好的试片压入其中一个9号橡胶塞大面的通孔中，使试验表面与9号橡胶塞大面平行，试片露出9号橡胶塞大面的部分  $2\mathrm{mm}\sim 3\mathrm{mm}$ ，如图1a)所示。

9.3.3 将铝管穿过13号橡胶塞中心，并在两端露出的铝管上分别插入9号橡胶塞，两个9号橡胶塞的小面对着13号橡胶塞。在13号橡胶塞小面与装有试片的9号橡胶塞之间预先套上一橡胶管。装有试片的9号橡胶塞内的铝管应与试片凹面接触。13号橡胶塞的大面与无试片的9号橡胶塞小面接触，如图1b)所示。

# 9.4 气相缓蚀能力试验

# 9.4.1 试验数量

试验共4组，一组为空白试验，空白试验不放置气相防锈材料，3组为样品试验，样品试验放置相同数量的气相防锈材料。

# 9.4.2 气相防锈纸、气相防锈塑料薄膜的试验

9.4.2.1 从样品的不同部位裁取有代表性的试样，气相防锈纸试样为两条，每条尺寸  $150\mathrm{mm}\times$

$25\mathrm{mm}$ ，气相防锈塑料薄膜试样为四条，每条尺寸  $150\mathrm{mm}\times 50\mathrm{mm}$ 。

9.4.2.2 分别用图钉将两条气相防锈纸或4条气相防锈塑料薄膜对称平行地钉在13号橡胶塞底部，含有气相缓蚀剂的一面应朝向试片，用一枚曲别针别在试样下端使之自然下垂。将组装后的橡胶塞装在广口瓶中，瓶底部预先注有  $10\mathrm{mL}$  质量分数为  $35\%$  的丙三醇水溶液，如图2所示。

9.4.2.3 将组装好的4组试验装置同时置于  $20^{\circ}\mathrm{C}\pm 1^{\circ}\mathrm{C}$  的培养箱中， $20\mathrm{h}$  后取出，迅速向广口瓶上的铝管内注满温度为  $0^{\circ}\mathrm{C}\sim 2^{\circ}\mathrm{C}$  的水，然后立即放回  $20^{\circ}\mathrm{C}\pm 1^{\circ}\mathrm{C}$  的培养箱中。 $3\mathrm{h}$  后取出试验装置，倒掉铝管中的水，立即检查试验表面锈蚀情况。如试验表面有可见凝露，应马上用镊子夹取浸有无水乙醇的脱脂棉，轻轻擦洗后检查。

# 9.4.3 气相防锈剂的试验

9.4.3.1 在广口瓶底部注入  $10\mathrm{mL}$  、质量分数为  $35\%$  的丙三醇水溶液，在玻璃容器中均匀散布  $0.05\mathrm{g}$  粉状的气相防锈剂，然后置于广口瓶底部。

9.4.3.2 按照9.3所述方法将组装后的试片装在广口瓶中，如图3所示。按照9.4.2.3试验步骤进行试验。

# 9.5 加速消耗后的气相缓蚀能力试验

# 9.5.1 气相防锈纸、气相防锈塑料薄膜的试验

9.5.1.1 将气相防锈纸裁成一张  $200\mathrm{mm}\times 300\mathrm{mm}$  的试样，在干净、光滑的玻璃板上铺一张滤纸，将裁好的气相防锈纸平铺在滤纸上，并使涂有气相缓蚀剂的一面朝上，在试样的四角压上重物，使其在消耗时不发生卷曲。

9.5.1.2 将气相防锈塑料薄膜中含有气相缓蚀剂的一面向内，尽量排出空气后热封成  $200\mathrm{mm}\times 400\mathrm{mm}$  的密封袋3个，并吊挂。

9.5.1.3 试样放在  $60^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$  的干燥箱内，经  $120\mathrm{h},72\mathrm{h},48\mathrm{h}$  或  $24\mathrm{h}$  后取出，自然冷却至室温，再按9.4.1和9.4.2规定进行试验。

# 9.5.2 气相防锈剂的试验

将  $0.5\mathrm{g}$  粉状气相防锈剂均匀平铺在直径为  $120\mathrm{mm}$  的培养皿中，在  $60^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$  的干燥箱中放置  $120\mathrm{h}$  后取出，自然冷却至室温，再按9.4.1和9.4.3规定进行试验。

# 10 缓蚀能力分级和结果评定

# 10.1 缓蚀能力分级

气相防锈材料的气相缓蚀能力和加速消耗后的气相缓蚀能力按锈蚀程度分为4级：- 0级：无锈蚀；- 1级：轻微锈蚀或锈蚀面积在  $20\%$  以下；- 2级：锈蚀面积在  $20\% \sim 80\%$  ；- 3级：锈蚀面积在  $80\%$  以上。注：距试片边缘  $2\mathrm{mm}$  区域不作计算。

# 10.2 结果评定

10.2.1 空白试验中试片3级锈蚀为试验有效，否则应重新进行试验。10.2.2 3片试片级差不超过一个级别时，以两片相同等级定级；3片试片级差超过一个级别时，应重新进行试验。

# 11 试验报告

试验报告应至少包括以下内容：

a) 本文件编号；b) 试样的详细说明，包括种类、尺寸、数量、状态等；c) 实验室环境条件；d) 试验结果与评定；e) 观察到的异常现象；f) 试验过程中与本文件的差异；g) 试验人员及日期。
