## 📋 技术实现

### Prompt改进（要求AI输出反应方程式）

```python
# ai_analyzer.py

Prompt要求：
1. 基于MSDS数据进行分析
2. 重点关注不相容物质、GHS分类、反应性风险
3. **如果化学品之间可能发生化学反应，必须写出化学反应方程式**
4. 反应方程式要准确、配平
5. 说明反应条件和危险性
6. 如果不会发生反应，chemical_reactions 数组留空 []
```

### JSON输出格式

```json
{
  "chemical_reactions": [
    {
      "reactants": ["过氧化氢溶液", "甲醇"],
      "equation": "H2O2 + CH3OH → CH2O + 2H2O",
      "conditions": "高温或催化条件下",
      "products": ["甲醛", "水"],
      "danger_level": "剧烈",
      "description": "可能瞬间释放大量热量..."
    }
  ]
}
```

### 前端展示

```javascript
// 反应剧烈程度颜色标识
剧烈反应   → 红色 (#e74c3c)
中等反应   → 橙色 (#f39c12)
缓慢反应   → 蓝色 (#3498db)
无明显反应 → 灰色 (#95a5a6)

// 展开/折叠按钮
toggleAIReport() - 切换报告显示状态
```
