# 1范围

# 3术语和定义

联合国《关于危险货物运输的建议书 规章范本》联合国《关于危险货物运输的建议书 试验和标准手册》确立的以及下列术语和定义适用于本标准。

3.1

易燃固体 flammable solids

易燃固体是易于燃烧的固体或摩擦可能起火的固体。

# 4试验设备

4.1热空气循环式烘箱,其内容积大于9L,控温精度  $100^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$ $120^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$ $140^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$

4.2边长  $25\mathrm{mm}$  和  $100\mathrm{mm}$  的立方形试样容器,用不锈钢制造,网孔边长为  $0.05\mathrm{mm}$  ,容器上部开。

4.32个直径  $0.3\mathrm{mm}$  的铬铝热电偶。

# 5试验步骤

5.1将待测物质的粉状或颗粒状试样装进试样容器,装满至边,并将容器轻拍若干次。如试样下沉,继续添加样品,试样堆高后,齐边削平,将容器用罩罩住,挂在烘箱中心。

5.2两个热电偶分别测量烘箱、试验中心温度。

5.3取边长为  $100\mathrm{mm}$  的立方体试样在  $140^{\circ}\mathrm{C}$  条件下进行试验并保持  $24\mathrm{h}$  ,连续记录试样温度和烘箱温度。

5.4取边长为  $25\mathrm{mm}$  的立方体试样在  $140^{\circ}\mathrm{C}$  条件下进行试验并保持  $24\mathrm{h}$  ,连续记录试样温度和烘箱温度。

5.5物质将要在体积大于  $0.45\mathrm{m}^{3}$  ,小于  $3\mathrm{m}^{3}$  的容器中运输,取边长为  $100\mathrm{mm}$  的立方体  $120^{\circ}\mathrm{C}$  条件下进行试验并保持  $24\mathrm{h}$  ,连续记录试样温度和烘箱温度。

5.6物质将要在体积小于  $0.45\mathrm{m}^{3}$  ,取边长为  $100\mathrm{mm}$  的立方体  $100^{\circ}\mathrm{C}$  条件下进行试验并保持  $24\mathrm{h}$  ,连续记录试样温度和烘箱温度。

# 6试验结果描述

6.1如果在  $24\mathrm{h}$  试验时间内发生自热或者试样温度比烘箱温度高出  $60^{\circ}\mathrm{C}$  ,则认为试验物为自热物质,记录为肯定结果。否则,记录结果为否定。

6.2试验物质如符合下列条件,则为非4.2项物质。

a)用  $100\mathrm{mm}^{3}$  立方体试样在  $140^{\circ}\mathrm{C}$  下试验时取得否定结果;

b) 用  $100 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得肯定结果, 用  $25 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得否定结果, 用  $100 \mathrm{~mm}^{3}$  立方体试样在  $120^{\circ} \mathrm{C}$  下试验取得否定结果, 并且该物质装在体积不大于  $3 \mathrm{~m}^{3}$  的容器内运输;

c) 用  $100 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得肯定结果, 用  $25 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得否定结果, 用  $100 \mathrm{mm}^{3}$  立方体试样在  $100^{\circ} \mathrm{C}$  下试验取得否定结果, 并且该物质装在体积不大于  $450 \mathrm{~L}$  的容器内运输。

6.3 用  $25 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验取得肯定结果的自热物质, 划为Ⅱ类包装。

6.4 自热物质如符合下列条件, 划为Ⅱ类包装。

a) 用  $100 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得肯定结果, 用  $25 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得否定结果, 并且该物质装在体积大于  $3 \mathrm{~m}^{3}$  的容器内运输;

b) 用  $100 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得肯定结果, 用  $25 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得否定结果, 用  $250 \mathrm{~mm}^{3}$  立方体试样在  $120^{\circ} \mathrm{C}$  下试验取得肯定结果, 并且该物质装在体积大于  $450 \mathrm{~L}$  的容器内运输;

c) 用  $100 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得肯定结果, 用  $25 \mathrm{~mm}^{3}$  立方体试样在  $140^{\circ} \mathrm{C}$  下试验时取得否定结果, 并且用  $100 \mathrm{~mm}^{3}$  立方体试样在  $100^{\circ} \mathrm{C}$  下试验取得肯定结果。
