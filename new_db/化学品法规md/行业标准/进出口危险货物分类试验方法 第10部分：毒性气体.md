# 3术语和定义

《关于危险货物运输的建议书规章范本》和SN/T1828.1界定的以及下列术语和定义适用于本文件。

3.1

受试物 test substance

本标准范围内的各种测试样品。

3.2

半数致死浓度  $\mathbf{L}\mathbf{C}_{50}$ $50\%$  lethal concentration

实验动物在规定时间内一次持续吸入受试物,引起半数动物死亡的浓度。

3.3

急性吸入毒性 acute inhalation toxicity

实验动物短期内(通常为1h)一次连续吸入较高浓度的化学物气体、蒸气、气溶胶或颗粒状物后短期内发生的不良效应。

3.4

毒性气体 toxic gases

符合下列条件之一的气体:

已知对人类具有的毒性或腐蚀性强到对健康造成危害的气体:或

其  $\mathrm{LC}_{50}$  值  $\leqslant 5000\mathrm{~mL} / \mathrm{m}^{3}$ ,因而推定对人类具有毒性或腐蚀性的气体。

# 4 试验方法

# 4.1 实验动物

应使用实验室中常用的种属动物进行试验。首选健康成年小鼠(18g~22g)或大鼠(180g~220g)。同性别各剂量组个体间体重差不超过平均体重的20%。试验前动物应在试验环境中至少适应3d~5d。

# 4.2 试验设备

# 4.2.1 动式吸入染毒设备

由机械通风系统、受试物发生器和染毒柜3部分组成。动式吸入染毒试验场所应有机械通风系统保证染毒柜内空气新鲜,其氧含量不低于19%,二氧化碳含量不超过3%,温度维持在26°C±2°C范围内,且一天之内变化不超过3°C,相对湿度为50%~70%,每小时换气12次~15次,气流速度不宜过大,染毒柜内空气稍呈负压,以防止受试物外溢。

# 4.2.2 静式吸入染毒设备

根据动物种属数量与染毒时间,确定容器容积。静式染毒柜容积计算方法为1只小鼠1h最低需气量为4.35L,或1只大鼠1h最低需气量为30.5L。

# 4.3 试验准备

每组实验动物不少于10只,雌雄各半。按照随机原则将实验动物分配到各浓度组和对照组。至少设置3个浓度,准备不同浓度的气体受试物。

# 4.4 试验步骤

# 4.4.1 染毒

4.4.1.1 可采用动式吸入染毒法或静式吸入染毒法染毒。

4.4.1.2 动式吸入染毒:按设计规定的各浓度组将实验动物分别放入染毒柜中,启动通风系统和受试物发生器,受试物按规定浓度使动物连续吸入1h,切断受试物发生器,动物终止吸入染毒,继续通风15min,染毒柜换气3次~4次,而后停止通风,取出动物进行观察。

4.4.1.3 静式吸入染毒:将动物放入染毒柜中,再将滴有液体受试物的滤纸或蒸发皿放在柜内上方位置,密闭染毒柜,启动风扇使气体混匀,到达规定时间后打开染毒柜取出动物,在动物房内饲养并进行观察。

# 4.4.2 观察

记录染毒期间每只实验动物的症状出现次序、时间和严重程度以及死亡时间。

# 4.5 计算

采用霍恩氏法计算LC50值,方法见GB15193.3。

# 5类别判定

# 5.1纯物质包装类别判定

5.1.1已知  $\mathrm{LC}_{50}$  值的气体,  $\mathrm{LC}_{50}$  值  $\leqslant 5000 \mathrm{~mL} / \mathrm{m}^{3}$ , 则判定为 2.3 项毒性气体。

5.1.2未知  $\mathrm{LC}_{50}$  值的气体,按照4.4试验步骤得出  $\mathrm{LC}_{50}$  值  $\leqslant 5000 \mathrm{~mL} / \mathrm{m}^{3}$ , 则判定为 2.3 项毒性气体。

5.1.3因腐蚀性而符合  $\mathrm{LC}_{50}$  值  $\leqslant 5000 \mathrm{~mL} / \mathrm{m}^{3}$  标准的气体,判定为具有腐蚀性次要危险性的毒性气体。

5.1.4如果气体具有易燃性和毒性,其危险性的先后顺序应为毒性优于易燃性。
