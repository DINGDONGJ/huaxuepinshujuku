# 3 术语和定义

GB/T21535、GB30000.9—2013和GB30000.16—2013界定的以及下列术语和定义适用于本文件。

3.1

# 有机过氧化物 organicperoxide

含有二价的- O- O- 结构，可视为过氧化氢的一个或两个氢原子已被有机基团所取代的衍生物的液态或固态有机物，包括有机过氧化物配制品(混合物)。有机过氧化物是可发生放热自加速分解、热不稳定的物质或混合物。

[来源：GB30000.16—2013，3.1，有修改]

3.2

# 自反应物质 self-reactive substance

即使没有氧(空气)也容易发生激烈放热分解的热不稳定液态或固态物质或者混合物。[来源：GB30000.9—2013，3.1，有修改]

# 4 试验原理

使用细沙等封闭材料完全覆盖试样，通过远程点火引燃试样以观察试样是否发生爆燃反应。通过判断试验后包装的破碎情况，以评估其是否具有迅速传播爆燃的能力。

# 5 材料与装置

# 5.1 点火药包

由火药、点火头和塑料膜组成。其中，火药为  $2\mathrm{g}$  黑火药。将黑火药均匀地铺在塑料膜中心位置，随后将点火头埋没至黑火药内部，最后使用金属丝、塑料绳等线材捆扎固定。

# 5.2 起爆器

用于启动点火药包的装置，通过产生大电流电脉冲使点火药包内部的点火头发火，最高脉冲电压不应低于  $2000\mathrm{V}$ 。

# 5.3 点火线

用于连接点火药包和起爆器的双绞线材，以便操作人员由远处点火。外部由绝缘阻燃材料保护，内部导体横截面积不应小于  $2\mathrm{mm}^2$ 。

# 5.4 封闭材料

能覆盖样品材料并构筑封闭环境的材料。宜选用干燥的散沙，内部无硬块状杂质。

# 5.5 支架

用于将点火药包固定至样品中心位置。

# 5.6 测温系统

在试验期间测量样品附近温度，主要部分包括热电偶、热电偶线和温度数据采集仪。测温系统的相关技术参数宜包括如下内容。

a）热电偶：量程覆盖室温至  $1200^{\circ}\mathrm{C}$ ，测温精度不低于  $0.1^{\circ}\mathrm{C}$ ，响应时间短于  $1\mathrm{s}$ ，外表涂层均匀牢固，符合GB/T30429规定。b）温度数据采集仪：采样频率不低于  $1\mathrm{Hz}$ ，可在试验期间持续稳定工作。

# 6 试验

# 6.1 试验准备

# 6.1.1 样品

包装件外观检查，要求包装件完好且包装件外不应残留任何不相容杂质。

# 6.1.2 测温单元

热电偶传感器上不应残留任何可能引起试验结果产生偏差的杂质，如还原性物质等。

# 6.2 试验步骤

# 6.2.1 固定点火药包

6.2.1 固定点火药包将样品放置于平整、干燥且坚硬的地面上。宜将点火药包置于样品内部中心位置。若无法直接将点火药包置于中心位置（如样品为坚硬的整块固体样品），则将点火药包置于样品上表面。对于液态样品，可额外使用5.5规定的支架辅助固定点火药包。

# 6.2.2 安装测温单元

6.2.2 安装测温单元在点火药包旁边安装热电偶，必要时可使用铁架台、金属丝等固定。将温度数据采集仪安装在安全位置，并与热电偶相连。

# 6.2.3 封闭样品

使用封闭材料覆盖样品的四周及顶部，每个方向的厚度不应低于  $0.5\mathrm{m}$ ，如图1所示。

# 6.2.4 准备试验

使用点火线将点火药包和起爆器相连，人员撤离至安全位置。

# 6.2.5 点火

打开起爆器电源，启动点火装置。

# 6.2.6 记录

通过观察温度数据采集仪监测样品状态。待其温度降低至室温后，试验人员才可进入试验场。若测温系统因试验而发生故障，所有试验人员应至少等待  $30\mathrm{min}$ ，才可进入试验场。记录样品试验后的状况，包括自反应物质、有机过氧化物和爆炸性物品的残留物、碎片、反应后情况等，作为判断样品反应水平的依据。

# 6.2.7 终止判据

如果观察到内容器或外容器裂成3块及以上(容器底部和顶部除外)，试验结果描述为“十”并停止试验。若内容器或外容器碎片小于3块(容器底部和顶部除外)，则重复上述步骤继续试验直至出现“十”结果或连续3次试验均得到“一”结果，相关评判示例参见附录A。

# 7 结果评定

任意内容器或外容器裂成3块及以上(容器底部和顶部除外)，试验结果描述为“十”，即受试物质在该包装件中爆燃。若3次试验中，内容器或外容器碎片均小于3块(容器底部和顶部除外)，试验结果描述为“一”，即受试物质在该包装件中未爆燃。
