# 前言

本标准按照GB/T1.1—2009给出的规则起草。

本标准由中国轻工业联合会提出。

本标准由全国烟花爆竹标准化技术委员会（SAC/TC149）归口。

本标准起草单位：湖南烟花爆竹产品安全质量监督检测中心、国家轻工业烟花爆竹安全质量监督检测中心。

本标准主要起草人：黎建芳、徐莉、黄茶香、黎仲、张光明、周林、黎开甫。

# 烟花爆竹 黏土

# 1范围

本标准规定了烟花爆竹用黏土的术语和定义、产品分类、技术要求、检验方法、检验规则及运输和储存。

本标准适用于已加工的烟花爆竹用黏土。

# 3术语和定义

下列术语和定义适用于本文件。

3.1

黄土 mud

外观呈黄灰色或棕黄色的黄土细粒，质地均一，具有黏性，经加工而成。

3.2

胶（黑）土 tidal mud外观呈黑色或黑灰色，经加工而成。

3.3

混合沙土 mixed clay

将沙土与木屑混合后，加胶调成稠状的黏土。

# 4产品分类

黏土按状态及产地不同分为黄土、胶土、混合沙土三类。

# 5技术要求

# 5.1外观

外观应符合以下要求：

a）黏土形状为粉状或粒状，无明显杂质、砂石。b）颗粒应均匀，有细微空隙。

产品理化性能指标应符合表1要求。

# 5.3 牢固性

黏土牢固性按6.5试验，要求不开裂、散落。

# 6检验方法

# 6.1外观检查

目测，手感检验。

# 6.2 堆积密度试验方法

准确称取  $20\mathrm{g}$  （精确至  $0.01\mathrm{g}$  试样，用倾泻法倒入  $50~\mathrm{mL}$  干燥的量筒内，轻摇量筒至试样基本平行，读取量筒内试样最高点毫升数。堆积密度  $\rho$  按式（1）计算。

$$
\rho = \frac{m}{V} \tag{1}
$$

式中：

$\rho$  试样的堆积密度，单位为克每毫升  $(\mathrm{g / mL})$ $m$  试样的质量，单位为克  $(g)$ $V$  试样的体积，单位为毫升  $(\mathrm{mL})$  0

允许差：取平行测定结果的算术平均值为测定结果。平行测定结果的绝对差值不大于  $0.1\mathrm{g / mL}$

# 6.3水分的测定

称取约  $10\mathrm{g}$  试样（精确至  $0.0001\mathrm{g})$  ，置于预先在  $105~\mathrm{^9C}$  恒重的称量瓶中，在温度为  $105~^{\circ}\mathrm{C}\pm 2~^{\circ}\mathrm{C}$  的电烘箱中烘  $1\mathrm{h}$  ，取出后置于干燥器中，冷却  $30\mathrm{min}$  ，称量。水分的含量  $X$  按式（2）计算。取平行测定结果的算术平均值为测定结果，平行测定结果的绝对差值应不大于  $0.5\%$

$$
X = \frac{m - m_1}{m}\times 100 \tag{2}
$$

式中：

$X$  水分含量，  $\%$ $m$  试样的质量，单位为克  $(g)$ $m_{\mathrm{I}}$  试样干燥后的质量，单位为克  $(g)$

# 6.4 吸湿率的测定

按QB/T1941.5测定。

# 6.5 牢固性的测定

6.5 牢固性的测定将黏土压入纸筒（内径  $25\mathrm{mm}\pm 2\mathrm{mm}$  、壁厚  $18\mathrm{mm}\pm 2\mathrm{mm}$  、筒高  $55\mathrm{mm}\pm 2\mathrm{mm}$  ）内，黏土厚度为  $10\mathrm{mm}\pm 2\mathrm{mm}$ ，保持水平，从  $1\mathrm{m}$  处向厚度为  $30\mathrm{mm}$  以上的硬木板做自由落体，每个样品重复3次，观察泥塞是否开裂或散落，测试10个样品。

# 7检验规则

# 7.1组批

7.1 组批黄土、胶土、混合沙土分别以相同品种、相同型号的黏土为一批；每批产品不应超过  $5000\mathrm{kg}$ ，不应少于  $100\mathrm{kg}$ 。

# 7.2 抽样方法

7.2 抽样方法按GB/T6678进行抽样，用专用工具随机从每个包装单元中取不应少于  $40\mathrm{g}$  样品，将所采样品混匀后，用四分法缩分样品，样品量不小于  $200\mathrm{g}$ 。

# 7.3 检验项目

检验项目为外观、堆积密度、水分、吸湿率、牢固性。

# 7.4 判定原则

7.4 判定原则检验结果如果有一项指标不符合本标准要求时，应重新自两倍量的采样单元数复检，复检结果有一项指标不合格，整批产品不合格。

# 8运输和储存

# 8.1运输

在运输过程中应采取防水措施。

# 8.2储存

储存于干燥通风库房中。
