# 批量导入功能说明 📦

## 📋 功能概述

升级了MSDS数据导入功能，现在支持**批量导入**多个JSON文件，大幅提升数据导入效率！

### 功能特点
- ✅ **批量选择**：一次选择多个JSON文件
- ✅ **拖拽上传**：支持拖拽多个文件到上传区域
- ✅ **实时进度**：显示导入进度和每个文件的状态
- ✅ **状态追踪**：每个文件显示待导入/导入中/成功/失败状态
- ✅ **文件管理**：可以移除不需要的文件
- ✅ **智能过滤**：自动过滤非JSON文件
- ✅ **错误提示**：详细的成功/失败信息

---

## 🎯 使用方法

### 方法一：点击选择文件

1. **打开导入界面**
   - 点击"导入MSDS数据"按钮

2. **选择多个文件**
   - 点击上传区域
   - 在文件选择对话框中：
     * Windows: 按住`Ctrl`键选择多个文件
     * Mac: 按住`Cmd`键选择多个文件
   - 点击"打开"

3. **查看文件列表**
   ```
   ┌───────────────────────────────────────────┐
   │ 📄 乙醇.json (15.6 KB)      [待导入] [×] │
   │ 📄 甲苯.json (18.3 KB)      [待导入] [×] │
   │ 📄 甲醛.json (16.2 KB)      [待导入] [×] │
   └───────────────────────────────────────────┘
   ```

4. **开始导入**
   - 点击"开始批量导入"按钮
   - 等待导入完成

### 方法二：拖拽上传

1. **打开导入界面**
   - 点击"导入MSDS数据"按钮

2. **拖拽文件**
   - 从文件管理器选择多个JSON文件
   - 直接拖拽到上传区域
   - 松开鼠标

3. **开始导入**
   - 文件列表自动显示
   - 点击"开始批量导入"

#### 2. JavaScript核心逻辑

**文件选择处理**
```javascript
let selectedFiles = [];  // 改为数组存储多个文件

function handleFileSelect(event) {
    const files = Array.from(event.target.files);
    
    // 过滤JSON文件
    const jsonFiles = files.filter(file => file.name.endsWith('.json'));
    
    // 创建文件对象数组
    selectedFiles = jsonFiles.map(file => ({
        file: file,
        status: 'pending',
        message: ''
    }));
    
    renderSelectedFiles();
}
```

**批量导入处理**
```javascript
async function importData() {
    for (let i = 0; i < selectedFiles.length; i++) {
        const item = selectedFiles[i];
        
        // 更新状态为导入中
        item.status = 'importing';
        renderSelectedFiles();
        
        // 更新进度
        const progress = Math.round(((i) / totalFiles) * 100);
        progressBar.style.width = progress + '%';
        
        // 执行导入
        const formData = new FormData();
        formData.append('file', item.file);
        const response = await fetch('/api/import', {
            method: 'POST',
            body: formData
        });
        
        // 更新结果
        if (response.ok) {
            item.status = 'success';
            successCount++;
        } else {
            item.status = 'error';
            errorCount++;
        }
    }
}
```

## 🐛 常见问题

### Q1: 可以选择文件夹吗？
**答**：目前不支持直接选择文件夹，但可以：
1. 进入文件夹
2. 全选文件（Ctrl+A / Cmd+A）
3. 批量选择导入

### Q2: 最多可以导入多少个文件？
**答**：理论上没有限制，但建议：
- 一次不超过50个文件
- 避免过大的文件（>10MB）
- 分批导入以提高稳定性

### Q3: 导入失败如何处理？
**答**：
1. 查看失败文件的错误信息
2. 检查JSON格式是否正确
3. 移除失败的文件
4. 重新选择该文件单独导入

### Q4: 可以中途取消吗？
**答**：目前不支持中途取消，导入开始后会完成所有文件。建议：
- 导入前仔细检查文件列表
- 移除不需要的文件
- 确认无误后再开始导入

### Q5: 重复的文件会怎样？
**答**：
- 系统会根据CAS号判断是否存在
- 存在则更新该化学品数据
- 不存在则新建化学品记录
