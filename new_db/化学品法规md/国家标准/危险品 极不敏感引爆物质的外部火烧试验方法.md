# 危险品 极不敏感引爆物质的外部火烧试验方法

# 1范围

本标准规定了极不敏感引爆物质的外部火烧试验的方法原理、试验设备、试样准备、试验步骤和结果表示。

本标准适用于极不敏感引爆物质的测试。

# 3术语和定义

GB19455、GB19458、联合国《关于危险货物运输的建议书：规章范本》（第十四修订版）确立的下列术语和定义适用于本标准。

3.1

整体爆炸 mass detonation or explosion of total contents

全部物质或物品同时发生爆炸。

3.2

爆炸 explosion

在极短时间内,释放出大量能量,产生高温,并放出大量气体,在周围造成高压的化学反应或状态变化的现象。

3.3

爆炸性物质 explosive substance

能够通过其自身化学反应产生气体,反应时在温度、压力和速度下能对周围环境造成破坏的某一种固态或液态物质(或这些物质的混合物)。烟火物质,即使不放出气体时,也包括在内。

3.4

爆炸品 explosive

固体或液体物质,在外界作用下(如受热、受压、撞击等)能发生剧烈的化学反应,瞬时产生大量的气体和热量,使周围压力急剧上升发生爆炸,对周围环境造成破坏的物品,也包括无整体爆炸危险,具有燃烧、抛射及较小爆炸危险的物品。

3.5

烟火物质 pyrotechnic substance

用来产生热、光、声、气或烟的效果或这些效果加在一起的一种物质或物质混合物。这些效果是由不起爆的自持放热化学反应产生的。

# 4方法原理

将试样制成规定的供试品进行外部火烧试验，记录试验现象并按照标准规定进行评估，确定物质是否属于极不敏感引爆物质。

# 5 试验设备

# 5.1 试样容器

内径  $45 \mathrm{mm} \pm 4.5 \mathrm{mm}$  、壁厚  $4 \mathrm{mm} \pm 0.4 \mathrm{mm}$  、长  $200 \mathrm{mm}$  的无缝钢管，两端攻外丝以便拧上端盖；端盖用强度至少同无缝钢管相同的钢或铸铁制造，攻内丝以便与无缝钢管管口拧合。

# 5.2 金属格栅

用于将供试品架在燃料之上并使其能够充分加热的支架。

# 5.3 捆带条、线

将试样捆在一起的钢制捆带条或线。

# 5.4 燃料

木材、液体或气体燃料。如用木材烧火时，须用煤油渗透木材和引火的木刨花。不管用何种燃料，应保证燃料的量足够持续燃烧  $30\mathrm{\min}$  ，必要时燃烧至供试品有充分时间对火起反应，并通过合适的加热方法使火焰温度至少达到  $800^{\circ}C$  。

# 5.5 点火系统

能够从两边同时点燃燃料的点火器或装置。

# 5.6 验证屏

三块  $2000 \mathrm{mm} \times 2000 \mathrm{mm} \times 2 \mathrm{mm}$  的铝片。

# 5.7 验证屏支撑架

使验证屏(铝片)垂直竖立着的适当支撑装置。

# 5.8 记录设备

用于记录事态发展的彩色电影或录像摄影机，最好兼具高速和常速功能。

# 6试样准备

以普通方法制作爆炸品测试样品。测试样品制成棒状，长  $200 \mathrm{mm}$  ，直径刚好能装入5.1 所规定的无缝钢管中。将制好的棒状样品装入无缝钢管中，管端用端盖封闭，扭力  $204 \mathrm{N}\cdot \mathrm{m}$  ，成为供试品。共制15 个待测样品。

# 7.试验步骤

警告：试验不应在风速超过  $\mathbf{6}\mathbf{\Omega}\mathbf{m} / \mathbf{s}$  的条件下进行。在火熄灭后，应遵守试验机构规定的一段安全等候时间。

# 7.1金属格栅放置

金属格栅架离地面的高度与采用的燃料有关。如果用木材堆烧火，金属格栅应离地面  $1. 0 \mathrm{m}$  高；如果用液体燃料烧火，金属格栅应离地面  $0. 5 \mathrm{m}$  高。

# 7.2 验证屏放置

三块验证屏分别竖立在供试品四周除下风面的三面，距离供试品边缘  $4 \mathrm{m}$  处；验证屏的中心与供试品的中心高度一致。如果供试品离地面高度不到  $1 \mathrm{m}$  ，验证屏则应与地面接触。如果在试验前验证

屏上已有穿孔或凹陷, 应当对这些穿孔或凹陷做记号, 使它们能够与试验中造成的穿孔或凹痕明确地区分。

# 7.3 燃料放置

燃料放在格栅下面的方式要使火能包围供试品。

# 7.3.1 木材放置

用木材烧火时, 应有平衡的空气/燃料比率, 以避免烟雾太多而记录不清事态发展, 并且燃烧强度和持续时间足以使供试品在  $10 \mathrm{~min} \sim 30 \mathrm{~min}$  内产生反应。可采用如下方法放置: 用截面大约  $50 \mathrm{~mm}$  见方的风干木头在金属格栅(高地面  $1 \mathrm{~m}$  高) 下面堆成网络状, 木条之间的横向距离约为  $100 \mathrm{~mm}$ , 堆至支撑供试品的格栅底部。木头堆垛面积应超出供试品, 每个方向超出的距离应至少为  $1.0 \mathrm{~m}$  。

# 7.3.2 液体燃料放置

如果用液体燃料烧火, 装燃料的贮槽周边应超出供试品, 每个方向超出的距离应至少为  $1.0 \mathrm{~m}$ , 格栅和贮槽之间的距离约为  $0.5 \mathrm{~m}$  。使用这种烧火方法之前, 应当考虑爆炸品和液体燃料之间是否会发生淬火作用或不利的相互作用, 从而影响试验结果。

# 7.3.3 气体燃料放置

如果使用气体燃料, 燃烧面积应超出供试品, 每个方向超出的距离应至少为  $1.0 \mathrm{~m}$  。气体供应必须能确保火焰均匀地包围供试品。蓄气筒应当足以使火持续燃烧至少  $30 \mathrm{~min}$  。点燃气体的方式可以是远距离点燃烟火或远距离释放靠近预先放置的点火源的气体。

# 7.4 试样放置

将 15 个供试品堆成 3 个相邻的堆垛放在一个金属格栅上, 每一堆垛由 2 上 3 下捆绑在一起的 5 个试样组成; 或将 15 个供试品平均放在 3 个金属格栅上, 每个金属格栅上的 5 个试样平行捆绑。

# 7.5 点火

把点火系统放在适当的位置后从两边同时点燃燃料, 一边是顶风口。

# 7.6 记录

拍摄彩色照片作为每次试验后试样情况的记录。记录陷坑以及试样容器的碎片大小和位置作为反应程度的证据。

# 7.7 试验次数

试验通常只进行一次, 但是如果用于烧火的木材或其他燃料全部烧完后, 在残余物中或在火烧区附近仍留有相当数量的爆炸性物质未烧毁, 那么应当用更多的燃料或用另一种方式增加火烧强度和/或持续时间, 再进行一次试验。如果试验结果不足以进行评估, 应当再进行一次试验。

# 8 结果表示

# 8.1 结果的评估依据

8.1.1 陷坑及封闭钢管的碎片大小和位置。

8.1.2 起爆或反应激烈程度、碎片抛射距离。

8.2 确定极不敏感引爆物质的试验标准

8.2.1 极不敏感引爆物质: 不起爆或反应不激烈、无爆炸碎片或碎片未抛射到  $15 \mathrm{~m}$  以外的物质。

8.2.2 非极不敏感引爆物质: 起爆或反应激烈、碎片抛射到  $15 \mathrm{~m}$  以外的爆炸性物质。结果记为"十"。
