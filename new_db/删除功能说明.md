# 化学品删除功能说明

## 📋 功能概述

系统新增了化学品删除功能，允许用户通过Web界面安全地删除化学品及其所有相关数据。

---

## 🎯 功能特性

### 1. **双重删除入口**

#### **入口1：化学品列表**
- 点击"📋 查看列表"打开侧边栏
- 鼠标悬停在化学品项目上
- 右侧会显示 🗑️ 删除按钮
- 点击即可删除

#### **入口2：MSDS详情页**
- 查询化学品后显示详情
- 在化学品名称右上角
- 有一个"🗑️ 删除化学品"按钮
- 点击即可删除

### 2. **安全确认机制**

- 点击删除按钮后会弹出确认对话框
- 显示将要删除的化学品名称和CAS号
- 明确提示此操作不可恢复
- 必须点击"确认删除"才会执行

### 3. **级联删除**

删除一个化学品时，会自动删除：
- ✅ 化学品基本信息
- ✅ 所有别名记录
- ✅ MSDS文档
- ✅ 所有MSDS章节（16个部分）
- ✅ 章节中的图片引用

### 4. **实时反馈**

- 删除过程中显示"删除中..."提示
- 删除成功显示绿色成功通知
- 删除失败显示红色错误提示
- 自动刷新列表和清空详情

---

## 💡 使用方法

### 方法1：从列表删除

1. **打开化学品列表**
   - 点击顶部的"📋 查看列表"按钮
   - 侧边栏从右侧滑出

2. **定位目标化学品**
   - 浏览列表或使用搜索框过滤
   - 找到要删除的化学品

3. **触发删除**
   - 鼠标悬停在目标化学品上
   - 右侧出现 🗑️ 图标
   - 点击 🗑️ 图标

4. **确认删除**
   - 弹出确认对话框
   - 检查化学品信息是否正确
   - 点击"确认删除"

5. **完成**
   - 显示成功提示
   - 列表自动刷新
   - 该化学品已从数据库中移除

### 方法2：从详情页删除

1. **查询化学品**
   - 在搜索框输入化学品名称或CAS号
   - 点击"🔍 查询"

2. **查看详情**
   - 系统显示化学品的完整MSDS信息
   - 在顶部化学品名称处

3. **点击删除按钮**
   - 化学品名称右上角有"🗑️ 删除化学品"按钮
   - 点击该按钮

4. **确认删除**
   - 弹出确认对话框
   - 点击"确认删除"

5. **完成**
   - 显示成功提示
   - 详情页自动清空
   - 搜索框清空

## ⚠️ 安全提示

### 删除前请确认

- ❌ **删除操作不可恢复**：删除后无法撤销
- ❌ **数据完全清除**：所有相关数据将被永久删除
- ✅ **仔细核对**：确认对话框会显示化学品名称和CAS号
- ✅ **谨慎操作**：只删除确实不需要的化学品

### 权限控制

当前版本所有用户均可删除化学品。如需权限控制，建议：

1. **添加用户认证**：实现登录功能
2. **角色权限**：区分普通用户和管理员
3. **删除日志**：记录删除操作的用户和时间
4. **软删除**：标记删除而非物理删除（可恢复）

## 🔧 技术实现

### 后端API

#### 接口地址
```
POST /api/delete
```

#### 请求参数
```json
{
    "chemical_id": 123
}
```

#### 响应格式

**成功响应**：
```json
{
    "success": true,
    "message": "成功删除化学品: 甲醛",
    "data": {
        "化学品名称": "甲醛",
        "CAS号": "50-00-0"
    }
}
```

**失败响应**：
```json
{
    "error": "化学品不存在"
}
```

#### 数据库操作

```sql
-- 删除化学品（外键级联会自动删除相关数据）
DELETE FROM 化学品 WHERE 编号 = ?;

-- 级联删除的表：
-- - 化学品别名 (foreign key: 化学品编号)
-- - MSDS文档 (foreign key: 化学品编号)
-- - MSDS章节 (foreign key: 文档编号)
```

### 前端实现

#### 确认对话框
- 使用CSS动画（淡入、滑动）
- 模态窗口设计
- 点击遮罩层可关闭

#### JavaScript函数

```javascript
// 显示删除确认对话框
showDeleteConfirm(chemicalId, chemicalName, casNumber, callback)

// 关闭确认对话框
closeConfirmDialog()

// 执行删除操作
confirmDelete()

// 调用删除API
deleteChemical(chemicalId)
```

#### 删除按钮样式
- 红色背景 (#dc3545)
- 悬停效果：加深颜色、阴影、上移
- 在列表中：悬停显示
- 在详情页：始终显示

## 🐛 常见问题

### Q1: 误删除了化学品怎么办？

**A**: 当前版本不支持恢复，需要重新导入。建议：
- 定期备份数据库
- 删除前仔细确认
- 考虑实现软删除功能

**数据库备份命令**：
```bash
mysqldump -u root -p危化品简化数据库 > backup_$(date +%Y%m%d).sql
```

### Q2: 删除按钮没有出现

**A**: 检查以下几点：
- 鼠标是否悬停在列表项上（列表中的删除按钮是悬停显示）
- 浏览器是否支持CSS hover效果
- 刷新页面（Ctrl + F5）

### Q3: 点击删除后没有反应

**A**: 可能原因：
- 网络连接问题
- 后端服务未启动
- 查看浏览器控制台的错误信息

### Q4: 删除失败提示"化学品不存在"

**A**: 可能原因：
- 化学品已被其他用户删除
- 数据库连接问题
- 刷新列表重试

### Q5: 如何批量删除化学品？

**A**: 当前版本不支持批量删除，需要逐个删除。未来版本计划：
- 添加多选功能
- 提供批量删除API
- 添加筛选条件批量删除

## 📝 使用建议

### 最佳实践

1. **删除前备份**
   - 重要数据先备份
   - 定期自动备份数据库

2. **仔细确认**
   - 删除前检查CAS号
   - 确保不是误操作

3. **权限管理**
   - 限制删除权限
   - 重要系统启用审批流程

4. **数据归档**
   - 定期归档旧数据
   - 而非直接删除

### 故障恢复

如果误删除了重要化学品：

1. **立即停止操作**
2. **从最近备份恢复**：
   ```bash
   mysql -u root -p危化品简化数据库 < backup_20240101.sql
   ```
3. **重新导入单个化学品**：
   ```bash
   python scrape_to_json.py "URL" --import
   ```
