# 进出口危险货物分类试验方法第6部分:遇水放出易燃气体物质

警告:由于自身危险性,测试实验室应对法规要求的健康和安全要求引起特别的重视。

# 1范围

SN/T1828—2019的本部分规定了进出口遇水放出易燃气体危险货物的试验和类别判定。

本部分适用于进出口遇水放出易燃气体物质的检验。

本部分不适用于发火物质、化学结构不含有金属或类金属的物质、物质在水中生产或经过水洗或者已知该物质溶于水后形成稳定的混合物。

# 3术语和定义

SN/T1828.1界定的以及下列术语和定义适用于本文件。

遇水放出易燃气体物质 substances which in contact with water emit flammable gases

是指遇水或受潮时,物质发生剧烈化学反应,放出危险数量的易燃气体,这种气体与空气混合能够形成爆炸性混合物,此类混合物极易被平常火源点燃,形成的冲击波和火焰能够对人体及环境造成危害。

# 4.3 试验设备

4.3 试验设备遇水放气试验仪或其他等效仪器。

# 4.4 环境要求

4.4.1 试验应在环境温度  $(20^{\circ}C)$  和大气压力下进行。

4.4.2 试验应在通风橱中进行。

# 4.5 试验步骤

# 4.5.1 遇水放出易燃气体物质的初筛实验步骤

# 4.5.1.1 入水试验

4.5.1.1 入水试验将直径为  $2 \mathrm{~mm}$  的物质置于  $20^{\circ} \mathrm{C}$  蒸馏水中,观察并记录发生的现象。

# 4.5.1.2 停留试验

4.5.1.2 停留试验将过滤纸平坦地放在  $20^{\circ} \mathrm{C}$  蒸馏水表面上,将直径为  $2 \mathrm{~mm}$  的物质置于过滤纸中心,观察并记录所产生的现象。

# 4.5.1.3 滴水试验

4.5.1.3 滴水试验将试验物质做成高约  $20 \mathrm{~mm}$  、直径约  $30 \mathrm{~mm}$  的堆垛,垛顶上做一凹槽。在凹槽中加几滴蒸馏水,观察并记录发生现象。

# 4.5.2 适用包装类别试验步骤

4.5.2.1用遇水放气试验仪测定物质与水反应所释放的气体体积,记下释放全部气体所需的时间,并记录中间读数。计算持续7h的气体释放速度,每隔1h计算1次。

4.5.2.2如果释放速度不稳定,或在持续7h之后气体仍在增加,应延长测定时间,最长为5d。如释放速度变得稳定或不断减少,并且已得到充分数据可将该物质划定一个包装类别,或确定该物质不应划人4.3项,则5d试验即可停止。

4.5.2.3如释放气体的化学物质是未知的,应对该气体进行易燃性试验,按SN/T1828.12的规定进行。
