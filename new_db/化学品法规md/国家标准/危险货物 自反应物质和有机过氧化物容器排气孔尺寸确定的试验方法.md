本文件描述了F型自反应物质和F型有机过氧化物运输容器排气孔尺寸确定试验原理、设备与材料、试验程序和试验结果。

# 3 术语和定义

GB/T567.1—2012、GB30000.9—2013、GB30000.16—2013和GB/T30429界定的以及下列术语和定义适用于本文件。

3.1

# 爆破片 bursting disc

因超压而迅速动作的压力敏感元件。

[来源：GB/T567.1—2012，3.3，有修改]

3.2

# 有机过氧化物 organic peroxide

含有二价的- O- O- 结构，可视为过氧化氢的一个或两个氢原子已被有机基团所取代的衍生物的液态或固态有机物。

注：包括有机过氧化物配制品（混合物）。有机过氧化物是可发生放热自加速分解、热不稳定的物质或混合物。[来源：GB30000.16—2013，3.1，有修改]

# 3.3

3.3自反应物质或混合物 self- reactive substances or mixtures即使没有氧(空气)也容易发生激烈放热分解的热不稳定液态或固态物质或者混合物。[来源:GB30000.9—2015,3.1,有修改]

# 4试验原理

4 试验原理模拟自反应物质和有机过氧化物使用常见容器运输时，在自加速分解或完全被火焰吞没情况下，容器上的紧急排气孔是否能够将容器内压力有效泄放。

# 5设备与材料

# 5.1 试验容器

试验容器的具体要求如下。

5.1 试验容器试验容器的具体要求如下。a）容器容积为  $200~\mathrm{mL}$ ，承压能力不小于  $10\mathrm{MPa}$ ，用于排气孔预试验，材质应符合GB/T713.7的规定。容器顶部配有一个开口并用爆破片封闭。b）容器的容积为  $10\mathrm{L}$ ，承压能力不小于  $10\mathrm{MPa}$ ，容器尺寸为外径  $200~\mathrm{mm}$ 、壁厚  $20~\mathrm{mm}$ 、高度  $500~\mathrm{mm}$ 、材质为不锈钢，应符合GB/T713.7的规定。容器顶部配有一个模拟运输容器减压阀的  $1\mathrm{mm}$  开口，第二个开口模拟紧急排气孔并用爆破片封闭。

# 5.2 爆破片

5.2 爆破片在指定压力及温度下爆破泄压的元件，应符合GB/T567.1—2012的规定。

# 5.3 电加热线圈

5.3 电加热线圈通电后对容器的实际加热速率达到计算加热速率，加热器的最高加热温度不小于  $600^{\circ}\mathrm{C}$ ，加热速率范围：  $0^{\circ}\mathrm{C} / \min \sim 20^{\circ}\mathrm{C} / \min$ 。

# 5.4 隔热材料

5.4 隔热材料能够有效阻滞容器外部热量传递至容器内部的材料，例如石棉、泡沫玻璃或陶瓷纤维。

# 5.5 温度数据采集仪

采样频率不小于  $10\mathrm{Hz}$ ，连续记录数据时长不少于  $3\mathrm{h}$ ，测试通道不少于5通道。

# 5.6 热电偶

5.6 热电偶温度测量范围：最高测量温度不小于  $1000^{\circ}\mathrm{C}$ ，灵敏度不大于  $0.1^{\circ}\mathrm{C}$ ，应符合GB/T30429的规定。热电偶材质不能与试样发生反应或催化。

# 5.7 压力数据采集仪

采集频率不低于  $1000\mathrm{Hz}$ ，连续记录数据时长不少于  $3\mathrm{h}$ ，测试通道不少于2通道。

# 5.8 压力传感器

压力传感器的具体要求如下。

a）测量范围：  $\mathrm{0~MPa\sim 30~MPa}$  0

b）测量误差：不大于  $0.15\% \mathrm{FS}$ 。

# 5.9 视频监控系统

用于远程观察试验过程。

# 6 试验程序

# 6.1 试验准备

# 6.1.1 计算加热速率

加热速率按以下具体要求计算。

a）根据试样的实际运输条件，确定是否有隔热层。

b）无隔热层部分输入的热量  $(q_{\mathrm{d}})$  按公式（1）计算：

$$
q_{\mathrm{d}} = 70961\times F\times (F_{\mathrm{r}}\times A)^{0.82}
$$

式中：

$q_{\mathrm{d}}$  ——无隔热层部分输入的热量，单位为瓦特（W）； $F$  ——隔热系数，无隔热层时取值为1，有隔热层时  $F$  按公式（3）计算； $F_{\mathrm{r}}$  ——加热常数，无隔热层时取值为1，有隔热层时取值为0.01； $A$  ——运输容器的浸润面积，单位为平方米  $(\mathrm{m}^2)$  。

c）带隔热层部分输入的热量  $(q_{\mathrm{i}})$  按公式（2）计算：

$$
q_{\mathrm{i}} = 70961\times F\times [(1 - F_{\mathrm{r}})\times A]^{0.82} \tag{2}
$$

式中：

$q_{\mathrm{i}}$  ——带隔热层部分输入的热量，单位为瓦特（W）；

$$
F = \frac{2\times U\times(923 - T_{\mathrm{po}})}{47032}
$$

式中：

$U$  ——热传导系数，单位为瓦特每平方米开尔文  $\left[\mathrm{W} / (\mathrm{m}^2\cdot \mathrm{K})\right]$  ； $T_{\mathrm{po}}$  ——减压条件下待测样品的温度，单位为开尔文（K）。

d）总加热速率  $(\frac{\mathrm{d}T}{\mathrm{d}t})$  按公式（4）计算：

$$
\frac{\mathrm{d}T}{\mathrm{d}t} = \frac{60\times(q_{\mathrm{d}} + q_{\mathrm{i}})}{M_{\mathrm{t}}\times C_{\mathrm{p}}}
$$

式中：

$\frac{\mathrm{d}T}{\mathrm{d}t}$  ——总加热速率； $M_{\mathrm{t}}$  ——待测样品的总质量，单位为千克  $(\mathrm{kg})$  ； $C_{\mathrm{p}}$  ——待测样品的比热容，单位为焦耳每千克开尔文  $\left[\mathrm{J} / (\mathrm{kg}\cdot \mathrm{K})\right]$  。

# 6.1.2 试验器材准备

试验器材按以下要求准备：

# GB/T 45237—2025

a) 将试验罐体与管路连接；b) 将压力传感器与压力采集系统连接；c) 将热电偶与温度数据采集仪连接。

# 6.1.3 试验样品准备

记录样品试验编号、物理状态等信息，进行拍照留存。

# 6.1.4 视频监控系统准备

检查视频监控系统，确保画面清晰，视频信号稳定。

# 6.1.5 加热速率调试

正式试验前，向试验容器内加入与待测样品比热容接近的惰性物质，调节加热速率至计算加热速率。

# 6.2 试验步骤

6.2.1 先使用小型试验容器进行排气孔预试验，获取待测物质产生的最大压力，为选择  $10\mathrm{~L}$  排气孔试验的孔径提供参考。

6.2.7 若两次试验中最大试验压力均小于运输容器规定的最大排气压力，即可停止试验，此时孔板的孔径为临界孔径。

# 7 试验结果

运输容器的紧急排气孔尺寸  $(\phi)$  与  $10\mathrm{~L}$  试验容器的临界孔径  $(\phi^{\prime})$  之间的换算关系按公式（5）计算：

$$
\frac{\pi\left(\frac{\phi}{2}\right)^2}{V} = \frac{\pi\left(\frac{\phi'}{2}\right)^2}{V_{\mathrm{t}}}
$$

（5）

式中：

$\pi$  ——圆周率，常数； $\phi$  ——运输容器的紧急排气孔尺寸，单位为毫米  $(\mathrm{mm})$  ； $V$  ——运输容器的容积，单位为立方米  $(\mathrm{m}^3)$  ；

$\phi^{\prime}$  ——10 L 试验容器的临界孔径, 单位为毫米  $(\mathrm{mm})$ ;  $V_{\mathrm{t}}$  ——10 L 试验容器的实际容积, 单位为立方米  $(\mathrm{m}^{3})$  。自反应物质和有机过氧化物加热速率计算实例见附录 A。

# 自反应物质和有机过氧化物加热速率计算实例

自反应物质和有机过氧化物容器排气孔尺寸确定的试验方法中加热速率计算实例，见示例1和示例2。

示例1：隔热槽罐

典型的  $20\mathrm{m^3}$  隔热槽罐：

$F_{\mathrm{r}} =$  加热常数  $= 0.01$ $M_{\mathrm{t}} =$  有机过氧化物或自反应物质和稀释剂的总质量  $= 16268\mathrm{kg}$ $K =$  隔热层导热率  $= 0.031\mathrm{W / (m\cdot K)}$ $L =$  隔热层厚度  $= 0.075\mathrm{m}$ $U =$  热传导系数  $= 0.4\mathrm{W / (m^2\cdot K)}$ $A =$  槽罐的浸润面积  $= 40\mathrm{m^2}$ $C_{\mathrm{p}} =$  有机过氧化物配制品的比热  $= 2000\mathrm{J / (kg\cdot K)}$ $T_{\mathrm{po}} =$  减压条件下有机过氧化物的温度  $= 100^{\circ}\mathrm{C}$

以及

$$
q_{\mathrm{i}} = 70961\times 2\times \frac{0.4\times(923 - 373)}{47032}\times [(1 - 0.01)\times 40]^{0.82} = 13558\mathrm{W}
$$

$$
q_{\mathrm{d}} = 70961\times 1\times (0.01\times 40)^{0.82} = 33474\mathrm{W}
$$

$$
\frac{\mathrm{d}T}{\mathrm{d}t} = \frac{(13558 + 33474)}{16268\times 2000}\times 60 = 0.086\mathrm{K / min}
$$

示例2：不隔热中型散装容器

典型的  $1.2\mathrm{m^3}$  不隔热中型散装容器（只有直接热输入，  $q_{\mathrm{d}}$  ）：

$F_{\mathrm{r}} =$  加热常数  $= 1$ $M_{\mathrm{t}} =$  有机过氧化物和稀释剂的总质量  $= 1012\mathrm{kg}$ $A =$  中型散装容器的浸润面积  $= 5.04\mathrm{m^2}$ $C_{\mathrm{p}} =$  有机过氧化物配制品的比热  $= 2190\mathrm{J / (kg\cdot K)}$

以及

$$
q_{\mathrm{d}} = 70961\times 1\times (1\times 5.04)^{0.82} = 267308\mathrm{W}
$$

$$
q_{\mathrm{i}} = 0
$$

$$
\frac{\mathrm{d}T}{\mathrm{d}t} = \frac{(0 + 267308)}{1012\times 2190}\times 60 = 7.2\mathrm{K / min}
$$
