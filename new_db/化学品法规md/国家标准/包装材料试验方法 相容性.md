# 4实验室环境条件

试验应在温度  $20^{\circ}C\sim 30^{\circ}C$  和相对湿度不大于  $80\%$  的环境中进行。

# 5 中性包装材料与固体材料的相容性

# 5.1 原理

5.1 原理用中性包装材料包装试片，置于特定温度、相对湿度的试验箱内一段时间，根据试片变化和空白试验进行对比，评价中性包装材料与固体材料的相容性。

# 5.2 试剂和材料

5.2.1 无水乙醇：GB/T678，分析纯。

5.2.2 水：GB/T6682，三级。

5.2.3固体材料试片（以下简称试片)：根据实际包装件内容物材料选定，尺寸为  $100\mathrm{mm}\times 50\mathrm{mm}$  ，厚度不大于  $5\mathrm{mm}$  。固体材料为金属时，如果没有特别指定，可选用下列材料：

符合GB/T5231—2022要求的T3纯铜板；符合GB/T3880.1—2023要求的2A12铝合金板；钢上镀锌钝化板；钢上镀镉钝化板。

5.2.4 吊钩：S型，材质为不锈钢或玻璃。

5.2.5 砂纸：240号，氧化铝砂纸。

5.2.6 硅胶干燥剂：符合BB/T0049—2021中5.1.5.1的要求。

# 5.3 仪器设备

湿热试验箱：符合GB/T10586要求。

# 5.4 试样

5.4.1中性包装材料试样应有代表性，开始试验前试样应密封保存，试验前及试验过程中应防止试样受到污染。

5.4.2 试样尺寸为  $150\mathrm{mm}\times 150\mathrm{mm}$  0

# 5.5 试验步骤

# 5.5.1 试片的准备

5.5.1.1试验前对铜、铝合金试片用砂纸交替垂直方向打磨。打磨后试片上磨纹平行一致，表面没有凹坑、划伤、锈蚀，试片及孔边缘没有毛刺。

5.5.1.2有镀层或涂层及其他非金属材料不需加工打磨处理，可直接用模拟件或切取  $100\mathrm{mm}\times 50\mathrm{mm}$  试片。

5.5.1.3准备好的试片，除不能接触乙醇的材料外，用镊子夹持试片和脱脂棉（纱布），在3只盛有无水乙醇的容器中顺序清洗3次，然后用吹风机热风吹干，冷却至室温后进行试验。不能连续投入试验时，置于盛有硅胶干燥剂的干燥器内，  $^{\textrm{\scriptsize 8h}}$  内使用，超过  $^{\textrm{\scriptsize 8h}}$  重新打磨清洗。

# 5.5.2 试验

5.5.2.1 平行试验4组，其中一组为空白试验，空白试验不用中性包装材料包装试片。

5.5.2.2 用试样包装试片，使试片纵向中心线附近为双层，两边为单层，然后将试片长度方向的两端折叠到双层这一面，用线绳（例如尼龙绳）沿试片纵向把折叠层捆紧。

5.5.2.3 上述被包装好的试片应垂直悬挂在  $39^{\circ} \mathrm{C} \pm 2^{\circ} \mathrm{C}$  、相对湿度不低于  $95\%$  的湿热试验箱中，试验  $72 \mathrm{~h}$  。

5.5.2.4 试验结束后，拆开包装，检查试片是否有腐蚀、软化、龟裂、起泡、变形、分层等变质情况。

# 5.5.3 结果评定

平行试验的3组试片与空白试片对比。只要试片均无变质，或变质不比空白严重，均为相容。如有一组比空白严重，需按5.5.1和5.5.2重新试验。若两组以上均比空白严重或重新试验仍有一组比空白严重，均为不相容。

注：在本文件中，金属表面出现锈斑、蚀点或形成疏松的或粒状的产物，就认为是产生腐蚀；仅在金属表面产生颜色变化而没有其他腐蚀特征时，不认为是腐蚀。

# 6 可剥性塑料或涂料与固体材料的相容性

# 6.1 原理

将可剥性塑料或涂料与固体材料通过半浸方式处理后，置于特定温度的试验箱内一段时间，根据固体材料变化和空白试验进行对比，评价可剥性塑料或涂料与固体材料的相容性。

# 6.2 试剂和材料

6.2.1 无水乙醇：GB/T678，分析纯。6.2.2 水：GB/T6682，三级。6.2.3 固体材料试片（以下简称试片）：同5.2.3。6.2.4 砂纸：240号，氧化铝砂纸。6.2.5 玻璃容器：带盖，可容纳  $100 \mathrm{~mm} \times 50 \mathrm{~mm}$  尺寸试片。6.2.6 硅胶干燥剂：符合BB/T0049—2021中5.1.5.1的要求。

# 6.3 仪器设备

干燥箱：符合GB/T30435要求，温度波动度为士  $2^{\circ}C$  0

# 6.4 试样

可剥性塑料或涂料试样应有代表性，开始试验前应密封保存，试验前及试验过程中应防止试样受到污染。

# 6.5 试验步骤

# 6.5.1 试片的准备

按5.5.1进行。

# 6.5.2 试验

平行试验4组，其中一组为空白试验，空白试验不放置试样。

将试样注入干净的可密封的玻璃容器内，试样在玻璃容器的高度为试片长度的二分之一。将试片竖直放入试样中，使试片的一半露在液面上，把玻璃容器盖好并密封在  $38^{\circ}C\pm 2^{\circ}C$  的干燥箱中放置  $30d$  。

试验结束后，将试片取出，检查试片是否有腐蚀、软化、龟裂、起泡、变形、分层等变质情况。

# 6.5.3 结果评定

平行试验的3组试片与空白试片对比。只要试片均无变质，或变质不比空白严重，均为相容。如有一组比空白严重，需按6.5.1和6.5.2重新试验。若两组以上均比空白严重或重新试验仍有一组比空白严重，均为不相容。

# 7 气相防锈包装材料与金属材料的相容性

# 7.1 原理

将气相防锈包装材料与金属材料通过非接触组合方式处理后，置于特定温度、相对湿度的容器内一段时间，根据金属材料变化和空白试验进行对比，评价气相防锈包装材料与金属材料的相容性。

# 7.2 试剂和材料

7.2.1 无水乙醇：GB/T678，分析纯。

7.2.2 丙三醇：GB/T687，分析纯。

7.2.3 水：GB/T6682，三级。

7.2.4 金属试片（以下简称试片）：根据实际包装件内容物材料选定，尺寸为  $75\mathrm{mm}\times 13\mathrm{mm}\times 1.5\mathrm{mm}$  。如果没有特别指定，可选用下列材料：

符合GB/T5231—2022要求的T3纯铜板；符合GB/T3880.1—2023要求的2A12铝合金板；钢上镀锌钝化；钢上镀镉钝化试片。

7.2.5 吊钩：S型，材质为不锈钢或玻璃。

7.2.6 试片架：材质为不锈钢。

7.2.7 砂纸：240号，氧化铝砂纸。

7.2.8 硅胶干燥剂：符合BB/T0049—2021中5.1.5.1的要求。

7.2.9 标本瓶：符合  $\mathrm{JY / T0447 - 2011}$  的要求，规格为  $\phi 60\mathrm{mm}\times 210\mathrm{mm}$  。

7.2.10 玻璃皿：直径  $30\mathrm{mm}\pm 2\mathrm{mm}$  ，高  $10\mathrm{mm}\sim 20\mathrm{mm}$  。

# 7.3 仪器设备

7.3.1 干燥箱：符合GB/T30435的要求，温度波动度为  $\pm 2^{\circ}C$  。

7.3.2 分析天平：感量  $0.001\mathrm{g}$  。

# 7.4 试样

7.4.1 气相防锈包装材料试样应有代表性，开始试验前试样应密封保存，试验前及试验过程中应防止试样受到污染。

7.4.2 柔性气相防锈包装材料：试样尺寸为  $200\mathrm{mm}\times 60\mathrm{mm}$  。

7.4.3 气相防锈剂：试样量为  $0.10\mathrm{g}\pm 0.005\mathrm{g}$  。

# 7.5 试验步骤

# 7.5.1 试片的准备

按5.5.1进行。

# 7.5.2 试验

# 7.5.2.1 通用要求

平行试验4组，其中一组为空白试验，空白试验不放置气相防锈包装材料。

# 7.5.2.2 柔性气相防锈包装材料

试样含有气相缓蚀剂的一面向内贴紧标本瓶上部内壁，按图1组装试验装置。在标本瓶底部注入 $25\mathrm{mL}$  质量分数为  $45\%$  的丙三醇水溶液，在  $65^{\circ}C\pm 2^{\circ}C$  的干燥箱中放置  $2\mathrm{h}$  。将试片悬挂在预先于 $65^{\circ}C\pm 2^{\circ}C$  的干燥箱中预热  $2\mathrm{h}$  的标本瓶内，其中气相防锈包装材料试样与试片距离不超过 $30~\mathrm{mm}$  ，试片下端距丙三醇水溶液液面约  $20~\mathrm{mm}$  。将瓶盖盖好后，放入  $60^{\circ}C\pm 2^{\circ}C$  的干燥箱中，连续加热  $120\mathrm{h}$  。试验结束后，将标本瓶从干燥箱中取出，冷却至室温，打开标本瓶检查金属试片的腐蚀情况。

# 8 气相防锈包装材料与可热封的包装材料的相容性

# 8.1 原理

将气相防锈包装材料与可热封的包装材料通过包装方式处理后，置于特定温度的试验箱内一段时间，根据可热封的包装材料变化和空白试验进行对比，评价气相防锈包装材料与可热封的包装材料的相容性。

# 8.2 试剂和材料

钢板：尺寸为  $100\mathrm{mm}\times 50\mathrm{mm}\times (4\sim 6)\mathrm{mm}$

# 8.3 仪器设备

8.3.1 干燥箱：符合GB/T30435的要求，温度波动度为  $\pm 2^{\circ}\mathrm{C}$

8.3.2 分析天平：感量  $0.001\mathrm{g}$

# 8.4 试样

8.4.1 气相防锈包装材料试样应有代表性，开始试验前试样应密封保存，试验前及试验过程中应防止试样受到污染。

8.4.2 柔性气相防锈包装材料：试样尺寸为  $100\mathrm{mm}\times 120\mathrm{mm}$

8.4.3 气相防锈剂：试样量为  $0.25\mathrm{g}\pm 0.005\mathrm{g}$

# 8.5 试验步骤

# 8.5.1 柔性气相防锈包装材料

平行试验4组，其中一组为空白试验，空白试验采用无气相防锈性能的中性包装材料。

将可热封的包装材料剪成  $254\mathrm{mm}\times 130\mathrm{mm}$ ，并沿长边对折成口袋。将两边热封，制成一个长  $127\mathrm{mm}$  、宽  $130\mathrm{mm}$  的口袋。将钢板用试样包好，含有气相缓蚀剂的一面对着钢板。包扎时钢板纵向中心线附近搭接。把包好钢板的试样装进口袋内，用手压出袋内空气，并把口袋开口处热封密封。将准备好的试样组合件置于温度恒定在  $65^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$  的干燥箱内放置  $168\mathrm{h}$

试验结束后，待袋子冷却到室温后，剪开热封的一边，取出包装的钢板。检查可热封包装材料是否软化、龟裂、起泡、变形、分层等，焊缝是否分离。

# 8.5.2 气相防锈剂

平行试验4组，其中一组为空白试验，空白试验不放置气相防锈剂。

试样均匀分散在尺寸为  $100\mathrm{mm}\times 50\mathrm{mm}\times (4\sim 6)\mathrm{mm}$  的钢板一表面上，将钢板放入按8.5.1制成

的热封袋中, 其他试验程序同 8.5.1。

# 8.5.3 结果评定

平行试验的 3 组可热封的包装材料与空白可热封的包装材料对比。只要可热封的包装材料均无变质, 或变质不比空白严重, 均为相容。如有一个比空白严重, 需按 8.5.1 或 8.5.2 重新试验。若两个以上均比空白严重或重新试验仍有一个比空白严重, 均为不相容。
