# 四氢化邻苯二甲酸酐危险特性分类方法

Classification method for hazardous characteristics of tetrahydrophthalic acid anhydride

# 前言

本标准按照GB/T1.1—2009给出的规则起草。

本标准由全国危险化学品管理标准化技术委员会(SAC/TC251)提出并归口。

本标准起草单位: 常州进出口工业及消费安全检测中心、常州出入境检验检疫局、中国化工经济技术发展中心、广东出入境检验检疫局技术中心。

本标准主要起草人: 刘君峰、张敏、曹梦然、王红松、李政军、叶树亮、杨遂军。

# 引言

四氢化邻苯二甲酸酐(简称四氢苯酐)主要用于生产醇酸树脂、不饱和聚酯树脂、涂料、杀虫剂、硫化调节剂、增塑剂和表面活性剂,是常见的有机合成原料中间体。

四氢化邻苯二甲酸酐是白色片状固体或结晶,分子式  $\mathrm{C}_{8} \mathrm{H}_{8} \mathrm{O}_{3}$ ,相对分子质量152.16,CAS号935- 79- 5,微溶于水。在四氢苯酐生产的工艺中,马来酸酐是主要合成原料之一,也是常见杂质之一。

联合国《关于危险货物运输的建议书规章范本》第3.3章"适用于某些物品的特殊规定"第169条明确规定,如果固态邻苯二甲酸酐或四氢苯酐中马来酸酐含量小于或等于  $0.05\%$ ,其危险性分类结果为非危险品,相反则分类为第8类腐蚀品,联合国编号(UN No.)为2698,包装类别为Ⅲ类。

为了对四氢化邻苯二甲酸酐危险特性的准确鉴定,建立四氢化邻苯二甲酸酐中杂质马来酸酐含量的测定方法是关键,特制定本标准。

# 四氢化邻苯二甲酸酐危险特性分类方法

# 1范围

本标准规定了固态四氢化邻苯二甲酸酐的危险货物危险特性分类方法。

本标准适用于固态四氢化邻苯二甲酸酐危险货物危险特性的分类。

# 2方法概要

2 方法概要称取一定量的固态四氢化邻苯二甲酸酐配成乙腈溶液,经有机过滤膜过滤后,用气相色谱进行分析,外标法定量。根据固态四氢化邻苯二甲酸酐中马来酸酐的含量,判定其危险特性。本方法中马来酸酐的定量检测限为  $5\mathrm{mg / kg}$  。四氢化邻苯二甲酸酐和马来酸酐的常见理化特性参见附录A。

# 3试剂和材料

3.1 乙睛:色谱纯。

3.2 马来酸酐标准品:纯度  $\geqslant 99\%$  。

3.3 马来酸酐标准储备溶液:准确称取  $10\mathrm{mg}$  马来酸酐标准品,精确至  $0.1\mathrm{mg}$  ,置于  $100~\mathrm{mL}$  容量瓶中,用乙睛稀释至刻度,混匀。该溶液的浓度为  $100\mathrm{mg / L}$  。

3.4标准工作溶液:分别移取  $0.25\mathrm{mL},0.5\mathrm{mL},1.0\mathrm{mL},2.0\mathrm{mL},5.0\mathrm{mL}$  和  $10.0~\mathrm{mL}$  马来酸酐标准储备溶液于6个  $100~\mathrm{mL}$  容量瓶中,用乙睛定容至刻度,所配标准工作溶液浓度为  $0.25\mathrm{mg / L},0.5\mathrm{mg / L}$ $1.0\mathrm{mg / L},2.0\mathrm{mg / L},5.0\mathrm{mg / L}$  和  $10.0~\mathrm{mg / L}$  。

# 4仪器和设备

4.1气相色谱仪(GC):配有氢火焰离子化检测器(FID)。

4.2有机过滤膜:  $0.45\mu \mathrm{m}$  。

4.3分析天平:精确至  $0.1\mathrm{mg}$  。

# 5分析步骤

# 5.1 测试液的制备

5.1 测试液的制备准确称取  $1\mathrm{g}$  四氢化邻苯二甲酸酐样品,精确至  $0.1\mathrm{mg}$  ,置于  $25\mathrm{mL}$  容量瓶中,用乙睛溶解并定容至刻度,混匀,待上机分析。

# 5.2气相色谱条件

a)色谱柱:DB-17MS  $30\mathrm{m}\times 0.25\mathrm{mm}$  (内径)  $\times 0.25\mu \mathrm{m}$  (膜厚)毛细管柱,或相当者;

b)柱温:初始温度  $70~\mathrm{^{\circ}C}$  ,保持  $2\mathrm{min}$  ,以  $20~^{\circ}\mathrm{C / min}$  升温至  $220~^{\circ}\mathrm{C}$  ,保持  $2\mathrm{min}$

c)进样口温度:  $240~^{\circ}\mathrm{C}$

d)检测器温度:  $240~^{\circ}\mathrm{C}$

e)载气:氮气(纯度  $>99.99\%$  )

f) 柱流速:  $1.0 \mathrm{~mL} / \mathrm{min}$ , 恒流模式; 
g) 燃烧气: 高纯氢, 流速  $30 \mathrm{~mL} / \mathrm{min}$ ; 空气: 流速  $300 \mathrm{~mL} / \mathrm{min}$ ; 
h) 进样量:  $1 \mu \mathrm{L}$ ; 
i) 不分流进样,  $0.75 \mathrm{~min}$  后开阀。

# 5.3 绘制标准工作曲线

按照5.2所列测定条件,将标准工作溶液(3.4)按照浓度由低到高的顺序依次进样测定。以标准溶液中马来酸酐的浓度为横坐标,单位为毫克每升  $(\mathrm{mg} / \mathrm{L})$ ,以对应的马来酸酐色谱峰面积为纵坐标,绘制标准曲线。典型的气相色谱图参见附录B。

按式(1)计算回归参数:

\[ y_{\mathrm{s}}=a \times x_{\mathrm{s}}+b \]

式中:

$y_{\mathrm{s}}$  ——马来酸酐的色谱峰面积;

$a$  ——回归曲线的斜率;

$x_{\mathrm{s}}$  ——标准工作溶液中马来酸酐的浓度,单位为毫克每升  $(\mathrm{mg} / \mathrm{L})$ ;

$b$  ——回归曲线的截距。

# 5.4 试样的测定

将样品测试液(5.1)同样按照5.2所列气相色谱条件进样分析,得样品中马来酸酐的色谱峰面积。

# 5.5 注意事项

当样品测试液(5.1)中马来酸酐的浓度大于标准曲线的浓度上限时,应将测试液用乙腈进行适当稀释,确保稀释后的测试液中马来酸酐含量在标准曲线的浓度范围内。

# 6 结果判定

四氢化邻苯二甲酸酐中马来酸酐含量可按式(2)计算:

$$
x = \frac{(y - b) \times 25 \times n}{a \times m} \tag{2}
$$

式中:

$x$  ——四氢化邻苯二甲酸酐中马来酸酐的含量,单位为毫克每千克  $(\mathrm{mg} / \mathrm{kg})$ ;

$y$  ——样品测试液中马来酸酐的色谱峰面积;

$b$  ——回归曲线的截距;

25 ——测试液定容体积,单位为毫升  $(\mathrm{mL})$ ;

$n$  ——测试液的稀释倍数;

$a$  ——回归曲线的斜率;

$m$  ——称样量,单位为克  $(\mathrm{g})$ 。

# 7 危险特性判定

7.1 如果四氢化邻苯二甲酸酐中马来酸酐含量小于等于  $500 \mathrm{mg} / \mathrm{kg}$  时,则应分类为非危险货物。

7.2 如果四氢化邻苯二甲酸酐中马来酸酐含量大于  $500 \mathrm{mg} / \mathrm{kg}$  时,则应分类为第8类腐蚀品,联合国编号(UN No.)2698,包装类别为Ⅲ类。
