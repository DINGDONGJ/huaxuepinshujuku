# 烟花爆竹用硫化锑

# 1范围

本标准规定了烟花爆竹用硫化锑的产品分级、技术要求、试验方法、检验规则和标志、包装、运输、贮存。

本标准适用于专供烟花爆竹产品所用的硫化锑。

# 5.1外观

目视检验。

按YS/T239.1的规定测定。

# 5.4水分的测定

# 5.4.1分析方法

称取  $10.0\textbf{g}$  试样于已恒重的称量瓶中,在电热恒温干燥箱中于  $105~\mathrm{^{\circ}C}$  烘干  $1\mathrm{~h~}$  ,取出,在干燥器中冷却  $0.5\mathrm{~h~}$  ,称量样品质量,并按式(1)计算水分含量  $(X)$  ,数值以  $\%$  表示:

$$
X = \frac{m - m_{1}}{m}\times 100\% \tag{1}
$$

式中:

$m$  ——样品质量,单位为克(g);

$m_{1}$  ——烘干后的样品质量,单位为克(g)。

# 5.5 粒度的测定

称取  $10.0 \mathrm{~g}$  试样,用孔径为  $0.125 \mathrm{~mm}$  筛子筛后称量筛上物的质量,按式(2)计算筛上物的质量分数  $(w)$ ,数值以  $\%$  表示:

\[ w=\frac{m_{1}}{m_{0}} \times 100\% \] (2)

式中:

$m_{1}$  ——筛上物的质量,单位为克(g);

$m_{0}$  ——样品质量,单位为克(g)。

# 6 检验规则

6.1 产品应经出厂质检合格,检验项目包括外观及表1中所列项目。

6.2 所有项目符合要求,判该批产品质量合格。

6.3 产品应组批,每批由同等级硫化锑组成,批量不得超过  $2000 \mathrm{~kg}$  。

6.4 抽样方法:抽取包装件数的  $10\%$  (但不得少于2件)。用专用工具在每个包装件的上、中、下部位取样、混匀,用四分法缩分样品,样品量不小于  $200 \mathrm{~g}$  。

# 7 包装、标志、运输、贮存

# 7.1 包装

采用防潮密封包装,包装应牢固、坚实,每件净重不得超过  $50 \mathrm{~kg}$  。

# 7.2 标志

包装上应注明:生产企业名称、地址、产品名称、级别、净含量、批号、生产日期、执行标准编号,并附有防潮、防水标志。且每个包装中应有产品合格证。

# 7.3 运输

运输中注意防水、防潮,不可与氧化剂混运。

# 7.4 贮存

应贮存在干燥的库房中,保质期为两年,超期应经检验合格方可使用。
