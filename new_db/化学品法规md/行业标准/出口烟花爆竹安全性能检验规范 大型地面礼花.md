# 前言

SN/T3057《出口烟花爆竹制品安全性能检验规范》共分为4部分:

第1部分:爆竹;

第2部分:烟雾烟花;

第3部分:大型地面礼花;

第4部分:罗马烛光。

本部分为SN/T3057的第3部分。

本部分按照GB/T1.1- 2009给出的规则起草。

本部分由国家认证认可监督管理委员会提出并归口。

本部分起草单位:中华人民共和国江西出入境检验检疫局。

本部分主要起草人:刘捷光、陈志勇、吴劲松、吕中、曹锋、张军连、彭徽。

# 出口烟花爆竹制品安全性能检验规范第3部分:大型地面礼花

# 1范围

SN/T3057的本部分规定了大型地面礼花的检测项目、样品准备、检验方法和结果评定。本部分适用于纸筒内径大于  $30~\mathrm{mm}$  的地面礼花。

# 5技术要求

# 5.1外观与外形

5.1.1产品的外形无明显变形,无损坏。

5.1.2产品外观整洁,表面无漏药、无霉变、无污染。

5.1.3 招纸粘贴吻合平整,文字图案清晰。

5.1.4应采用符合危险运输包装要求的运输包装。

# 5.2引火线

5.2.1引火线表面整洁干燥,无破损、无霉变。

5.2.2 不得使用氯酸盐引火线。

5.2.3 应安装主引火线和备用引火线,且引火线位置应醒目或有明显标记。

5.2.4 引火线应在  $6 \mathrm{~s} \sim 15 \mathrm{~s}$  内引燃主体,或采用电点火方式。

5.2.5 引火线应牢固安装,应能承受  $227 \mathrm{~g}$  拉力  $10 \mathrm{~s}$  而不脱落。

5.2.6 引火线应有护引套保护。

# 5.3 筒体

5.3.1 筒体应粘合捆扎牢固,在正常条件下装卸、运输、贮存及燃放过程中不开裂、不散筒。

5.3.2 筒体应由纸、纸板或塑料制成,不能采用金属材料。

5.3.3 单个筒体壁厚不小于其内径的  $5 \%$

# 5.5 主体平稳性

产品置于  $60^{\circ}$  的斜板上不得倾倒。

# 5.6 禁限用药

应符合进口国要求。

# 5.7 产品声级

在离地  $1 \mathrm{~m}$  高,离燃放点  $15 \mathrm{~m}$  处测定至少5次有效值,其最大值不能超过  $120 \mathrm{~dB}$

# 6 标志

6.1 运输包装标注的内容应包括:产品厂号批号年号、产品名称或货号、含量、爆炸标志、国际危险标记。

6.2 销售包装的标注应符合进口国要求。

# 7 检验

# 7.1 检验项目

检验项目包括:内外包装、标志、外观、部件、引火线、燃放性能药种、药量。

# 8 试验结果评估方法

8.1 缺陷类别判定和验收规则按GB/T10632规定执行。

8.2 一个样品同时存在几种缺陷时,以最重的缺陷计算,且只作为一个不合格品统计。

# 9 试验报告

报告应包括以下内容:

试验样品名称、数量、规格;

生产企业名称;

运输包装信息;

试验结果的记录;

说明所用试验方法与本标准的差异;

试验日期、试验人签字、试验单位盖章。
