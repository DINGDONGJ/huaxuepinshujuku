## 📦 一键安装（Windows）

### 步骤1：准备工作
1. ✅ 确保已安装 **MySQL 8.0+**
2. ✅ 确保已安装 **Python 3.8+**

### 步骤2：创建数据库
打开MySQL命令行，执行：
```sql
CREATE DATABASE 危化品简化数据库 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 步骤3：初始化
```bash
# 1. 双击运行（初始化数据库）
install_deps.bat

# 2. 导入数据库
mysql -u root -p 危化品简化数据库 < init_simple_db.sql

# 3. 可选：导入样例数据
mysql -u root -p 危化品简化数据库 < sample_data.sql
```

### 步骤4：配置数据库密码
编辑 `app.py`，第26行：
```python
'password': '1234',  # 改为你的MySQL密码
```

### 步骤5：启动应用
```bash
# 双击运行
start_web.bat
```

### 步骤6：访问系统
浏览器打开：http://localhost:5000

## 🐛 快速排错

### 问题1：无法连接数据库
**解决**：
1. 检查MySQL是否启动
2. 确认密码是否正确（`app.py`第26行）
3. 确认数据库名称：`危化品简化数据库`

### 问题2：依赖安装失败
**解决**：
```bash
# 使用国内镜像
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

### 问题3：PDF打不开
**解决**：
1. 确认 `pdf/` 目录下有PDF文件
2. 检查浏览器控制台（F12）是否有错误
3. 尝试刷新页面（Ctrl + F5）

### 问题4：搜索很慢
**解决**：
- **首次搜索慢**：正常现象，正在建立缓存
- **第二次还慢**：刷新页面会清除缓存，不要刷新
- 查看是否显示"⚡ 使用缓存加速"

## 💡 使用技巧

### 技巧1：快速查找
- **CAS号查询**：最精确，如 `64-17-5`
- **中文名**：支持模糊搜索，如 `甲`
- **英文名**：如 `Ethanol`
- **分子式**：如 `C2H6O`

### 技巧2：PDF操作
- **翻页**：箭头键 `←` `→`
- **缩放**：`Ctrl` + 鼠标滚轮
- **跳转**：点击侧边栏搜索结果

### 技巧3：提升搜索速度
1. 打开PDF后，**不要刷新页面**
2. 多搜索几个化学品，体验缓存威力
3. 同一PDF的所有搜索都很快

### 技巧4：批量导入数据
```bash
# 1. 批量爬取
for chemical in 甲苯 乙醇 苯 甲醛; do
    python scrape_to_json.py $chemical
done

# 2. 在Web界面批量上传JSON文件
```
