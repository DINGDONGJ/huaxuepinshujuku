# 3 方法原理

激光器发射激光到气体样品池，激光与气体分子碰撞后发出拉曼散射光，不同分子的拉曼散射光谱是特定的，通过检测样品中不同分子的特定光谱频率与强度，并与已知标准气的拉曼光谱频率及强度对比，从而得到样品的组分及含量。

# 4 仪器与设备

# 4.1 激光拉曼气体分析仪

激光拉曼气体分析仪应能检测到表1中规定的天然气组分。

# 4.2 过滤器

过滤器需满足可滤除粒径在大于  $0.1\mu \mathrm{m}$  的固体颗粒物。

# 4.3 气体减压器

对于含硫天然气，应选择耐硫化氢腐蚀的气体减压器。

# 5 试剂与材料

# 5.1 标准气

5.1 标准气分析需要的标准气可采用国家二级标准物质，或按GB/T5274制备，标准气的所有组分应处于均匀的气态。对于样品中的被测组分，标准气中相应组分的浓度应与实际样品气中浓度接近，应不低于样品中组分浓度的一半，也不大于该组分浓度的2倍。标准气中组分的最低浓度应大于  $0.02\%$ 。

# 5.2 零点气

氩气或其他惰性气体，纯度不低于  $99.999\%$ $(\phi)$ 。

# 5.3 氢氧化钠溶液

氢氧化钠溶液（  $200\mathrm{g / L}$  )，称取氢氧化钠（化学纯）溶于水中配制。

# 6 测定步骤

# 6.1 准备

6.1 准备按照分析仪器要求，调整激光拉曼天然气分析仪至实验条件，并使分析仪运行稳定，将零点气（见5.2）与仪器相连接，进行零点标定。

# 6.2 标定

6.2 标定按仪器说明书给出的步骤，进入仪器的标定状态，将标准气（见5.1）与激光拉曼气体分析仪相连，调节压力和流量至实验条件，充分吹扫后标定。

# 6.3 进样与样品分析

6.3 进样与样品分析依次连接天然气样品容器，减压阀、过滤器和分析仪，调节压力和流量至实验条件范围内，天然气样品通过调压过滤后，进入仪器的样品池，充分吹扫后进行分析。取样应符合GB/T13609的规定。

# 6.4 尾气处理

6.4 尾气处理6.2和6.3中的通过仪器出口排出的含硫气体，使用氢氧化钠溶液（见5.3）吸收。

# 7 结果表示

7 结果表示在测量状态，仪器显示的分析结果即样品中各组分的含量，记录3次分析结果，取平均值作为最终测量结果，其有效位数按标准气的有效位数取舍。
