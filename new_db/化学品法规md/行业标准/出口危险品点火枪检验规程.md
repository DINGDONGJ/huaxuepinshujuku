# 前言

SN/T0761系列标准共分为3部分：

第1部分：出口危险品打火机检验规程；第2部分：出口危险品打火机儿童安全性试验方法；第3部分：出口危险品点火枪检验规程。

本部分为SN/T0761系列标准的第3部分。

本部分按照GB/T1.1—2009给出的规则起草。

本部分参照加拿大《危险品（点火枪）规则》、美国《联邦法规》及国际标准化组织ISO22702：2003(E)《点火枪消费安全特性》而制定的。

本部分由国家认证认可监督管理委员会提出并归口。

本部分起草单位：中华人民共和国天津出入境检验检疫局、中华人民共和国宁波出入境检验检疫局、中华人民共和国温州出入境检验检疫局。

# 3 定义

下列术语和定义适用于本文件。

3.1

# 点火枪 utility lighter

充灌有不大于  $10\mathrm{g}$  的丁烷或其他易燃气体或液体，可重复充灌或没有充灌系统，并能承受一定压力，带有燃料释放、引燃装置，用手持并以手动点火系统进行点燃的点火装置，主要用于点燃下列物品如：蜡烛、燃气灶具、碳式气体烧烤炉、野营烤炉、灯笼和燃气装置和器皿或标灯。当为加长型时，大于或等于  $100~\mathrm{mm}$  。

3.2

后混式点火枪 postmixing burner utility lighter燃料和空气在点燃处进行混合的点火枪。

3.3

前混式点火枪 premixing burner utility lighter燃料和空气在点燃前已混合的点火枪。

3.4

一次性点火枪 utility lighter，disposable不能进行反复充灌的点火枪。

3.5

可重复充灌式点火枪 utility lighter，refillable能从外部重新注入燃料或者能更换燃料箱的点火枪。

3.6

可调节点火枪 utility lighter，adjustable通过手动操作来调节火焰高度的点火枪。

3.7

不可调节点火枪 utility lighter，non- adjustable无火焰调节装置的点火枪。

3.8

跳火 flaring

稳定火焰条件下火焰高度的变化。

3.9

喷火、溅火 spitting, spattering

无雾化燃料飞溅或液体燃料以小液滴燃烧状态从主火焰中脱离的一种现象。

3.10

延续燃烧 sustained self- ignition

按正常动作熄灭点火焰后的燃烧。

# 4要求

4.1 所有点火枪应附有进口国官方语言或英语标注的警告“远离儿童可及范围及高温环境”或其他同一含义的警告，用以表述合适的使用方法及注意事项，且应与其他标记从尺寸、颜色、背景、位置明显区分开（要求尺寸至少  $10 \mathrm{~mm}$ ，背景为白色，文字说明为黑色或红色）。标记应在点火枪的使用有效期内保持清晰可见，同时点火枪或其包装上应注有正体字标注的生产商名称，或进口国的注册商标。

4.2 每一个点火枪都应对调节燃烧高度的装置进行永久性标注，并在其整个有效期内保持清晰。应采用简单易懂的标记来表明装置增加或减小燃烧高度的操作方法。

4.3 为减少意外点燃或自燃现象的发生，点火枪应用手动装置进行点燃，装置至少应遵循以下要求中的一项：

a) 两次或多次独立操作的动作来完成点火；b) 压力装置产生火焰的压力应大于或等于  $15 \mathrm{~N}$ （见图1）。

4.5点火枪应附有特别标记词“警告（WARNING）”和表达正确使用方法的安全说明，安全说明应包括以下语句：

“远离儿童”或“放置于儿童触及不到的地方”（此语句应突出并有明显区别）；“点燃时远离脸部及衣物”；“不可用来点燃香烟、雪茄或烟斗”。

针对不同适用类型的点火枪，安全说明可使用下列语句：

a) “内装灌压可燃气体”；b) “不可置于超过  $50^{\circ}C$  环境中，不可在阳光下长时间暴晒”；c) “不可刺穿或投入火中”。

还可以使用下列语句：

a) “可见火焰上方温度很高，应予以格外注意以避免烧伤或火灾”（适用于所有前混式点火枪）。b) “持续点燃时间禁止超过  $30~\mathrm{s}$ ”（适用于所有前混式点火枪）。c) “燃料充灌后，须等待  $2\mathrm{min}$  方可再行使用”（可重复充灌点火枪必须具有此语句）。

# 5 抽样

# 5.1 抽样批

以相同材料、相同结构、相同生产工艺生产的点火枪为一检验批。

# 5.2 抽样数量

对一次性点火枪，每一检验批的抽样数量为60个。对可重复灌注点火枪，每一检验批的抽样数量为60个。

# 5.3 抽样方法

从整个抽样批中随机抽取。

# 5.4 样品的使用

样品的使用按图7进行。

# 5.5 检验项目

防止儿童开启装置试验、燃烧高度试验（包括火焰高度试验、爆火、溅火和跳火试验、熄灭试验三项）、跌落试验、温度试验、持续燃烧试验、压力试验、燃液容量试验、循环燃烧试验、重复注气试验和燃料相容性试验共12项。

# 5.6 样品的预处理及试验环境

5.6.1 未充灌燃料的样品应充灌生产商说明书规定的燃料。

5.6.2 除防止儿童开启试验外，样品均应在  $23^{\circ}C\pm 2^{\circ}C$  的温度环境中至少预处理  $10\mathrm{h}$  以上。

5.6.3 进行跌落试验时，试验样品进行6.2.2规定的预处理前，还应预先在  $- 10^{\circ}C\pm 2^{\circ}C$  的温度环境中至少预处理  $10\mathrm{h}$  。

5.6.4 检验环境温度为  $23^{\circ}C\pm 2^{\circ}C$  ，通风良好，有遮光设施。

# 5.7 检验内容

# 5.7.1 防止儿童开启装置试验

5.7.1.1 检验方法：

a）感官检测，观察防止儿童开启装置有无松动，并使点火枪打火至少3次；b）如果感官检测符合5.7.1.2合格准则后需要进行非感官检测，则依据EN13869：2002进行试验。

5.7.1.2 试验合格准则：

a）点火枪的防止儿童开启装置应无松动；b）点火枪至少用两种分离独立的行动来完成点火；c）点火枪的点火机构每次操作后都能自动复位；d）经本标准规定的除压力试验、燃液容量试验外的所有试验后，能继续有效。

# 5.7.2 燃烧高度试验

# 5.7.2.1 检测仪器

燃烧高度试验箱和秒表。

# 5.7.2.2 检验方法

# 5.7.2.2.1 总则

燃烧高度试验包括火焰高度试验、爆火、溅火和跳火试验、熄灭试验三项。

# 5.7.2.2.2 火焰高度试验

试验如下：

a）若点火枪装有燃烧高度调节装置，首先对未经调节的出厂火焰进行测试，然后将燃烧高度调节装置调至最大位置进行试验，然后再将燃烧高度调节装置调至最小位置进行试验。如果点火枪燃烧高度调节装置是带螺纹的或类似装置，并且在最大定位时没有明确的中止位置，按下列程序进行试验：- 对未经调节的出厂火焰高度；- 在最小定位时测量燃烧高度；- 旋转燃烧高度调节器加大  $360^{\circ}$ ，并测量相应的火焰高度。

注：最后点火枪火焰高度调节装置可能脱离点火枪。

b）竖直点燃点火枪并持续  $5\mathrm{s}$  。c）测量并记录可见火焰的顶端至点火枪燃料孔顶端的最大距离。d）按正常动作熄灭火焰，测量并记录按正常动作熄灭点火枪后延续燃烧的时间。e）进行燃烧高度试验时应注意：- 产品的位置能保证产生垂直向上的火焰；- 燃烧高度的测量精确到  $5\mathrm{mm}$  。- 所有的燃烧试验应在光线减弱的情况下进行。

# 5.7.2.2.4 爆火、溅火和跳火试验

# 5.7.2.2.4.1 试验方法

试验如下：

a) 调节火焰高度至最大高度；b) 点燃点火枪，用任何手动姿势保持燃烧  $10 \mathrm{~s}$  ；c) 按正常动作熄灭点火枪；d) 观察是否出现任何爆火、溅火现象。如果试验样品无缺陷，则继续重新在  $(23 \pm 2)^{\circ} \mathrm{C}$  环境中稳定  $5 \mathrm{~min}$  ；a) 点燃样品，使火焰竖直向上；b) 将样品向下旋转至与水平成  $45^{\circ}$  角（见图8），观察稳定火焰的高度或火焰的平均高度，保持燃烧  $10 \mathrm{~s}$  ；

![](images/8fa122b37d05c1a0758212773c0125f116a70ea689f4317e004dea969c1d7e12.jpg)  
图8 样品试验方式

c) 熄灭样品，恢复垂直向上位置；d) 观察是否跳火超过  $50 \mathrm{~mm}$ ，或者火焰高度超过最大火焰高度。如果试验样品无缺陷，则继续重新在  $(23 \pm 2)^{\circ} \mathrm{C}$  环境中稳定  $5 \mathrm{~min}$  ；a) 倒置样品  $10 \mathrm{~s}$  ；b) 旋转样品至直立状态，点燃样品；c) 燃烧  $5 \mathrm{~s}$ ，观察火焰高度；d) 观察是否  $5 \mathrm{~s}$  内跳火超过  $50 \mathrm{~mm}$ ，或者火焰高度超过最大火焰高度。

# 5.7.2.2.4.2 合格准则

不应出现任何爆火、溅火现象，跳火不应超过  $50 \mathrm{~mm}$ ，火焰高度不能超过最大火焰高度。

# 5.7.2.2.5 熄灭试验

# 5.7.2.2.5.1 对于后混式点火枪

将样品分为两组，样品组1试验程序如下：a) 设定火焰高度  $100 \mathrm{~mm}$ ，或当最大火焰高度小于  $100 \mathrm{~mm}$  时设定其最大火焰高度；

b）冷却  $1\mathrm{min}$  后点燃点火枪，使样品呈水平向下  $45^{\circ}$  的方向，点燃样品并保持燃烧  $20\mathrm{~s~}$  ，再以正常方式熄灭火焰。测量并记录任何延续燃烧现象。样品组2试验程序如下：a）点火枪火焰高度调至最大；b）冷却  $1\mathrm{min}$  后点燃点火枪，使样品呈水平向下  $45^{\circ}$  的方向，点燃样品并保持燃烧  $10\mathrm{~s~}$  c）按正常动作熄灭点火枪，测量并记录任何延续燃烧现象。

# 5.7.2.2.5.2 对于前混式点火枪

a）设定火焰高度  $75~\mathrm{mm}$  ，或当最大火焰高度小于  $75~\mathrm{mm}$  时设定其最大火焰高度；b）冷却  $1\mathrm{min}$  后点燃点火枪，使样品呈水平向下45度的方向，点燃样品并保持燃烧  $20\mathrm{~s~}$  ，再以正常方式熄灭火焰，测量并记录任何延续燃烧现象。

# 5.7.2.2.5.3 合格准则

要求延续燃烧不超过  $3\mathrm{~s~}$  ，对于有风挡点火枪，则要求火焰在风挡内不应延续燃烧超过  $3\mathrm{~s~}$  。

# 5.7.3 跌落试验

# 5.7.3.1 检测仪器

冷冻箱、跌落试验仪（配备计算机测量系统）。

# 5.7.3.2 检验方法

5.7.3.2.1 将样品分成两组进行跌落试验：

样品组1：待测样品应当在  $(23\pm 2)^{\circ}C$  环境中至少稳定  $10\mathrm{~h~}$  。对于可调节点火枪，应将火焰调至允许的最大高度。样品组2：样品应当在  $(- 10\pm 2)^{\circ}C$  温度下保持  $24\mathrm{~h~}$  ，然后在  $(23\pm 2)^{\circ}C$  温度下稳定至少10个  $\mathrm{h}$  。对于可调节点火枪，应将火焰调至  $50~\mathrm{mm}$  的最大高度。

5.7.3.2.2 样品从  $(1.5\pm 0.1)\mathrm{m}$  高处自由跌落至混凝土地表面，3次跌落样品初始姿态为：

a）竖直向下；b）竖直向上；c）水平。

5.7.3.2.3 放置天平测量系统进行称量。

# 5.7.3.3 合格准则

合格准则：

a）不应出现燃料箱破裂/爆裂或者自燃现象；b）跌落试验后  $5\mathrm{min}$  内，称量燃料泄漏率不应超过  $15\mathrm{mg / min}$  c）附有罩壳的样品跌落过程中罩壳应关闭。

# 5.7.4 温度试验

# 5.7.4.1 检测仪器

高温试验箱。

# 5.7.4.2 检验方法

进行点火枪温度试验的程序如下：

# 5.7.6.1 检测仪器

# 5.7.6.2 试验方法

点火枪压力试验按如下程序进行：

5.7.6.2 试验方法点火枪压力试验按如下程序进行：a) 解除防止儿童开启装置，排空燃料箱中的燃料；b) 在点火枪燃料箱大面上打孔，注意避开在燃料箱隔墙上打孔（在钻孔前除去燃料箱的外表装饰）；c) 将点火枪垂直放置于压力试验装置中进行测试；d) 以不超过  $69\mathrm{kPa / s}$  的速度给点火枪注氮加压至  $1500\mathrm{kPa}$ ，并关掉气源（如果无论何时，若加压时或加压后钻的周围发现泄漏，那么使设备减压，拧紧压紧装置少许，并重新加压）；e)  $1\mathrm{min}$  后记录点火枪的内部压力，记录泄漏位置。

# 5.7.7 燃液容量试验

# 5.7.7.1 检测仪器

分析天平、台钻[配备  $3.06\mathrm{mm}(1 / 8^{\prime \prime})$  的钻头]、注射器。

# 5.7.7.2 试验方法

试验方法如下：

a）测量点火枪质量  $m_{1}$ ，排空燃料，再测量排空燃料后点火枪质量  $m_{2}$ ，按  $23^{\circ}C\pm 2^{\circ}C$  时燃料的密度  $(0.54 / \mathrm{cm}^3)$ ，利用式(1)计算液体容积  $V_{1}$

$$
V_{1} = (m_{1} - m_{2}) / 0.54
$$

b）取出燃料箱打孔，然后称量  $m_{3}$

c）用注射器向燃料箱内注蒸馏水，确认燃料箱内无气泡，然后称量  $m_{4}$

d）利用式（2）计算点火枪燃料箱的容积  $V_{0}$

$$
V_{0} = (m_{4} - m_{3}) / 1
$$

# 5.7.7.3 合格准则

$V_{1} / V_{0}$  不应超过  $85\%$

# 6 检验结果的判定

6.1点火枪经上述12项试验后，每项试验全部合格，则判定该批点火枪合格，如有1项及1项以上不合格，则判定该批点火枪不合格。

6.2不合格的处置：如有1项试验不合格，则加倍抽样重新进行检验，如仍有1项或1项以上不合格，则判定该批点火枪不合格。
