# 液态沥青和稀释沥青 闪点测定阿贝尔闭口杯法

# 1 范围

本标准规定了使用阿贝尔闭合式试验器测定液态沥青和稀释沥青闪点的方法。本标准适用于闪点低于或等于  $110~\mathrm{^{\circ}C}$  的液态沥青和稀释沥青闪点的测定。

# 2 规范性引用文件

下列文件对于本文件的应用是必不可少的。凡是注日期的引用文件,仅注日期的版本适用于本文件。凡是不注日期的引用文件,其最新版本(包括所有的修改单)适用于本文件。

NF M07- 033 石油产品 与试验方法有关的精度数据的测定和应用(Petroleum products—Determination and application of precision data in relation to methods of test)

# 3 术语和定义

下列术语和定义适用于本文件。

3.1

闪点 flash point

试样在规定条件下加热到其蒸汽与空气的混合物接触火焰发生闪火时的最低温度。

# 4 试验原理

密闭容器中将试验样品与流动空气隔开,慢慢搅动并均匀地加热。按照一定的间隔时间引入点火源,并记录样品闪火的最低温度。

# 5.3 盖子

5.3.1 容器盖子保证容器的密闭性。配有向下的封口环, 与容器的法兰盘对齐。法兰盘用银焊或铅焊接, 可以与盖子连接在一起。盖子上部装有温度计的座槽和支撑点火器的轴销。导轨上固定着一对导销、一个白色滚珠和一个连接搅拌装置的套管。

5.3.2 盖子上部有 3 个方形孔, 对称分布在盖子直径上, 一个在中心位置, 另外两个相对紧靠在法兰盘的内端。导轨在定位销的相对位置移动可开启或关闭盖子上的方形孔。导轨的行程被适配的限位块限制, 其到达朝外的行程终点时, 盖孔完全打开, 到达相反位置时, 盖孔完全关闭。

5.3.3 支撑点火器灯的轴销固定于定位销的上部, 其可使灯能自由摆动, 且需装有灯芯嘴。如果导轨移动露出方孔, 摆动的灯会与固定在导轨上的限位块接触。灯在中央开口的上部翻转, 翻转到最低位置时, 灯芯嘴需处于盖子和中央孔的中间。火源处于孔内的中央位置。可以使用煤气点火器。温度计的坐槽为插口座, 且需按一定角度安装。温度计的坐槽在这个角度上正好能使温度计竖着从盖中心穿过。装在盖子上的白色滚珠直径为  $3.8 \mathrm{~mm} \pm 0.2 \mathrm{~mm}$  。盖子上面除了滚珠, 其他所有部分使用材料均为黄铜, 滚珠可以用象牙或其他合适的材料。盖子如图 3 所示。盖子及温度计插座规格尺寸见表 2。

5.3.4 套管用于连接叶片式机械搅动器 (图 4), 搅拌器用于在加温过程温度分配更均匀。套管尽量靠近盖子的外沿并与温度计座槽相对。套管的倾角及搅拌器的规格要求如下: 旋转中连杆不接触液位计, 叶片处于温度计槽下面且两者不能接触。搅拌器由连杆组成, 连杆下端焊接 4 个叶片。套管的下截面和卡环的上截面应尽量避免在旋转中产生任何竖向间隙。所有机械装置的配置能确保试验中连杆转速达到  $70 \mathrm{r} / \mathrm{min} \sim 80 \mathrm{r} / \mathrm{min}$  。套管及搅拌装置规格尺寸见表 3。

5.5.2 纤维或胶木垫圈右截面为角尺形, 装于加热槽的中央开口。容器与垫圈应都位于加热槽内的中心位置。纤维或胶木垫圈由6个螺丝固定, 以避免加热槽和容器之间接触。开口插座与容器盖上的插座类似, 竖立直放, 以便将温度计埋在水槽中。漏斗和排放管通过板的上部与加热槽连接, 板上固定着两个环可以将整个装置抬起。

5.5.3 加热槽放于铸铁三角架上。三角架上固定一个厚度大于或等于  $0.55 \mathrm{~mm}$  的铜制圆柱形外壳, 外壳朝里折边, 槽正好与外壳的外侧叠边平齐。外壳配有直径为  $165 \mathrm{~mm} \pm 2.5 \mathrm{~mm}$  的2个柄。加热槽可以用任何合适的装置加热。装置应位于通风循环良好的环境, 例如: 风通过小直径管子可从开孔进入加热槽中。

5.5.4 温度计的卡环为黄铜材料, 其外径可在插座上调节, 温度计管厚度为  $0.5 \mathrm{~mm}$ , 边缘厚度为  $2.5 \mathrm{~mm} \pm 0.1 \mathrm{~mm}$  。

5.5.5 使用规定特性的加热槽温度计。加热槽温度计与容器温度计规格见附录A。

5.5.6 分钟摆动75次  $\sim 80$  次, 可用有效长度为  $60 \mathrm{~cm}$  的吊摆代替节拍器。

# 6 样品分析特别注意事项

# 6.1 样品分析注意事项

为了避免挥发性试剂的损耗, 在取样和试验操作中尽量避免样品与大气的接触。将样品保存在密封的容器中, 在有争议的情况下, 至少单独保留  $100 \mathrm{~g}$  样品。

# 6.2 操作方法

6.2.1 如果在实验室温度下, 样品因太稠不能倒出, 可把样品放于密封容器在加热槽中加热, 使试样温度最大控制在预期闪点值  $10 ^{\circ} \mathrm{C}$  以下。

6.2.2 如果测定的闪点在  $100 ^{\circ} \mathrm{C}$  以上, 将加热槽装满水, 并用水或水和甘油混合剂容器将槽直径的环形空间填满。使槽的温度大于预热试样的温度。

6.2.3 如6.2.1所示条件下, 抽取样品达到液位计指示器的最高位。装上盖子并配上温度计。

6.2.4 起动搅拌装置, 将搅拌速度调节到  $70 \mathrm{~r} / \mathrm{min} \sim 80 \mathrm{~r} / \mathrm{min}$  。在很稠的样品中刚开始不能到达这个转速, 但随着温度的上升转速也上升, 最终达到  $70 \mathrm{~r} / \mathrm{min} \sim 80 \mathrm{~r} / \mathrm{min}$  。

6.2.5 点燃点火器。调节加热槽使容器中沥青的温度每分钟升高  $0.4 ^{\circ} \mathrm{C}$  至  $0.7 ^{\circ} \mathrm{C}$  。

注: 为了保持加温的速度, 要求保持槽的温度比试验样品的温度高  $4 ^{\circ} \mathrm{C}$  。

6.2.6 温度每升高  $1 ^{\circ} \mathrm{C}$ , 就将点火器的火苗放在气体中测试是否可燃, 同时不断搅拌。在设定闪点温度的  $10 ^{\circ} \mathrm{C}$  以下时用下列方式进行第一次操作: 慢慢打开盖子的导轨, 在节拍器摆动前3次时处于打开

状态，摆动第4次时关闭。

6.2.7控制温度不断升高，直到点火器可将其点燃，产生明火，但不可将其与围绕着测试火的浅蓝色光晕混淆。记录此温度，样品在这个温度下发生燃烧并且气压表的气压接近  $100\mathrm{~Pa}(1\mathrm{~mbar})$  。

如果温度最终确定，但以下任何一种准备工作未完成，应重新试验，如：试样的预先热处理，升温的速度等。

# 6.3 试验结果表达

6.3.1 修正温度计读取数值的误差。

6.3.2在6.2.1基础上根据大气压差再次修正数值，修正大气压差  $101.3\mathrm{kPa}(760 \mathrm{mm} \mathrm{Hg})$  ，操作如下：在  $103\mathrm{~kPa}$  以下每  $3.3\mathrm{~kPa}$  加  $1 ^{\circ}\mathrm{C}$  ，而在  $101.3\mathrm{~kPa}$  以上每  $3.3\mathrm{~kPa}$  减去  $1 ^{\circ}\mathrm{C}$  。
