# 搜索自动补全功能说明 🔍

## 📋 功能概述

为搜索框添加了**智能自动补全**功能，用户输入时实时显示匹配的化学品候选项，支持：
- ✅ 中文名称匹配（如：输入"甲" → 显示"甲醛"、"甲苯"、"甲酸"等）
- ✅ CAS号匹配（如：输入"50-00" → 显示"50-00-0 甲醛溶液"）
- ✅ 英文名称匹配（如：输入"form" → 显示"formaldehyde"）
- ✅ 别名匹配（如：输入"福尔马林" → 显示"甲醛溶液"）

---

## ✨ 核心特点

### 1. 智能匹配
- 🎯 **模糊搜索**：支持部分匹配，输入关键词即可找到相关化学品
- 📊 **优先级排序**：完全匹配 > 前缀匹配 > 包含匹配
- 🔢 **多字段支持**：同时搜索中文名、英文名、CAS号、别名

### 2. 实时响应
- ⚡ **300ms防抖**：避免频繁请求，优化性能
- 🔄 **实时更新**：每次输入自动刷新候选列表
- 🌀 **加载提示**：显示加载动画，提升用户体验

### 3. 键盘操作
- ⬆️ **向上箭头**：选择上一个候选项
- ⬇️ **向下箭头**：选择下一个候选项
- ⏎ **Enter键**：确认选择并执行搜索
- ⎋ **Esc键**：关闭候选列表

### 4. 美观界面
- 🎨 **紫色主题**：与系统整体风格一致
- 🌟 **高亮匹配**：关键词高亮显示
- 💫 **悬停效果**：鼠标悬停变色
- 📱 **响应式设计**：支持移动端

#### JavaScript核心函数

1. **输入处理**（防抖）
```javascript
function handleSearchInput() {
    const keyword = document.getElementById('searchInput').value.trim();
    
    if (autocompleteTimer) {
        clearTimeout(autocompleteTimer);
    }
    
    if (!keyword) {
        hideAutocomplete();
        return;
    }
    
    // 延迟300ms搜索（防抖）
    autocompleteTimer = setTimeout(() => {
        fetchAutocomplete(keyword);
    }, 300);
}
```

2. **获取候选项**
```javascript
async function fetchAutocomplete(keyword) {
    const list = document.getElementById('autocompleteList');
    
    // 显示加载状态
    list.innerHTML = '<div class="autocomplete-loading"><i class="fas fa-spinner fa-spin"></i> 搜索中...</div>';
    list.classList.add('show');
    
    try {
        const response = await fetch(`/api/autocomplete?keyword=${encodeURIComponent(keyword)}`);
        const data = await response.json();
        
        if (response.ok && data.suggestions && data.suggestions.length > 0) {
            renderAutocomplete(data.suggestions, keyword);
        } else {
            list.innerHTML = '<div class="autocomplete-no-results">未找到匹配项</div>';
        }
    } catch (error) {
        list.innerHTML = '<div class="autocomplete-no-results">加载失败</div>';
    }
}
```

3. **渲染候选列表**
```javascript
function renderAutocomplete(suggestions, keyword) {
    let html = '';
    suggestions.forEach((item, index) => {
        // 高亮匹配的文本
        let displayName = item.中文名;
        const regex = new RegExp(`(${keyword})`, 'gi');
        displayName = displayName.replace(regex, '<span class="autocomplete-item-match">$1</span>');
        
        html += `
            <div class="autocomplete-item" onclick="selectAutocomplete(${index})">
                <span class="autocomplete-item-name">${displayName}</span>
                <span class="autocomplete-item-cas">${item.CAS号}</span>
            </div>
        `;
    });
    
    list.innerHTML = html;
}
```

4. **键盘操作**
```javascript
function handleSearchKeydown(event) {
    const items = list.querySelectorAll('.autocomplete-item');
    
    if (event.key === 'ArrowDown') {
        // 向下箭头
        autocompleteSelectedIndex = Math.min(autocompleteSelectedIndex + 1, items.length - 1);
        updateAutocompleteSelection(items);
    } else if (event.key === 'ArrowUp') {
        // 向上箭头
        autocompleteSelectedIndex = Math.max(autocompleteSelectedIndex - 1, -1);
        updateAutocompleteSelection(items);
    } else if (event.key === 'Enter') {
        // 回车键
        if (autocompleteSelectedIndex >= 0) {
            selectAutocomplete(autocompleteSelectedIndex);
        }
    } else if (event.key === 'Escape') {
        // ESC键
        hideAutocomplete();
    }
}
```

### 后端API

#### 接口定义
```python
@app.route('/api/autocomplete', methods=['GET'])
def autocomplete():
    """自动补全API - 根据关键词返回候选化学品列表"""
    keyword = request.args.get('keyword', '').strip()
    
    if not keyword:
        return jsonify({'suggestions': []})
```

#### SQL查询（智能排序）
```sql
SELECT DISTINCT 
    c.编号,
    c.CAS号,
    c.中文名,
    c.英文名
FROM 化学品 c
LEFT JOIN 化学品别名 a ON c.编号 = a.化学品编号
WHERE c.中文名 LIKE %keyword%
   OR c.英文名 LIKE %keyword%
   OR c.CAS号 LIKE %keyword%
   OR a.别名 LIKE %keyword%
ORDER BY 
    CASE 
        WHEN c.中文名 = keyword THEN 1      -- 完全匹配优先
        WHEN c.中文名 LIKE 'keyword%' THEN 2 -- 前缀匹配次之
        WHEN c.CAS号 = keyword THEN 3       -- CAS完全匹配
        WHEN c.CAS号 LIKE 'keyword%' THEN 4 -- CAS前缀匹配
        ELSE 5                              -- 其他包含匹配
    END,
    c.中文名
LIMIT 10
```

#### 优先级规则
1. **完全匹配**：输入"甲醛" → "甲醛溶液"排第一
2. **前缀匹配**：输入"甲" → "甲醛"、"甲苯"优先于"氯甲烷"
3. **CAS匹配**：输入"50-00-0" → 直接定位到甲醛溶液
4. **包含匹配**：输入"醇" → 显示所有包含"醇"的化学品

## 🐛 常见问题

### Q1: 候选列表不显示
**解决方法**：
1. 检查网络连接
2. 查看浏览器控制台是否有错误
3. 确认后端API正常运行
4. 检查数据库中是否有匹配数据

### Q2: 键盘操作不响应
**解决方法**：
1. 确保候选列表已显示
2. 检查是否有JavaScript错误
3. 确认事件监听器已正确绑定

### Q3: 搜索太慢
**解决方法**：
1. 添加数据库索引
2. 减少LIMIT数量
3. 增加防抖延迟
4. 启用缓存机制

### Q4: 中文匹配不准确
**解决方法**：
1. 检查数据库字符集（应为utf8mb4）
2. 确认排序规则正确
3. 优化SQL查询的ORDER BY逻辑
