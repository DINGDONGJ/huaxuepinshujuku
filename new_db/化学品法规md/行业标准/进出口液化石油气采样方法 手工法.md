# 中华人民共和国出入境检验检疫行业标准

# 进出口液化石油气采样方法 手工法

Method of sampling for import and export liquified petroleum gases—Manual method

中华人民共和国国家质量监督检验检疫总局 发布

# 前言

本标准按照GB/T1.1—2005给出的规则起草。

本标准代替SN/T1651—2005《进出口液化石油气采样方法手工法》。与SN/T1651—2005相比,主要技术变化如下:

增加了检验批的概念;

增加了采样预检条款;

增加了不均匀样品的混匀条款;

增加了制定采样方案条款;

增加了接收储罐采样的条款;

删除了关于加压式和半冷式液化石油气运输船在采样前应使用滑管式液位计检测游离水的规定。

本标准由国家认证认可监督管理委员会提出并归口。

本标准起草单位:中华人民共和国浙江出入境检验检疫局。

本标准主要起草人:沈宣铭、俞旭峰、刘滨、陈祥准。

本标准所代替标准的历次版本发布情况为:

SN/T1651—2005。

# 进出口液化石油气采样方法 手工法

警示——使用本标准的人员应具有相关的液化石油气采样工作经验。本标准并未指出所有可能的安全问题。使用者有责任采用适当的安全和健康措施,并保证符合国家有关法规规定的条件。

# 1范围

本标准规定了采取进出口液化石油气代表性样品的手工操作方法。

本标准适用于采取液化石油气液相部位的样品,不适用于采取液化石油气气相部位的样品。

# 3术语和定义

下列术语和定义适用于本文件。

3.1

加压式液化石油气运输船 pressure type LPG ship

储存或装运通过常温下加压方式进行液化的石油气体的船舶

3.2

冷冻式液化石油气运输船 freezing type LPG ship

储存或装运通过常压下冷冻方式进行液化的石油气体的船舶

3.3

半冷式液化石油气运输船 semi- freezing type LPG ship

储存或装运通过加压和冷冻两种方式进行液化的石油气体的船舶。

3.4

标准采样管 standard sample transfer line

连接采样器与产品源之间的导管,导管上装有控制阀和排出阀。

3.5

简易采样管 simple sample transfer line

连接采样器与产品源之间的导管,导管两端带有螺冒,导管上没有阀门。

3.6

滑管式液位计 slip tube gauge

固定在加压式或半冷式液化石油气船舱上,用于测量船舱内液化石油气液位高度的一组可上下滑动的并带刻度的金属管。

3.7

产品源 product source

储存液化石油气的各类容器和输送管线。

3.8

检验批 inspection lot

同一合同、同一规格产品为一检验批。

# 4 采样设备

# 4.1 采样器

采样器应符合GB/T5842的要求,有单阀型、双阀型、非预留容积管型和预留容积管型,常见采样器参见附录A。根据检验需要的试样量,选择不同规格型号的采样器。非预留容积管型采样器应在采样前称定皮重,单阀型采样器应在采样前适当抽真空,双阀预留容积管型采样器应允许排出占采样器容积  $20\%$  的样品,预留容积管一端应有明显的标记。每只采样器应只用于采取产品源中某一部位的点样,采样器应专用。采样前,对可能泄漏的采样器,应按照GB/T5842要求进行气密性试验。

# 4.2 采样管

有简易采样管和标准采样管两种,采用尼龙、不锈钢管或其他耐腐蚀弹性金属管制作而成。采样结束后应及时拆卸采样管并妥善保管,保持清洁干燥,必要时两端可用塞子或帽盖封好,防止杂质或污物进入。

# 5 采样安全注意事项

液化石油气系易燃易爆危险化学品,采样安全参照附录B的规定。

# 6 采样一般原则

6.1 产品源中的液化石油气存在气液两相,采样时应仅采取液相部位的样品。

6.2 如果液化石油气主要由一种成分组成,则可从产品源的任何部位采样。

6.3 如果液化石油气已经呈均匀状态,则可从产品源的任何部位采样。

6.4 加压式和半冷式液化石油气船舱采样前,应先把滑管式液位计拉到指定的高度,排空滑管式液位计中滞留的液化石油气。不符合6.2和6.3要求的,应至少采集上部、中部和下部等部位的样品。

6.5 不符合6.2和6.3要求的冷冻式液化石油气运输船,应在装卸过程中,从船舱或输送管线上采样,并应根据货物的总数量、输送速度和装卸时间等条件,制定采样方案。

6.6 受客观条件限制,如果无法在产品源上采样,可在接收储罐上采样,储罐应清洁干燥。

# 7 采样准备

# 7.1 采样前的预检

液化石油气采样前应进行预检,预检按GB/T6680—2003中4.2规定进行,并根据检查结果制定采样方案,按此方案采集具有代表性的样品。

# 7.2 液化石油气的混匀

7.2 液化石油气的混匀液化石油气的混匀按GB/T6680—2003中4.3规定进行。

# 7.3 采样方案的制定

7.3 采样方案的制定按GB/T6681—2003第5章的要求制定采样方案,采样方案包括以下内容:检验批、采样单元数;样品类型及样品量;采样时间、地点、位置;采样方法、步骤和采样工具等。对于符合6.2和6.3要求的液化石油气,至少采集一个样品,并且样品量应满足实验室测试需求。不符合6.2和6.3要求的液化石油气,应至少采集3个样品。

# 7.4 采样连接

7.4 采样连接加压式或半冷式液化石油气运输船采样,将采样管的一端连接滑管式液位计的喷嘴,另一端与采样器连接。冷冻式液化石油气运输船采样,将采样管的一端连接船上的采样口,另一端与采样器连接。输送管线上采样,将采样管一端与输送管线上的采样口连接,另一端与采样器连接。其他储存或装运条件下采样,将采样管的一端与产品源连接,另一端与采样器连接。典型采样连接见附录C。

# 7.5 采样设备的冲洗

采样设备包括简易采样管、标准采样管、双阀型采样器和单阀型采样器,其冲洗要求见附录D。

# 8采样

# 8.1 采样过程

# 8.1.1 使用简易采样管采样

8.1.1 使用简易采样管采样当采样设备冲洗结束后,立即开启产品源阀门,接着慢慢开启采样器入口阀C,直到样品充满整个采样器,关闭采样器入口阀C,再关闭产品源阀门。小心松开采样管两端连接,排尽液相样品,卸下采样器,按照8.2的要求调节采样量。

# 8.1.2 使用标准采样管采样

8.1.2 使用标准采样管采样当采样设备冲洗结束后,开启产品源阀门和控制阀A,接着慢慢开启采样器入口阀C,直到样品充满整个采样器,关闭采样器入口阀C,再关闭产品源阀门,开启采样管上的控制阀A和排出阀B,排尽液相样品,卸下采样器,按8.2的要求调节采样量。

# 8.2 调节采样量

8.2.1采样结束后应尽快调节采样量,对于非预留容积管型采样器,可放出多余的液体,用称重法调整液体样品约为采样器容积的  $80\%$  0

8.2.2对于预留容积管型采样器,将采样器垂直竖立,使有预留容积管一端朝上,慢慢打开连通预留容积管的阀门,排出多余的液体样品,当排出量达到规定的预留容积量,观察到排出的液体变成气体时,立即关闭阀门。

8.2.3如果在采样过程中发生泄漏,或在调节采样量前发现采样器上阀门被打开,或者在调节采样量时,发现预留容积管一端无液态样品排出,均应废弃该样品,并重新安排采样。

# 9 样品检漏

9 样品检漏采样完成后, 应把采样器浸入水浴中进行检漏。如果发现泄漏, 应废弃该样品, 维修或者更换新的采样器重新采样。

# 10 样品标签

10 样品标签对满足要求的样品应加贴样品标签, 样品标签的内容应包括: 样品编号和/或报检号、样品名称、委托单位、采样地点、储罐的名称和编号、采样部位、采样人、采样日期。

# 11 样品储存

11 样品储存样品尽可能在阴凉、干燥和避光的房间内储存, 房间通风条件良好, 样品在保存期间应保持标签完整无损。为了防止泄漏或被意外开启, 可在采样器的阀门上安装一个盖帽或者在阀门的旋钮上装一个架子以固定阀门。

采样安全注意事项

B.1 采样人员应穿着防静电服,不应穿带钉鞋;在登上船舱或岸罐前,应用手触摸金属物如铁梯扶手,消除随身所带的静电。

B.2 采样人员不得携带非防爆电子通讯设备和非防爆手电筒进入采样现场。

B.3 遇恶劣天气,如7级以上大风、暴雨、雷电时,应暂停采样。

B.4 采样时,工作人员应站在上风头,防止吸入液化石油气气体。

B.5 抽取低温冷冻状态的液化石油气样品时,应戴防冻手套,必要时,还应戴防护镜、穿防护服,防止低温样品飞溅到手上或眼睛里造成冻伤。

B.6 采样器的冲洗或具体采样过程中,采样器的样品出口端均不应朝向现场任何人员。

B.7 当样品需要排放时,应遵守有关安全和环保法规的规定。

B.8 液化石油气系易燃易爆危险化学品,当样品需要运输时,采样人应遵守危险品运输有关法规的规定。

采样设备的冲洗

# D.1 冲洗简易采样管

按7.4的要求连接后,小心开启产品源阀门,用拟采样品冲洗。

# D.2 冲洗标准采样管

如附录C中图C.1所示,将标准采样管两端分别与产品源和采样器入口阀C连接。关闭控制阀A、排出阀B和入口阀C,开启产品源阀门,接着开启控制阀A和排出阀B,用拟采样品冲洗。

# D.3 冲洗双阀型采样器

D.3.1如果采样器装过未知样品,或可能残留会影响分析结果的样品,或两者都有,按以下步骤冲洗:

a)如图C.2所示,将采样管与采样器出口阀D连接,采样器垂直放置,保持入口阀C端朝上;

b)关闭排出阀B、入口阀C和出口阀D,开启控制阀A,接着开启入口阀C和出口阀D,使样品注

满采样器,当液体样品从入口阀C流出时,关闭入口阀C和出口阀D,接着关闭控制阀A;

c)松开采样器与采样管的连接,将采样器旋转  $180^{\circ}$  ,使出口阀D朝上,开启入口阀C和出口阀D,排出液相样品;

d)重新翻转采样器使入口阀C端朝上,重复上述冲洗步骤至少3次。

D.3.2如果采样器装过已知样品,并且样品不影响分析结果,按照下面的步骤冲洗:如图C.1所示,将采样器垂直放置,保持出口阀D端朝上,当采样管冲洗完毕后,关闭排出阀B和入口阀C,开启控制阀A,接着开启入口阀C,然后慢慢开启出口阀D,使部分液相样品进入采样器。关闭控制阀A,从出口阀D中排出部分气相样品。关闭出口阀D,开启排出阀B,排出残余液相样品。重复上述冲洗操作至少3次。

# D.4 冲洗单阀型采样器

单阀型采样器的冲洗按照SH/T0233—1992中6.3.1的规定进行。
