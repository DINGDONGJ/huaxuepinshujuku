# 前言

SN/T0761系列标准共分为3部分：

第1部分：出口危险品打火机检验规程；第2部分：出口危险品打火机儿童安全性试验方法；第3部分：出口危险品点火枪检验规程。

本部分为SN/T0761系列标准的第1部分。

本部分按照GB/T1.1—2009给出的规则起草。

本部分代替SN/T0761—1999《出口危险品打火机检验规程》。本次修订除参照ISO9994：2005(E)《打火机安全特性》外，还将美国试验与材料协会ASTMF400—2004《打火机消费者安全标准》、EN13869：2002《儿童安全打火机安全要求与测试方法》有关内容纳入本部分。

本部分与SN/T0761—1999《出口危险品打火机检验规程》相比主要内容变化如下：

修改了燃烧高度试验的判定合格参数；修改了温度试验中的温度参数；修改了抽样数量；修改了样品使用流程；修改了燃烧高度试验（包括火焰高度试验、爆火、溅火和跳火试验、熄火试验三项）；修改了防止儿童开启试验的合格准则；修改了燃烧高度试验的合格准则；修改了跌落试验的样品分配；增加了液体打火机、后混式打火机、前混式打火机、一次性打火机、液体打火机、可重复充灌式打火机、可调节打火机、不可调节打火机的定义；增加了火焰高度、喷火、溅火、跳火的定义；增加了调火装置的推力要求；增加了重复注气标识的要求；增加了对安全警示标识的要求与图示说明；增加了样品预处理及试验环境的内容；增加了燃液容量试验、循环燃烧试验、重复注气试验和燃料相容性试验；增加了防止儿童开启装置试验的试验部分内容；删除了豪华打火机的定义；删除了对更新设备之前的检测仪器的要求；删除了对  $15^{\circ}C$  及  $55^{\circ}C$  对打火机燃料充灌量的要求。

本部分由中华人民共和国国家质检总局提出并归口。

本部分起草单位：天津出入境检验检疫局、湖南出入境检验检疫局、宁波出入境检验检疫局。

# 3 术语和定义

下列术语和定义适用于本文件。

3.1

打火机 lighter

3.1打火机 lighter充灌有不大于  $10\mathrm{g}$  的丁烷或其他易燃气体或液体，可重复充灌或没有充灌系统，并能承受一定压力，带有燃料释放、引燃装置的器具。一般用于点燃香烟，也可用于其他点火。

3.2

气体打火机 gas lighter

3.2气体打火机 gas lighter一种充灌液化碳氢化合物燃料的产品，如正丁烷和异丁烷，在  $24^{\circ}C$  时标准蒸气压超过  $104\mathrm{kPa}$  。

3.3

液体打火机 fluid lighter

3.3液体打火机 fluid lighter一种附有外露灯芯的打火机，使用液态烃类物（如乙烷）作燃料，标准蒸汽压在  $24^{\circ}C$  时不超过  $34.5\mathrm{kPa}$  。

3.4

后混式打火机 postmixing burner lighter

燃料和空气在点燃处进行混合的打火机。

3.5

前混式打火机 premixing burner lighter

燃料和空气在点燃前已混合的打火机。

3.6

一次性打火机 disposable lighter

不能进行重复充灌的打火机。

3.7

可重复充灌式打火机 refillable lighter

能从外部重新注入燃料或者能更换燃料箱的打火机。

3.8

可调节打火机 adjustable lighter通过手动操作来调节火焰高度的打火机。

3.9

不可调节打火机 non- adjustable lighter无火焰调节装置的打火机。

3.10

风挡 shield

全部或部分包裹打火机的燃料出口，且凸出向外的一种结构。

3.11

火焰高度 flame height

可见火焰顶部到风罩的直线距离；如果没有风罩，则是从火焰顶部到灯芯底部或燃烧阀嘴的直线距离。

3.12

跳火 flaring

稳定火焰条件下火焰高度的变化。

3.13

喷火、溅火 spitting，sputtering

无雾化燃料飞溅或液体燃料以小液滴燃烧状态从主火焰中脱离的一种现象。

# 4 要求

# 4.1 警告标记

所有打火机应附有进口国官方语言或英语标注的警告“远离儿童可及范围及高温环境”或其他同一含义的警告，用以表述合适的使用方法及注意事项，且应与其他标记从尺寸、颜色、背景、位置明显区分开（要求尺寸至少  $10~\mathrm{mm}$ ，背景为白色，文字说明为黑色或红色）。标记应在打火机的使用有效期内保持清晰可见，同时打火机或其包装上应注有正体字标注的生产商名称，或进口国的注册商标。

# 4.2 对燃烧高度的装置进行标注

每一个打火机都应对调节燃烧高度的装置进行永久性标注，并在其整个有效期内保持清晰。应采用简单易懂的标记来表明装置增加或减小燃烧高度的操作方法。

# 4.3 打火机应用手动装置进行点燃

为减少意外点燃或自燃现象的发生，打火机应用手动装置进行点燃，装置至少应遵循以下要求中的一项：

a）两次或多次独立操作的动作来完成点火；b）压力装置产生火焰的压力应大于或等于  $15~\mathrm{N}$ （见图1或图2）。

# 4.5 安全说明

4.5.1 打火机应附有特别标记词“警告（WARNING）”和表达正确使用方法的安全说明，安全说明应包括以下语句：

a）“远离儿童”或“放置于儿童触及不到的地方”（此语句应突出并有明显区别）；b）“点燃时远离脸部及衣物”。

4.5.2 针对不同适用类型的打火机，安全说明可使用下列语句：

a）“内装灌压可燃气体”；b）“不可置于超过  $50^{\circ}C$  环境中，不可在阳光下长时间暴晒”；c）“不可刺穿或投入火中”。

4.5.3 还可以使用下列语句：

a）“可见火焰上方温度很高，应予以格外注意以避免烧伤或火灾”（适用于所有前混式打火机）；b）“持续点燃时间禁止超过  $10~\mathrm{s}$  ”（适用于所有前混式打火机）。

# 4.7 重复充灌说明

可重复充灌气体打火机，应附有正确进行充灌操作的详细说明。此说明应包括厂商提供的适应性燃料说明和充灌容器与燃料箱相匹配的说明信息，以确保正确完成充灌操作。

# 6 检验

# 6.1 检验项目

防止儿童开启装置试验、燃烧高度试验（包括火焰高度试验、爆火、溅火和跳火试验、熄灭试验三项）、跌落试验、温度试验、持续燃烧试验、压力试验、燃液容量试验、循环燃烧试验、重复注气试验和燃料相容性试验共12项。

# 6.2 样品的预处理及试验环境

6.2.1 未充灌燃料的样品应充灌生产商说明书规定的燃料。6.2.2 除防止儿童开启试验外，样品均应在  $23^{\circ}C\pm 2^{\circ}C$  的温度环境中至少预处理  $10\mathrm{h}$  以上。6.2.3 进行跌落试验时，试验样品进行6.2.2规定的预处理前，还应预先在  $- 10^{\circ}C\pm 2^{\circ}C$  的温度环境中至少预处理  $10\mathrm{h}$  。6.2.4 检验环境温度为  $23^{\circ}C\pm 2^{\circ}C$  ，通风良好，有遮光设施。

# 6.3 检验内容

# 6.3.1 防止儿童开启装置试验

# 6.3.1.1 检验方法

a）感官检测，观察防止儿童开启装置有无松动，并使打火机打火至少3次；b）如果感官检测符合6.3.1.2合格准则后，需要进行非感官检测，则依据BSEN13869：2002进行试验。

# 6.3.1.2 试验合格准则

a）打火机的防止儿童开启装置应无松动；b）打火机至少用两种分离独立的行动来完成点火；c）打火机的点火机构每次操作后都能自动复位；d）经本标准规定的除压力试验、燃液容量试验外的所有试验后，能继续有效。

# 6.3.2 燃烧高度试验

# 6.3.2.1 检测仪器

燃烧高度试验箱和秒表。

# 6.3.2.2 检验方法

# 6.3.2.2.1 总则

燃烧高度试验包括火焰高度试验、爆火、溅火和跳火试验、熄灭试验三项。

# 6.3.2.2.2 火焰高度试验

# 6.3.2.2.2.1 试验方法

试验程序如下：

a）若打火机装有燃烧高度调节装置，首先对未经调节的出厂火焰进行测试，然后将燃烧高度调节

装置调至最大位置进行试验，然后再将燃烧高度调节装置调至最小位置进行试验。如果打火机燃烧高度调节装置是带螺纹的或类似装置，并且在最大定位时没有明确的中止位置，按下列程序进行试验：

对未经调节的出厂火焰高度；在最小定位时测量燃烧高度；旋转燃烧高度调节器加大  $360^{\circ}$ ，并测量相应的火焰高度。

注：最后打火机火焰高度调节装置可能脱离打火机。

b）竖直点燃打火机并持续  $5\mathrm{s}$  。

c）若打火机无风挡，测量并记录可见火焰的顶端至打火机燃料孔顶端的最大距离。

d）若打火机有风挡，测量并记录可见火焰的顶端至打火机风挡顶端的最大距离，如风挡是可伸缩的，将风挡调至最大回缩位置。

e）按正常动作熄灭火焰。

f）测量并记录按正常动作熄灭打火机后延续燃烧的时间。

g）进行燃烧高度试验时应注意：产品的位罝能保证产生垂直向上的火焰；燃烧高度的测量精确到  $5\mathrm{mm}$  ；所有的燃烧试验应在光线减弱的情况下进行。

# 6.3.2.2.3 爆火、溅火和跳火试验

# 6.3.2.2.3.1 试验方法

液体打火机不进行此试验，气体打火机试验的程序如下：

a）调节火焰高度至最大高度；b）点燃打火机，用任何手动姿势保持燃烧  $5\mathrm{s}$  ；c）按正常动作熄灭打火机；d）观察是否出现任何爆火、溅火现象。

如果试验样品无缺陷，则继续重新在  $(23\pm 2)^{\circ}C$  环境中稳定  $5\mathrm{min}$ ，程序如下：

a）点燃样品，使火焰竖直向上；

b）将样品向下旋转至与水平成  $45^{\circ}$  角（见图9），观察稳定火焰的高度或火焰的平均高度，保持燃烧  $5\mathrm{s}$ ；

c）熄灭样品，恢复垂直向上位置；d）观察是否跳火超过  $50~\mathrm{mm}$ ，或者火焰高度超过最大火焰高度。如果试验样品无缺陷，则继续重新在  $(23\pm 2)^{\circ}C$  环境中稳定  $5\mathrm{min}$ ，程序如下：

a）倒置样品  $10\mathrm{s}$ ；b）旋转样品至直立状态，点燃样品；c）燃烧  $5\mathrm{s}$ ，观察火焰高度；d）观察是否跳火超过  $50~\mathrm{mm}$ ，或者火焰高度超过最大火焰高度。

# 6.3.2.2.3.2 合格准则

不应出现任何爆火、溅火现象，跳火不应超过  $50~\mathrm{mm}$ ，火焰高度不能超过最大火焰高度。

# 6.3.2.2.4 熄灭试验

# 6.3.2.2.4.1 试验方法

将样品分为两组，样品组1试验程序如下：

a）调节火焰高度为  $50~\mathrm{mm}$ ，或当最大火焰高度小于  $50~\mathrm{mm}$  时调节到最大火焰高度；b）冷却  $1\mathrm{min}$  后点燃打火机，保持燃烧  $10\mathrm{s}$ ；c）按正常动作熄灭打火机。样品组2试验程序如下：a）打火机火焰高度调至最大；b）冷却  $1\mathrm{min}$  后点燃打火机，保持燃烧  $5\mathrm{s}$ ；c）按正常动作熄灭打火机。

# 6.3.2.2.4.2 合格准则

样品组1、样品组2均不应出现前混式打火机熄灭时间超过  $5\mathrm{s}$ ，后混式熄灭时间超过  $2\mathrm{s}$  的现象。

# 6.3.3 跌落试验

# 6.3.3.1 检测仪器

冷冻箱、跌落试验仪（配备计算机测量系统）。

# 6.3.3.2 检验方法

6.3.3.2.1 将样品分成两组进行跌落试验：

样品组1：待测样品应当在  $(23\pm 2)^{\circ}C$  环境中至少稳定  $10\mathrm{h}$  。对于可调节打火机，应将火焰调至允许的最大高度。样品组2：样品应当在  $(- 10\pm 2)^{\circ}C$  温度下保持  $24\mathrm{h}$  ，然后在  $(23\pm 2)^{\circ}C$  温度下稳定至少  $10\mathrm{h}$  。对于可调节打火机，应将火焰调至  $50~\mathrm{mm}$  的最大高度。

6.3.3.2.2样品从  $(1.5\pm 0.1)\mathrm{m}$  高处自由跌落至混凝土地表面，3次跌落样品初始姿态为：

a) 竖直向上；b) 竖直向下；c) 水平。

6.3.3.2.3 放置天平测量系统进行称量。

# 6.3.3.3 合格准则

合格准则如下：

a) 不应出现燃料箱破裂/爆裂或者自燃现象；b) 跌落试验后  $5\mathrm{min}$  内，称量燃料泄漏率不应超过  $15\mathrm{mg / min}$  ；c) 附有罩壳的样品跌落过程中罩壳应关闭。

# 6.3.4 温度试验

# 6.3.4.1 检测仪器

高温试验箱。

# 6.3.4.2 检验方法

进行打火机温度试验的程序如下：

a) 若打火机装有燃烧高度调节装置，调节该装置至打火机能产生向上垂直高度为  $50~\mathrm{mm}$  火焰的位置；b) 将打火机放于高温试验箱中，在  $65^{\circ}C\pm 2^{\circ}C$  温度中保持  $4\mathrm{h}$  ；c) 将打火机取出高温试验箱，置于  $23^{\circ}C\pm 2^{\circ}C$  温度中至少  $10\mathrm{h}$  ；d) 检查打火机并记录任何损伤及燃料有无全部泄漏。

# 6.3.4.3 合格准则

合格准则如下：

a) 对于液体打火机，不应出现燃料箱、密封部件破裂/爆裂现象。在温度稳定之后，如果液体燃料泄空，按照厂商提供的方式和燃料，可重新充灌样品；b) 对于气体打火机，在温度稳定之后，不应出现称量燃料泄漏超过  $15\mathrm{mg / min}$  现象。

# 6.3.5 持续燃烧试验

# 6.3.5.1 检测仪器

持续燃烧试验仪。

# 6.3.5.2 检验方法

检验方法如下：

6.3.5.2 检验方法检验方法如下：a) 若打火机装有燃烧高度调节装置，调节该装置至打火机能产生向上垂直高度为  $50~\mathrm{mm}$  火焰的位置；b) 除去防止儿童开启装置，将打火机放置于持续燃烧试验仪中，压下气体释放杠杆；c) 点燃打火机使其产生垂直向上的火焰，并保持  $2\mathrm{min}$ ，然后按正常动作熄灭打火机；d) 观察并记录无论有无火焰时，任何打火机组成部件燃烧、结构装置的爆炸或燃料箱的破裂。

# 6.3.5.3 合格准则

6.3.5.3 合格准则打火机经上述试验后，不应出现打火机组成部件的燃烧，气门结构的脱离或燃料箱的破裂。

# 6.3.6 压力试验

# 6.3.6.1 检测仪器

6.3.6.1 检测仪器台钻[配备  $3.06\mathrm{mm}(1 / \mathrm{s}^{\prime \prime})$  的钻头]、氮气瓶和压力试验仪（配备计算机自动测量系统）。

# 6.3.6.2 试验方法

打火机压力试验按如下程序进行：

6.3.6.2 试验方法打火机压力试验按如下程序进行：a) 解除防止儿童开启装置，排空燃料箱中的燃料；b) 在打火机燃料箱大面上打孔，注意避开在燃料箱隔墙上打孔（在钻孔前除去燃料箱的外表装饰）；c) 将打火机垂直放置于压力试验装置中进行测试；d) 以不超过  $69\mathrm{kPa / s}$  的速度给打火机注氮加压至  $1500\mathrm{kPa}$ ，并关掉气源（如果无论何时，若加压时或加压后钻的周围发现泄漏，那么使设备减压，拧紧压紧装置少许，并重新加压）；e)  $1\mathrm{min}$  后记录打火机的内部压力，记录泄漏位置。

# 6.3.6.3 合格准则

打火机经上述试验后，内部压力下降应不超过  $250\mathrm{kPa / min}$

# 6.3.7 燃液容量试验

# 6.3.7.1 检测仪器

分析天平、台钻[配备  $3.06\mathrm{mm}(1 / \mathrm{s}^{\prime \prime})$  的钻头]、注射器。

# 6.3.7.2 试验方法

6.3.7.2 试验方法a) 测量打火机质量  $m_{1}$ ，排空燃料，再测量排空燃料后打火机质量  $m_{2}$ ，按  $23^{\circ}\mathrm{C}\pm 2^{\circ}\mathrm{C}$  时燃料的密度  $(0.54\mathrm{g / cm^3})$ ，利用公式  $V_{1} = (m_{1} - m_{2}) / 0.54$ ，计算液体容积  $V_{1}$ ；b) 取出燃料箱打孔，然后称量  $m_{3}$ ；

c）用注射器向燃料箱内注蒸馏水，确认燃料箱内无气泡，然后称量  $m_{4}$ ；d）利用公式  $V_{0} = (m_{4} - m_{3}) / 1$ ，计算打火机燃料箱的容积  $V_{0}$ 。

# 6.3.7.3 合格准则

$V_{1} / V_{0}$  不应超过  $85\%$ 。

# 6.3.8 循环燃烧试验

# 6.3.8.1 检测仪器

燃烧高度试验箱和秒表。

# 6.3.8.2 试验方法

a）将火焰高度调至  $50~\mathrm{mm}$ ，当最大火焰高度低于  $50~\mathrm{mm}$  时，调至最大高度；b）点燃样品使火焰竖直向上并持续燃烧  $20~\mathrm{s}$ ；c）熄灭样品，间歇时间为  $5\mathrm{min}$ ；d）重复上述试验9次，使试验总数达到10次。

# 6.3.8.3 合格准则

不应出现6.3.2.2.2.2里所列明的火焰缺陷。

# 6.3.9 重复注气试验

# 6.3.9.1 检测仪器

天平。

# 6.3.9.2 试验方法

6.3.9.2.1对附有密封燃料箱的液体打火机：

a）将密封塞从注气口拔掉，依据厂商提供的方式和燃料，充灌燃料箱；b）装好密封塞擦拭火机，晾干；c）观察密封塞接缝或燃料箱本身燃料是否明显泄漏。

6.3.9.2.2 对于可重复充灌气体打火机：

a）排空样品的燃料箱，按照厂商提供的方式和燃料，重新充灌样品；b）天平称量样品燃料泄漏率是否超过  $15\mathrm{mg / min}$ 。

# 6.3.9.3 合格准则

合格准则如下：

a）对液体打火机，燃料不应有明显泄漏；b）对于气体打火机，燃料泄漏率不应超过  $15\mathrm{mg / min}$ 。

# 6.3.10 燃料相容性试验

# 6.3.10.1 检测仪器

密封容器、附有出气孔的控温箱，温度能保持在  $(40\pm 2)^{\circ}C$  、精度为  $1^{\circ}$  的测温器（量程在  $35^{\circ}C\sim 45^{\circ}C$  之间）、天平（精度为  $0.1\mathrm{mg}$ ）。

# 6.3.10.2 试验方法

6.3.10.2.1 对于液体打火机：

a) 采用标准方法充灌样品，建议使用厂商推荐燃料；b) 放置于密闭容器中，使样品密闭装置处于打开状态；c) 向密闭容器中注入厂商推荐使用的燃料，使样品完全浸泡于燃料中，密封密闭容器；d) 稳定温度在  $(40 \pm 27^{\circ} \mathrm{C}$ ，将样品放入控温箱保持  $28 \mathrm{~d}$ ；e)  $28 \mathrm{~d}$  后将容器从控温箱取出，并将样品从容器中取出，完全晾干样品；f) 依据厂商推荐的方式和燃料，重新充灌样品；g) 稳定样品在  $(23 \pm 27^{\circ} \mathrm{C}$  环境下至少  $10 \mathrm{~h}$ ；h) 从各角度感官检测样品是否泄漏。

6.3.10.2.2 对于气体打火机：

a) 稳定控温箱温度在  $(40 \pm 2)^{\circ} \mathrm{C}$ ，点燃样品，确保机内仍有燃料，将样品放入控温箱  $28 \mathrm{~d}$ ；b)  $28 \mathrm{~d}$  后，从控温箱里取出样品；稳定样品在  $(23 \pm 2)^{\circ} \mathrm{C}$  环境下至少  $10 \mathrm{~h}$ ；c) 天平测量样品燃料泄漏率是否超过  $15 \mathrm{mg} / \mathrm{min}$ 。如温度稳定后，样品无燃料，则加充制造商要求使用的燃料确定有无泄漏，若有，则再次称重。

# 6.3.10.3 合格准则

合格准则如下：

a) 对于液体打火机，不应出现任何泄漏现象；b) 对于气体打火机，不应出现燃料泄漏率超过  $15 \mathrm{mg} / \mathrm{min}$  或燃料完全泄漏现象。

# 7 检验结果的判定

7.1 打火机经上述12项试验后，每项试验全部合格，则判定该批打火机合格，如有1项及1项以上不合格，则判定该批打火机不合格。

7.2 不合格的处置：如有1项试验不合格，则加倍抽样重新进行检验，如仍有1项或1项以上不合格，则判定该批打火机不合格。
