# PDF多关键词搜索功能说明

## 🎯 功能概述

在查看法规PDF时，系统会**自动搜索化学品的所有名称**，包括：
- ✅ CAS号
- ✅ 中文名称
- ✅ 所有别名

## 🔍 搜索逻辑

### 关键词优先级

系统会按以下顺序收集搜索关键词：

1. **CAS号**（最优先）
   - 例如：`64-17-5`
   - 全球唯一标识，匹配最精确

2. **中文名称**
   - 例如：`乙醇`
   - 官方标准名称

3. **所有别名**
   - 例如：`酒精`、`无水乙醇`、`食用酒精`
   - 系统会自动分割多个别名（支持逗号、分号、顿号分隔）

### 搜索示例

假设查询**乙醇**：

```javascript
搜索关键词：['64-17-5', '乙醇', '酒精', '无水乙醇', '食用酒精']
```

系统会：
1. 在PDF中搜索所有关键词
2. 找到所有匹配位置
3. 跳转到第一个匹配页
4. 在侧边栏列出所有匹配项
5. 高亮显示所有匹配文本

## 🛠️ 技术实现

### 别名分割规则

系统会自动识别以下分隔符：
- `,` 逗号
- `，` 中文逗号
- `;` 分号
- `；` 中文分号
- `、` 顿号
- 空格

例如：
```
所有别名: "酒精, 无水乙醇；食用酒精、工业酒精"
↓ 自动分割为：
['酒精', '无水乙醇', '食用酒精', '工业酒精']
```

### 搜索算法

```javascript

    // 对每个关键词进行搜索

        while (找到匹配) {
            保存搜索结果 {
                pageNum: 页码,
                context: 上下文,
                keyword: 匹配的关键词,
                index: 位置索引
            }
        }

```

### 高亮显示逻辑

```javascript
// 在文本图层中检查每个文本元素
textDivs.forEach(span => {
    const text = span.textContent;
    // 检查是否包含任何一个关键词
    const hasMatch = keywords.some(keyword => text.includes(keyword));
    if (hasMatch) {
        span.classList.add('highlight'); // 添加高亮样式
    }
});
```

## 📝 使用场景

### 场景1：查询"甲醛"

**化学品信息**：
- CAS号: `50-00-0`
- 中文名: `甲醛`
- 别名: `福尔马林, 蚁醛, 甲醛溶液`

**搜索结果**：
- ✅ CAS号匹配: "50-00-0" → 在法规中找到3处
- ✅ 名称匹配: "甲醛" → 找到8处
- ✅ 别名匹配: "福尔马林" → 找到2处
- 📊 总计: 13处匹配

### 场景2：查询"盐酸"

**化学品信息**：
- CAS号: `7647-01-0`
- 中文名: `盐酸`
- 别名: `氢氯酸, 氯化氢溶液`

**搜索结果**：
- ✅ 在"高毒物品目录"中找到盐酸相关条目
- ✅ 在"易制爆化学品名录"中找到氢氯酸条目
- 🎯 自动跳转并高亮所有匹配项

## 🔧 兼容性说明

### 向后兼容

系统同时支持：
- ✅ 新方式: 传入关键词数组 `['64-17-5', '乙醇', '酒精']`
- ✅ 旧方式: 传入单个关键词 `'64-17-5'`

### 空值处理

- 空CAS号 → 跳过
- 空名称 → 跳过
- 空别名 → 跳过
- 所有关键词都为空 → 不执行搜索
