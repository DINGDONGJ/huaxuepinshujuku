# 危险品热稳定性和空气稳定性的筛选实验

# 1 范围

本标准规定了危险品热稳定性和空气稳定性筛选实验的仪器和测试步骤。本标准适用于对危险品热稳定性和空气稳定性试验的测定。

# 2 原理

长期贮存的不稳定性可以用高温短期试验来模拟。

# 3 仪器

除试验室常规仪器外，需要以下仪器：

a）加热炉：带有恒温控制的加热炉，最大误差为士  $2^{\circ}C$

b）样品容器，包括：

1)  $250~\mathrm{mL}$  烧瓶。2) 玻璃杯，体积约  $250~\mathrm{mL}$  03) 密封安培瓶。4) 电子天平，精度  $1\mathrm{mg}$

# 4 试验步骤

# 4.1 样品制备

# 4.1.1 不易挥发性样品

将约  $20\mathrm{g}$  不易挥发样品置于样品容器中。

# 4.1.2 易挥发样品

将约  $20\mathrm{g}$  易挥发性样品置于安培瓶中，并密封。

# 4.2 测试

# 4.2.1 热稳定性测试

将样品密封于容器放入加热炉中，并控制温度在  $55^{\circ}C\pm 2^{\circ}C$  维持  $14d$

# 4.2.2 空气稳定性筛选

以水饱和的空气作为试验的气氛，并按照4.2.1操作。

# 4.3 测试结束

4.3.1 从炉内取出样品容器，冷却至室温。

SN/T 2902—2011

4.3.2 解除样品容器的密封。

# 5 报告格式和结果判定

# 5.1 报告格式

样品容器类型；测定化学变化的方法；在贮存14d之后的一种典型性质改变或分解的百分率。

# 5.2 结果判定

选用适当方法（如熔点、密度等）确定样品是否分解或发生其他变化。若熔点或另一特性维持恒定或分析测定后被测物质量变化不超过  $5\%$  ，则通过试验。
