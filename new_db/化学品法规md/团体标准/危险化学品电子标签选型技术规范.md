# 危险化学品电子标签选型技术规范

# 1 范围

本文件规定了危险化学品电子标签选用要求、应用规范与要求以及试验方法。本文件适用于在危险化学品生产、储存、运输、经营、使用以及废弃处置等阶段使用的射频识别电子标签。

# 3 术语和定义

GB/T32830.1—2016界定的以及下列术语和定义适用于本文件。

3.1

射频识别 radio frequency identification;RFID

使用电磁耦合或感应耦合，通过各种调制和编码方案，与电子标签进行双方向通信，并读取电子标签信息。

[来源：GB/T32830.1—2016，3.1]

3.2

# 电子标签 electronic tag

用于物体或物品标识、具有信息存储机制的、能接收读写设备的电磁场调制信号并返回响应信号的数据载体。

[来源:GB/T32830.1—2016,3.2]

3.3 无源电子标签 passive electronic tag不含内装电池、通过从阅读器发出的射频能量中提取其工作所需电源的电子标签。

3.4

保留区 reserve area电子标签中用于存储灭活口令和访问口令的存储区域。

3.5 电子产品代码区 EPC area电子标签中用于存储识别标签对象的电子产品码的存储区域。

# 4 选用要求

# 4.1 电子标签一般要求

# 4.1.1 工作模式

危险化学品电子标签应为无源电子标签。

# 4.1.2 工作频率

4.1.2 工作频率危险化学品电子标签工作频段应为超高频（Ultra High Frequency），频率范围为  $840\mathrm{MHz}\sim 960\mathrm{MHz}$ ，标签空中接口特性应符合GB/T29768或ISO/IEC18000- 63的规定。

# 4.1.3 标签存储

标签存储器特性应满足如下要求：

4.1.3 标签存储标签存储器特性应满足如下要求：a）标签数据保存时间不小于10年；b）标签擦写次数不小于1万次；c）标签存储应具备用户区。危险化学品唯一编码可存储于电子标签的电子产品代码区、用户区或两区域同时使用，应结合所采用的危险化学品标识编码体系确定标签各区存储容量，以满足危险化学品编码的存储需求。

# 4.1.4 标签读写性能

标签读写性能应满足如下要求：

4.1.4 标签读写性能标签读写性能应满足如下要求：a）在无任何遮挡的环境下，标签的读写距离应不小于  $5\mathrm{m}$ ，单个标签读取时间不超过  $5\mathrm{ms}$ ；b）电子标签粘接于各种金属材料上，其读写距离不应低于空气中读写距离的  $80\%$ ；c）将电子标签置于周围分布有金属的环境下，其标签读写距离不应低于空气中读写距离的  $80\%$ ；d）批量读取40个电子标签的时间不超过  $5\mathrm{s}$ 。

# 4.2 电子标签环境适应性要求

# 4.2.1 工作温度、湿度

4.2.1 工作温度、湿度电子标签的工作温度范围应至少满足  $- 35^{\circ}C\sim 70^{\circ}C$  ，存储温度范围应至少满足  $- 40^{\circ}C\sim 150^{\circ}C$  存储、工作湿度范围应至少满足相对空气湿度  $20\% \sim 95\%$  。

# 4.2.2 封装外壳防护

4.2.2 封装外壳防护电子标签封装外壳应密封防尘防水，外壳防护等级（IP代码）符合GB/T4208—2017中IP68的要求，暴露在沙子、尘土、雨雪、盐雾等环境中之后仍可正常工作，并且没有损伤。

# 4.2.3 防静电性能

4.2.3 防静电性能在承受  $2\mathrm{kV}$  的静电放电电压后，标签读写性能不发生改变，并保持存储数据的完整性。电子标签封装外壳需防静电。

# 4.2.4 弱酸、弱碱适应性

在接触  $\mathrm{pH}$  值为  $5\sim 9$  的物质后，封装不因腐蚀发生破裂等异常现象，电子标签能够正常工作。

# 4.2.5 自由跌落适应性

4.2.5 自由跌落适应性当电子标签粘接于  $10\mathrm{kg}\sim 100\mathrm{kg}$  的物品侧面或底面，从  $2.5\mathrm{m}$  高度的地方跌落，标签读写性能不发生改变，并保持存储数据的完整性。封装不发生异常，粘接效果不发生改变。

# 4.2.6 机械冲击适应性

4.2.6 机械冲击适应性在受到总均方根加速度值  $(g_{\mathrm{rms}})$  为30的机械冲击  $11\mathrm{ms}$  后，仍能正常运行，  $x,y,z$  轴3个方向上至少达到3个半正弦波脉冲。

# 4.2.7 大气条件适应性

4.2.7 大气条件适应性电子标签的工作气压范围应至少满足  $86\mathrm{kPa}\sim 106\mathrm{kPa}$  。在该工作气压范围及4.2.1所述条件下读写性能均不发生改变，封装不发生破裂、鼓胀等异常现象，粘接效果不发生改变。

# 4.3 电子标签封装要求

4.3.1 电子标签的封装材料应结合其需要附着的表面类型，可选择工程塑料等硬质材料或树脂胶等柔性材料。

4.3.2 封装后电子标签的读写性能应符合4.1.4的要求，环境适应性应符合4.2的要求。

# 4.4 电子标签外观要求

4.4 电子标签外观要求使用电子标签的危险化学品，应在标签适当位置标识如图1所示的RFID标识符号。对于采用硬质材料封装的标签，应以激光刻录方式刻录在表面；对于采用柔性材料封装的标签，相关信息应印制在标签的滴胶层内。

# 5 电子标签应用规范与要求

# 5.1 电子标签安装要求

# 5.1.1 安装方式

5.1.1.1 根据不同危险化学品的包装形式和电子标签附着的表面类型，电子标签可在产品或周转容器上以反应胶粘接、不干胶粘接、扎带固定、铆钉铆接等方式进行安装固定。5.1.1.2 标签的安装不应影响危险化学品外包装或其周转容器的正常使用和使用寿命。

# 5.1.2 安装位置

5.1.2.1 对于采用独立式包装的危险化学品，应根据其包装形式、形状等，选择不易碰撞、易于读取的位置进行安装，并保证同批次产品的安装位置相同。5.1.2.2 对于使用周转容器进行转运的危险化学品，尽量与容器铭牌等已有标识合并或并列安装，或考虑读取器架设方位、角度等现场条件，选择易于读取的位置进行安装。5.1.2.3 对于包装可回收重新利用的危险化学品，宜考虑电子标签在包装重复利用时不易受到损坏，选择恰当位置安装，保证电子标签在包装重复利用时的完整性和可用性。

# 5.1.3 防转移要求

标签被安装固定后，受外力剥离后应无法直接将该标签转移到其他危险化学品上使用。

# 5.2 电子标签信息安全要求

电子标签存储信息应具有不可篡改性，即采用一写多读模式，产品信息写入后未经授权只能读取，不可更改。

# 6 试验方法

# 6.1 金属环境中的读写性能

随机选取50枚电子标签，置于周围分布有规则或不规则金属环境下，且金属分布的磁场强度为 $2.0\mathrm{A / m}\sim 7.5\mathrm{A / m}$ ，按厂家给定的读写距离标准，对每个标签进行400次的标签读写测试，总正确率不低于  $99\%$  。

# 6.2 粘接于金属表面的读写性能

随机选取50枚电子标签，分别粘接于各种金属材料（纯金属、合金、金属间化合物和特种金属材料等）上，置于金属分布的磁场强度为  $2.0\mathrm{A / m}\sim 7.5\mathrm{A / m}$  环境下，在满足5.1.2的要求前提下，按厂家给定的读写距离标准，对每个标签进行400次的标签读写测试，总正确率不低于  $99\%$  。

# 6.3 防静电（ESD）性能

按照GB/T17626.2规定的方法进行试验。

# 6.4 接触弱酸、弱碱后的读写性能

随机选取100枚电子标签分为两组，每组50枚，对其中一组喷洒  $\mathrm{pH}$  值为5的液体，另一组喷洒 $\mathrm{pH}$  值为9的液体，静置干燥后，按厂家给定的读写距离标准，对每个标签进行400次的标签读写测试，总正确率不低于  $99\%$  。

# 6.5 自由跌落适应性

按照GB/T2423.7—2018规定的方法进行试验。

# 6.6 机械冲击适应性

按照IEC60068- 2- 53：2010规定的方法进行试验。

# 6.7 大气条件适应性

按照GB/T2423.10规定的方法进行试验。
