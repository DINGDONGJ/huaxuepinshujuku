## 数据库配置详解

### 1. Web应用配置 (`app.py`)

#### 配置位置

文件：`new_db/app.py`  
行数：约 21-28 行

#### 默认配置

```python
# 数据库配置
DB_CONFIG = {
    'host': 'localhost',           # 数据库主机地址
    'user': 'root',                # 数据库用户名
    'password': '1234',            # 数据库密码
    'database': '危化品简化数据库',  # 数据库名称
    'charset': 'utf8mb4',          # 字符集（不建议修改）
    'cursorclass': pymysql.cursors.DictCursor  # 游标类型（不建议修改）
}
```

#### 配置参数说明

| 参数 | 默认值 | 说明 | 示例 |
|------|--------|------|------|
| `host` | `localhost` | 数据库服务器地址 | `192.168.1.100`、`db.example.com` |
| `user` | `root` | 数据库登录用户名 | `msds_user`、`admin` |
| `password` | `1234` | 数据库登录密码 | `MyP@ssw0rd!` |
| `database` | `危化品简化数据库` | 要使用的数据库名 | `chemical_db`、`msds_system` |
| `charset` | `utf8mb4` | 字符编码（必须utf8mb4支持中文） | 保持默认 |
| `cursorclass` | `DictCursor` | 查询结果返回格式 | 保持默认 |

#### 修改示例

**场景1：本地数据库，自定义密码**
```python
DB_CONFIG = {
    'host': 'localhost',
    'user': 'root',
    'password': 'MyStrongPassword123',  # 修改为你的密码
    'database': '危化品简化数据库',
    'charset': 'utf8mb4',
    'cursorclass': pymysql.cursors.DictCursor
}
```

**场景2：远程数据库服务器**
```python
DB_CONFIG = {
    'host': '192.168.1.100',      # 远程服务器IP
    'user': 'msds_admin',         # 远程数据库用户
    'password': 'RemoteDB@2024',  # 远程数据库密码
    'database': '危化品简化数据库',
    'charset': 'utf8mb4',
    'cursorclass': pymysql.cursors.DictCursor
}
```

**场景3：云数据库（如阿里云RDS）**
```python

    'host': 'rm-xxxxxx.mysql.rds.aliyuncs.com',  # RDS地址
    'port': 3306,                                  # 端口（默认不写就是3306）
    'user': 'msds_user',                           # RDS账号
    'password': 'CloudDB@2024',                    # RDS密码
    'database': 'chemical_db',                     # RDS数据库名
    'charset': 'utf8mb4',
    'cursorclass': pymysql.cursors.DictCursor
}
```

```python
parser.add_argument('--password', default='1234', help='数据库密码（默认：1234）')
```

### 3. 数据库初始化脚本 (`init_simple_db.sql`)

#### 配置位置

文件：`new_db/init_simple_db.sql`  
行数：14-20 行

#### 默认配置

```sql

    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;
```

#### 修改示例

如果要使用英文数据库名：

```sql

    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

CREATE DATABASE IF NOT EXISTS chemical_msds_db
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

```

## 常见问题

### Q1: 连接被拒绝 (Connection refused)

**错误信息**：
```
pymysql.err.OperationalError: (2003, "Can't connect to MySQL server on 'xxx' ([Errno 111] Connection refused)")
```

**解决方法**：
1. 检查MySQL服务是否启动：
   ```bash
   # Windows
   net start mysql
   
   # Linux
   systemctl status mysql
   ```

2. 检查端口是否正确（默认3306）

3. 检查防火墙规则：
   ```bash
   # Linux
   sudo ufw allow 3306
   
   # Windows
   # 在防火墙设置中开放3306端口
   ```

### Q2: 访问被拒绝 (Access denied)

**错误信息**：
```
pymysql.err.OperationalError: (1045, "Access denied for user 'xxx'@'xxx' (using password: YES)")
```

**解决方法**：
1. 检查用户名和密码是否正确

2. 检查用户权限：
   ```sql
   -- 在MySQL中执行
   SELECT user, host FROM mysql.user;
   SHOW GRANTS FOR 'your_user'@'your_host';
   ```

3. 授予权限：
   ```sql
   GRANT ALL PRIVILEGES ON 危化品简化数据库.* TO 'user'@'host';
   FLUSH PRIVILEGES;
   ```

### Q3: 数据库不存在 (Unknown database)

**错误信息**：
```
pymysql.err.OperationalError: (1049, "Unknown database '危化品简化数据库'")
```

**解决方法**：
1. 确认数据库已创建：
   ```sql
   SHOW DATABASES;
   ```

2. 执行初始化脚本：
   ```bash
   mysql -u root -p < new_db/init_simple_db.sql
   ```

### Q4: 字符编码问题

**错误信息**：中文显示乱码

**解决方法**：
1. 确保数据库字符集为 `utf8mb4`：
   ```sql
   ALTER DATABASE 危化品简化数据库 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. 确保连接字符集为 `utf8mb4`：
   ```python
   DB_CONFIG = {
       # ...
       'charset': 'utf8mb4',  # 确保这一行存在
   }
   ```

### Q5: 远程连接超时

**错误信息**：
```
pymysql.err.OperationalError: (2003, "Can't connect to MySQL server on 'remote_ip' (timed out)")
```

**解决方法**：
1. 检查MySQL配置文件 `my.cnf` 或 `my.ini`：
   ```ini
   [mysqld]
   bind-address = 0.0.0.0  # 允许远程连接
   ```

2. 重启MySQL服务

3. 检查云服务器安全组规则是否开放3306端口

### Q6: 表不存在

**错误信息**：
```
pymysql.err.ProgrammingError: (1146, "Table '危化品简化数据库.化学品' doesn't exist")
```

**解决方法**：
1. 检查是否执行了初始化脚本

2. 手动执行：
   ```bash
   mysql -u root -p 危化品简化数据库 < new_db/init_simple_db.sql
   ```
