# 出口烟花爆竹用烟火药剂安全性能检验方法 第2部分:  $75~\mathrm{^{\circ}C}$  热安定性测定

# 1范围

1 范围SN/T 1731 的本部分规定了出口烟花爆竹用烟火药剂  $75~\mathrm{^{\circ}C}$  热安定性测定的试验方法。本部分适用于出口烟花爆竹用烟火药剂  $75~\mathrm{^{\circ}C}$  热安定性的测定。

# 2规范性引用文件

下列文件对于本文件的应用是必不可少的。凡是注日期的引用文件,仅注日期的版本适用于本文件。凡是不注日期的引用文件,其最新版本(包括所有的修改单)适用于本文件。

SN/T0306.4出口烟花爆竹检验规程第4部分:安全性检验

# 3术语和定义

下列术语和定义适用于本文件。

3.1

# 75℃热安定性thermalstabilityat75℃

在  $75~\mathrm{^{\circ}C}$  恒定温度下,测试烟花爆竹产品烟火药剂在一定时间范围内对热相对稳定性。

# 4测试条件

4.1设备和材料如下:

a) 玛瑙研钵;

b) 油压千斤顶;

c) 天平(精度  $0.01\mathrm{g}$  )

d)  $75~\mathrm{^{\circ}C}$  热安定性试验自动控制装置;

e) 测温探头(准确度  $1~\mathrm{^{\circ}C}$  ,测温范围  $0~\mathrm{^{\circ}C}\sim 100~\mathrm{^{\circ}C}$  )

f) 惰性参比物质:见SN/T0306.4;

g) 平底玻璃试管:  $150\mathrm{mm}\times \phi 2.2\mathrm{mm}$

h) 橡胶塞;

i) 称量纸。

4.2测试条件如下:

a) 温度:见SN/T0306.4;

b) 时间:见SN/T0306.4。

# 5测试方法

# 5.1取样

5.1.1以烟花爆竹每个烟火药剂配方进行检测,当烟花产品具有多个药剂配方时,应将各效果药剂

分离。

5.1.2 小颗粒烟火药剂配方直接用玛瑙研钵研成粉状;大颗粒烟火药剂配方先用油压千斤顶压碎,再用玛瑙研钵研成粉状。

5.1.3 测试样品过筛 80 目,放于称量纸上。

5.1.4 用天平称取测试样  $10 \mathrm{~g} \pm 0.1 \mathrm{~g}$  。

# 5.2 原理

一定量的烟花爆竹烟火药剂在  $75^{\circ} \mathrm{C}$  恒温环境中,在规定的时间内有无燃烧、爆炸或药温与参比物的温度差等于或大于  $3^{\circ} \mathrm{C}$  的现象,以此判定被测烟火药剂是否符合规定要求。

# 5.3 步骤

5.3.1 将纯净水加入  $75^{\circ} \mathrm{C}$  热安定性试验自动控制装置的电热恒温水浴锅中,接通电源,将温度设定为  $75^{\circ} \mathrm{C}$  。

5.3.2 将称取的试样和惰性参比物质  $(10 \mathrm{~g} \pm 0.1 \mathrm{~g})$  分别放入平底玻璃管内,插入测温探头顶端深至烟火药剂中部位置,塞好橡胶塞,如图 1。
