# PDF查看功能使用说明

## ✅ 功能已实现

现在您可以在MSDS第15部分"法规信息"中，点击法规名称直接查看对应的PDF文件！

---

## 🎯 使用方法

### 1. 查看化学品MSDS
- 在搜索框中输入化学品名称或CAS号（如：乙酸乙酯）
- 点击"🔍 搜索"按钮

### 2. 找到第15部分
- 滚动到MSDS结果页面的第15部分"法规信息"
- 查找包含法规名称的小标题（带有📄图标的）

### 3. 点击法规名称
- 点击如"《易制爆危险化学品名录（2011年版）》，公安部2011年11月25日公告 📄"
- 系统会自动弹出PDF查看器并加载对应的PDF文件

### 4. PDF查看器功能
- **⬅️ 上一页 / 下一页 ➡️**：翻页浏览
- **🔍 缩小 / 放大**：调整PDF显示大小
- **✕ 按钮**：关闭PDF查看器
- **ESC键**：快捷键关闭PDF查看器

## 🔧 如何添加新的法规PDF

### 步骤1：添加PDF文件
将PDF文件复制到 `new_db/pdf/` 文件夹中。

### 步骤2：更新代码映射
编辑 `new_db/templates/index.html`，找到 `regulationPdfMap` 对象（约2604行）：

```javascript
const regulationPdfMap = {
    '易制爆危险化学品名录': '易制爆危险化学品名录.pdf',
    '危险化学品目录': '危险化学品目录2015.pdf',
    '高毒物品目录': '高毒物品目录.pdf',
    
    // 添加新的法规
    '您的法规关键词': '您的PDF文件名.pdf',
};
```

### 步骤3：重启Web服务
重启Flask应用即可生效。

## ❓ 常见问题

### Q1: PDF加载失败怎么办？
**A**: 检查以下几点：
1. PDF文件是否存在于 `new_db/pdf/` 文件夹中
2. 文件名是否与代码中的映射一致
3. 文件是否损坏（尝试在本地打开）
4. 浏览器控制台是否有错误信息

### Q2: 为什么有些法规名称不能点击？
**A**: 只有在 `regulationPdfMap` 中配置的法规才能点击。未配置的法规名称会显示为普通文本。

### Q3: 可以跳转到PDF的指定页码吗？
**A**: 当前版本先打开第1页，后续可以通过建立化学品-页码映射实现精确跳转。

### Q4: PDF加载速度慢怎么办？
**A**: 
- 压缩PDF文件大小
- 使用更快的网络连接
- 考虑使用CDN加速PDF文件访问

### Q5: 移动端可以查看PDF吗？
**A**: 可以！PDF查看器已优化响应式布局，支持移动端访问。
