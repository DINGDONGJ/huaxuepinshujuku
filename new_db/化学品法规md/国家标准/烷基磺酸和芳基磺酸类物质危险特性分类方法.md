# 烷基磺酸和芳基磺酸类物质危险特性分类方法

# 1范围

本标准规定了烷基磺酸和芳基磺酸类物质危险特性分类试验的术语和定义、原理、试剂、仪器、游离硫酸含量测定及分类方法。

本标准适用于烷基磺酸和芳基磺酸类物质危险特性分类试验。

# 3术语和定义

联合国《关于危险货物运输的建议书 规章范本》《关于危险货物运输的建议书 试验和标准手册》界定的以及下列术语和定义适用于本文件。

3.1

腐蚀性物质 corrosive substances

在接触生物组织时会造成严重损伤、或在渗漏时会严重损害甚至毁坏其他货物或运输工具的物质。

3.2

烷基磺酸·alkylsulphonic acids

分子式以  $\mathbf{R - SO}_{3}\mathbf{H}$  (R为烷基)为特征的化学品。

3.3

芳基磺酸 arylsulphonic acids

分子式以  $\mathbf{R - C}_{6}\mathbf{H}_{4}\mathbf{- SO}_{3}\mathbf{H}$  (R为烷基)为特征的化学品。

# 4原理

依据GB/T8447以双硫原作指示剂,用硝酸铅标准溶液滴定缓冲的试样丙酮溶液,测定烷基磺酸和芳基磺酸类物质中的游离硫酸的含量,并按照联合国《关于危险货物运输的建议书 规章范本》进行分类定级。

# 5试剂

除非另有说明,所用试剂均为分析纯,水为GB/T6682规定的二级水。

5.1 蒸馏水:无二氧化碳蒸馏水。

5.2 丙酮:分析纯。

5.3 浓硝酸:  $65\%$  (质量分数),  $\rho = 1.4 \mathrm{~g} / \mathrm{mL}$  。

5.4 硝酸溶液  $(1.0 \mathrm{~mol} / \mathrm{L})$  :

取浓硝酸(5.3)  $69.2 \mathrm{~mL}$  置于盛有蒸馏水(5.1)的烧杯中,并在  $1000 \mathrm{~mL}$  容量瓶中定容。

5.5 氢氧化钠:分析纯。

5.6 氢氧化钠溶液  $(1 \mathrm{~mol} / \mathrm{L})$  :

取  $8.0 \mathrm{~g}$  氢氧化钠(5.5)溶于蒸馏水(5.1)中,转入  $200 \mathrm{~mL}$  容量瓶中,以蒸馏水(5.1)定容。

5.7 氨水:  $18\%$  (质量分数)。

5.8 硝酸铅:分析纯。

5.9 硝酸铅标准滴定溶液  $(0.01 \mathrm{~mol} / \mathrm{L})$  :

取  $3.5 \mathrm{~g}$  硝酸铅(5.8),溶于蒸馏水(5.1)中,转入  $1000 \mathrm{~mL}$  容量瓶中,蒸馏水(5.1)定容。然后依照  $\mathrm{GB} / \mathrm{T} 601$  进行标定。

5.10 二氯乙酸铵缓冲溶液:

将  $67 \mathrm{~mL}$  二氯乙酸加至约  $250 \mathrm{~mL}$  蒸馏水(5.1)中,在酸度计的指示下,小心地用氨水(5.7)中和至  $\mathrm{pH} = 7$  。待冷却后再加入  $33 \mathrm{~mL}$  的二氯乙酸,并稀释至  $600 \mathrm{~mL}$  。

5.11  $0.5 \mathrm{~g} / \mathrm{L} 1,5$  二苯基硫巴腙(双硫腙)丙酮溶液,棕色瓶中保存,保存期1周。

# 6仪器

普通实验室器具和:

6.1 酸度计。

6.2 精密天平:准确至  $0.001 \mathrm{~g}$  。

7.2.1 用  $50~\mathrm{mL}$  蒸馏水(5.1)溶解样品(7.1), 定容至  $100~\mathrm{mL}$  。

7.2.2 按照表2, 移取相应体积的试样液(7.2.1)至锥形瓶中, 并加蒸馏水(5.1)至  $200~\mathrm{mL}$ , 加入  $1~\mathrm{mL}$  双硫腙溶液(5.11)。然后加入氢氧化钠溶液(5.6)至溶液微红, 再逐滴加入硝酸溶液(5.4), 至出现绿色, 然后加入  $2~\mathrm{mL}$  二氯乙酸铵溶液(5.10)和  $80~\mathrm{mL}$  丙酮(5.2), 立即用硝酸铅标准滴定溶液(5.9)滴定, 至得到稳定的砖红色。

# 7.3 结果计算

按式(1)进行烷基磺酸或芳基磺酸中硫酸含量  $X$  的计算:

\[ X=\frac{0.098 \times V \times C \times 10^{4}}{m_{0} \times V_{0}} \]

式中:

$m_{0}$  试样的质量,单位为克  $(g)$

$V_{0}$  测定时移取的试样体积,单位为毫升  $(\mathrm{mL})$

$V$  滴定消耗的硝酸铅标准滴定溶液的体积,单位为毫升  $(\mathrm{mL})$

$C$  硝酸铅标准滴定溶液的浓度,单位为摩尔每升  $(\mathrm{mol} / \mathrm{L})$

0.098 硫酸的毫摩尔质量,单位为克每毫摩尔  $(\mathrm{g} / \mathrm{mmol})$  。

# 7.4 精密度

两平行样测定所得结果相对误差不超过平均值的  $4\%$  。
