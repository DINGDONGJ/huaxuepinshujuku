# 前言

本标准按照 GB/T 1.1—2009 给出的规则起草。本标准由中国轻工业联合会提出。本标准由全国烟花爆竹标准化技术委员会（SAC/TC 149）归口。本标准起草单位：山东花王烟花爆竹有限公司、湖南烟花爆竹产品安全质量监督检测中心。本标准主要起草人：方钊、钟军、黄茶香、朱玉平、邹曾、徐莉、唐蛟麟。

# 烟花爆竹 规格与命名

# 1范围

本标准规定了烟花爆竹产品的规格及命名规则。本标准适用于烟花爆竹产品。

# 3术语和定义

下列术语和定义适用于本文件。

3.1

# 规格 specification

烟花爆竹产品（含产品中有药筒体）几何尺寸的描述，如体积、长度、外径、内径等。

3.2

# 命名 name

用烟花爆竹特有属性描述产品名称，包括产品类别、产品级别、规格、商品名称、专业名称等信息。

3.3

# 专业名称 academic name

用于描述烟花爆竹产品结构、燃放效果等的一种专业称呼。

3.4

商品名称 commodity name企业用于区分其他烟花爆竹产品的一种商业称呼。

# 4产品规格

# 4.1一般要求

4.1.1烟花爆竹产品规格应使用毫米  $(\mathrm{mm})$  作为计量单位。4.1.2长度用“L”表示，高度用“h”表示，内径用“  $\phi$  ”表示，外径用“  $\Phi$  ”表示，乘号用“  $\times$  ”表示。4.1.3长方体或正方体的烟花爆竹产品规格描述为：“长  $\times$  宽  $\times$  高”。4.1.4圆锥形烟花爆竹产品规格描述为：“圆锥形：底面外径  $\times$  高”。4.1.5圆柱体烟花爆竹产品规格描述为：“底面外径  $\times$  高”。

4.1.6 多面体（如六面体）烟花爆竹产品规格描述为：“六面体：底面边长  $\times$  高”。4.1.7 礼花弹产品规格描述为“3号、4号、5号、6号、7号、8号、10号、12号”。4.1.8 火箭类产品规格描述为：“筒体外径  $\times$  筒体长度  $\times$  产品总长度”。4.1.9 吐珠类产品规格描述为：“产品外径  $\times$  产品总长度”。4.1.10 线香型产品规格描述为：“敷（裹）药部分长度  $\times$  产品总长度”。4.1.11 不规则产品规格应描述为“横向最大尺寸  $\times$  纵向最大尺寸  $\times$  竖向最大尺寸”。4.1.12 烟雾型、摩擦型及其他出口产品的规格按进口国要求执行。

# 5.1 命名规则

# 5.1.1 总则

5.1.1.1 烟花爆竹产品名称的命名规则如图1所示。

5.1.1.2 产品类别按GB10631规定的产品大类、小类确定，产品级别用“A或B或C或D”表示。

5.1.1.3 烟花爆竹产品名称的印刷、字体高度等应符合GB10631和GB24426要求。

5.1.1.4 产品已注册商标时，产品名称宜包含产品商标信息。

5.1.1.5 商品名称由企业自主决定，可按照产品的燃放效果、结构、材质、外形、企业文化等进行命名。

5.1.1.6 除5.1.2.3和5.1.3.3规定以外，产品名称应包含规格信息。

5.1.1.7 爆竹类、双响、吐珠类、礼花类产品的规格信息是指产品的外径；喷花类、旋转类、火箭、旋转升空烟花、烟雾型、架子烟花类产品的规格信息是指产品中有药筒体的外径；组合烟花类产品的规格信息是指筒体内径；线香型产品的规格信息是指产品的总长度。

5.1.1.8 根据印刷排版要求，专业名可另起一行。

5.1.1.9 烟花爆竹产品名称中“烟花爆竹”“产品类别”代码参见附录A。

# 5.1.2 个人燃放类

5.1.2.1 爆竹类、吐珠类、组合烟花类产品商品名称应包含产品的数量信息。

5.1.2.2 爆竹类、喷花类、旋转类、升空类、吐珠类、玩具类（玩具造型除外）产品名称可不包含专业名称。

5.1.2.3 玩具造型（玩具类）产品名称可不含规格信息。

5.1.2.4 个人燃放类产品专业名称示例参见附录B（表B.1）。

# 5.1.3 专业燃放类

5.1.3.1 吐珠类、组合烟花类产品商品名称应包含产品的数量信息。

5.1.3.2 焰火专供产品及架子烟花类产品名称可不含商品名称，礼花弹产品商品名称可用“××号礼花弹”命名。

5.1.3.3 礼花弹产品商品名称用“××号礼花弹”命名时，产品名称可不含规格信息。

5.1.3.4 旋转类、升空类产品名称可不含专业名。

5.1.3.5 专业燃放类产品专业名示例参见附录B（表B.2）。
