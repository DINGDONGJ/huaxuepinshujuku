============================================================================
MSDS图片爬取功能 - 使用说明
============================================================================

📸 功能介绍
============================================================================
本系统现在支持自动爬取和显示MSDS中的图片，特别是：
1. 第二部分 - GHS危险性象形图
2. 第十四部分 - 运输标签图片

✨ 功能特点
============================================================================
✅ 自动下载图片到本地
✅ 避免重复下载（使用URL哈希命名）
✅ 数据库存储图片路径（JSON格式）
✅ Web界面美观显示
✅ 支持鼠标悬停放大效果

📋 数据库结构变化
============================================================================
MSDS章节表新增字段：
  图片JSON - 存储图片信息数组
  格式：[
    {
      "url": "images/abc123.png",
      "alt": "GHS象形图",
      "type": "ghs",
      "original_url": "http://..."
    }
  ]

🚀 使用步骤
============================================================================

1. 更新数据库结构
-------------------
mysql -u root -p1234
DROP DATABASE IF EXISTS 危化品简化数据库;
source C:\Users\Administrator.DESKTOP-URBQKM0\Desktop\huaxuepinshujuku\new_db\init_simple_db.sql
exit

2. 爬取带图片的MSDS数据
-------------------
方式A：使用批处理（推荐）
  双击：run_scraper.bat
  选择：[2] 爬取并直接导入数据库
  输入URL
  
方式B：使用命令行
  cd new_db
  python scrape_to_json.py "URL" --import

3. 查看结果
-------------------
爬取后会在 msds_json/ 文件夹中生成：
  ├── 化学品名_CAS号.json       # JSON数据文件
  └── images/                     # 图片文件夹
      ├── abc123.png             # GHS象形图
      └── def456.png             # 运输标签

4. 启动Web应用查看
-------------------
双击：start_web.bat
访问：http://localhost:5001
搜索化学品，展开第2部分或第14部分即可看到图片

🎨 图片显示效果
============================================================================
- 图片自动排列，支持多张显示
- 每张图片最大200x200px
- 鼠标悬停有放大效果
- 带图片说明文字
- 紫色主题，与整体风格一致

🔧 技术细节
============================================================================
图片下载：
  - 使用requests库下载
  - MD5哈希命名避免重复
  - 超时设置10秒
  - 自动处理相对路径

图片过滤：
  - 自动跳过logo、二维码等无关图片
  - 只下载第2部分和第14部分的图片

存储策略：
  - 图片文件：msds_json/images/xxx.png
  - 数据库：JSON格式存储路径和元数据
  - Web访问：通过Flask静态路由提供

⚠️ 注意事项
============================================================================
1. 图片文件夹位置固定在 msds_json/images/
2. 确保该文件夹有写入权限
3. 图片会自动去重，相同URL只下载一次
4. Web应用需要能访问 msds_json/ 文件夹

🆘 常见问题
============================================================================
Q: 爬取后看不到图片？
A: 检查 msds_json/images/ 文件夹是否存在且有图片文件

Q: Web界面显示图片404？
A: 确保Flask应用和msds_json文件夹在同一目录

Q: 想手动添加图片？
A: 将图片放到 msds_json/images/ 并在数据库中添加JSON记录：
   UPDATE MSDS章节 SET 图片JSON = '[{"url":"images/xxx.png","alt":"说明","type":"ghs"}]'
   WHERE 章节序号 = 2;
