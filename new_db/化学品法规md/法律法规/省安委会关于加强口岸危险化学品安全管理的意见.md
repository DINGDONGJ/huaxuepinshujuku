# 省安委会关于加强口岸危险化学品安全管理的意见

苏安〔2018〕10号

各设区市人民政府，省安委会各成员单位：

为深入贯彻落实党的十九大精神，进一步加强我省危险化学品安全管理，完善口岸危险化学品安全保障体系，省交通运输厅会同省安监局等相关部门起草了《关于加强口岸危险化学品安全管理的意见》，现印发给你们，请结合实际，认真贯彻落实。

江苏省安全生产委员会  2018年4月8日

# 关于加强口岸危险化学品安全管理的意见

我省是危险化学品大省，经济总量、港口吞吐量、进出口数量位居全国前列，对危险化学品生产、使用、仓储、装卸、运输等环节的安全管理带来了严峻挑战，根据《中共中央国务院关于推进安全生产领域改革发展的意见》《国务院办公厅关于印发危险化学品安全综合治理方案的通知》《中共江苏省委江苏省人民政府关于印发“两减六治三提升”专项行动方案的通知》等精神，为促进江苏口岸危险化学品健康发展，现提出以下意见：

# 一、总体要求

深入贯彻落实党的十九大精神，坚持创新、协调、绿色、开放、共享发展理

念，积极适应经济发展新常态和石化产业发展新趋势，坚持科学发展、安全发展、绿色发展，全面落实“减化”要求，着力优产业、控规模、提标准、严准入、落责任、强执法、共监管，完善口岸危险化学品安全保障体系，提升安全水平，促进经济社会可持续发展。

# 二、优化化工产业布局

继续推进全省化工企业“四个一批”专项行动，重点实施压减、转移、改造计划，建立化工园区与危化品码头联动发展计划，减少运输中间环节，规范化工园区管理，推动化工企业入园进区。到2020年，全省化工企业入园率达  $50\%$  以上。（省经信委、省环保厅、省安监局、省交通运输厅）

# 三、严控危险化学品规模

沿江危化品码头新建项目严控审批，严格控制新增码头危化品作业品种，梳理危险货物作业附证品种，规范品种名称，对于一年以上未作业的货种，重新评定作业条件。（省交通运输厅）

推进长江江苏段水路运输危化品“限禁控”工作，完成危化品“限禁控”目录研究。（江苏海事局、省交通运输厅）

# 四、严格危险化学品行业准入

（一）推进安全生产标准化达标。推动港区危险化学品生产、装卸、仓储企业实现安全生产标准化二级以上达标，一二级危险化学品重大危险源、具有爆炸危险性装置和场所的企业应当达到安全生产二级标准化。强化安全生产标准化运行监督检查，提升港区危化品企业安全管理水平。（省交通运输厅、省安监局）

（二）提升重点运输船舶安全技术性能。研究制定江苏省内河散装危险化学品船舶安全与防污染地方标准。2018年6月1日起全面禁止以船体外板为液货舱的化学品船和600总吨以上单壳油船航行。在长江江苏段水域逐步淘汰III型散装化学品船。推动货主、码头单位实施危险化学品船选船机制。（省交通运输厅、江苏海事局、省质监局）

（三）加强危险化学品重点特种设备准入。对港区内的压力容器、压力管道和气瓶进行全面排查，未按要求定期检验合格的一律停止使用。（省质监局，

港区主管部门）

（四）严格检验监管进出口危险化学品及其包装。按照标准对危险化学品实施检验，严格执行出口危险化学品产地检验、口岸放行，进口危险化学品在入境口岸实施检验的要求。（江苏检验检疫局、南京海关）

# 五、落实企业安全生产主体责任

（一）企业主体责任。督促企业严格落实安全生产责任“五落实五到位”要求，建立健全企业全员安全生产责任制，明确从主要负责人到一线从业人员的安全生产责任、责任范围和考核标准，确保思想到位，责任到位，落实到位。强化对企业和相关责任人责任追究，对发生事故的责任人员从严追究责任，并落实相关禁业限制。（省交通运输厅、省安监局）

（二）加强港口特殊作业和船岸界面管理。推动动火作业第三方监管，对构成一级、二级重大危险源区域内实施一级或特殊动火作业的，实施第三方技术服务机构审核动火作业方案，监督动火。港航企业建立船岸界面管理机制，明确船港双方的安全职责，防控装卸作业安全风险。（省交通运输厅、江苏海事局）

（三）提升企业安全防控能力。构建风险管控和隐患排查治理双重预防机制，完善风险排查、评估、预警和防控机制，在沿江主要危化品港区重点危化品企业开展风险隐患辨识、评估、管控试点工作，并完善推广，落实隐患排查治理制度，实现事故隐患闭环管理，重大事故隐患实施挂牌督办，未按时整改的一律停业整顿。危化品航运企业应当建立并落实自主监控制度，建设并运用CCTV、AIS等系统，实施危化品船舶动态监控。（省交通运输厅、省安监局、江苏海事局）

# 六、强化多部门联合执法

（一）加强联防联控。口岸各单位建立健全信息互通、监管互助、执法互认的工作机制，完善区域协同监管执法工作，实现部门联动、齐抓共管、合力推进的工作格局。强化行政执法与刑事司法衔接，依法严厉打击非法犯罪行为。（南京海关、江苏检验检疫局、省环保厅、省安监局、省交通运输厅、江苏海事局）

（二）加大处罚力度。口岸从事危险化学品的企业发生重大安全环保事故、证照手续不全的或在特殊作业环节发生亡人事故的，一律停产整顿，整顿不合要求的一律不得开工生产和申（换）领工业产品生产许可证、安全生产许可证、

危险化学品安全生产许可证、港口经营许可证、污染物排放许可证。严厉打击涉危不报、高危低报等违法违规行为，并将此类违法违规行为纳入企业信用管理系统。（南京海关、江苏检验检疫局、省环保厅、省安监局、省交通运输厅、江苏海事局）

# 七、强化共同监管

（一）建立联席会议机制。建立由口岸、海关、检验检疫、海事、安监、港口等多部门参与的口岸危险化学品安全管理联席会议机制，联席会议由省交通运输厅、江苏海事局召集，定期研究口岸危险化学品安全管理，每半年通报一次执法监管情况，形成齐抓共管的良好机制。（省交通运输厅、江苏海事局牵头，各相关部门参与）

（二）加强应急救援能力建设。地方人民政府要结合实际，按照“水陆同治、统筹兼顾”原则，强化危险化学品事故应急处置能力，规划建设应急救援基地，加强应急装备建设。建立公安消防部门和危化品码头企业为主的专兼职应急队伍，提升重大危化品事故和第一时间救援能力。（各设区市政府、省公安厅、省交通运输厅、江苏海事局）

（三）强化口岸部门数据共享。加强海关、检验检疫、安监、海事、港口等口岸部门信息互联互通，实现实时数据共享。推动“一船多方”一体化监管平台建设，实现海事、港口、海关、检验等部门共用信息化平台，对船、港、货及其各类运输作业安全的实时全过程监管。（南京海关、江苏检验检疫局、省安监局、省交通运输厅、江苏海事局）

（四）完善港口危化品船舶公共服务设施。加快建设船舶污染物接收设施、公共洗舱站点等公共服务设施，优化危化品船舶锚地布局，满足危化品船舶运行需要。（省交通运输厅、江苏海事局）
