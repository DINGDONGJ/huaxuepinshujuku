# 化学品热稳定性测定第2部分:热重分析法

# 1范围

SN/T3078的本部分规定了温度范围在室温到800℃之间材料热稳定性评估以及材料质量变化程度鉴定的方法。

本部分适用于反应温度范围内不发生升华或蒸发的固体或液体。含能材料,药物以及聚合物都可以使用本部分。本部分尤其适用于那些熔点和反应以及分解初期时间点相重合的物质。

本部分只能被用来测试包含质量变化的反应或分解情况。对于不均匀样品,本部分并不可靠。本部分本身并不能用于确定安全的操作或储存温度。

# 4方法提要

# 5 仪器

# 5.1 热重分析仪(TGA)

5.1.1 热天平,包括:

熔炉:在测试方法适用的温度范围内将样品统一加热至恒定温度或以恒定速率给样品加热。

温度传感器。可以用来测定熔炉或样品的温度,精确到  $\pm 0.1^{\circ}\mathrm{C}$ 。

天平:能连续记录样品质量。最小量程为  $10\mathrm{mg}$ ,灵敏度为  $\pm 10\mu \mathrm{g}$ 。也可使用更大量程的设备。但灵敏度至少为重量的  $\pm 0.1\%$ 。

维持容器惰性或活性气体的纯度在  $99.9 + \%$  并且吹扫速率为  $(20\pm 5)\mathrm{mL} / \mathrm{min}\sim (100\pm 5)\mathrm{mL} / \mathrm{min}$ 。吹扫速率会因使用设备的不同而不同。应避免吹扫速率过快,因为这将会产生空气涡流和温度变化,从而影响实验结果。

注:实验也可以在自发环境中进行。差示扫描量热仪(DSC)中含有直径为  $0.025\mathrm{mm}\sim 0.38\mathrm{mm}$  小孔的密封容器被认为能得到一个气体自发产生饱和的环境。

5.1.2 温度控制器:能够执行特定的温度程序,并能控制在  $(1\pm 0.1)^{\circ}\mathrm{C} / \mathrm{min}\sim (20\pm 0.1)^{\circ}\mathrm{C} / \mathrm{min}$  速率。5.1.3 记录设备:  $Y$  轴可以记录并进行演示任何样品质量信号片段,包括信号噪音,  $X$  轴表示温度或时间信号,包括信号噪音。

5.1.4 容器(平底锅、坩埚等):与样品不会产生反应,在测试方法温度限值下保持热稳定的容器(平底锅、坩埚等)。

注:在自发环境实验中,可使用DSC中含有直径为  $0.025\mathrm{mm}\sim 0.38\mathrm{mm}$  小孔的密封容器。

# 5.2 天平

量程为大于或等于  $100\mathrm{mg}$  的用于称量样品或容器的天平。精确到  $\pm 0.1\mathrm{mg}$ 。

# 5.3 附带设备

将样品装入DSC密封的器皿内进行自发环境研究的装置。

# 6 分析步骤

# 6.1 仪器准备

6.1.1 按照生产商操作手册中的步骤准备TGA。

6.1.2 按照生产商操作手册把温度传感器放在合适位置。应保证样品容器不与传感器接触,除非TGA设计的时候将温度传感器安置在坩埚座上。同样重要的是温度传感器在温度标定后不能移动。

6.1.3 在整个实验过程中,熔炉气流速率维持在  $20 \mathrm{mL} / \mathrm{min} \sim 100 \mathrm{mL} / \mathrm{min}$ 。

# 6.2 取样和安全预防

6.2.1 样品应该是能代表测试材料的样品,包括颗粒大小和纯度。

6.2.2 在其他信息不足的情况下,样品接收后应该立即对其进行分析。如果在分析之前,需对样品进行某种加工,例如干燥,其中导致的质量变化必须在报告中详细记录。

6.2.3 样品质量的选择取决于材料的危险度,仪器的灵敏度,加热速率以及样品均一性。此测试方法材料数量越少越好。但样品量应足够代表材料,并提供足够信号。通常材料的质量是  $1 \mathrm{mg} \sim 10 \mathrm{mg}$ 。应考虑样品的大小,因为厚的样品会因样品内部导热性滞后而发生转折变宽。

6.2.4 对于未知危险性的材料,第一次使用该检测方法进行检测时,需要在样品准备和测试之前采取相应的预防措施。

6.2.5 大样品(大于  $5 \mathrm{mg}$  )应该在考虑其潜在危险反应之后进行试验。对于含能材料或者性质不明的材料最安全的方法为一开始使用质量不超过  $1 \mathrm{mg}$ ,并且使用低加热速率  $(1^{\circ}\mathrm{C} / \mathrm{min} \sim 10^{\circ}\mathrm{C} / \mathrm{min})$ 。

6.2.6 当需要对材料进行磨压来减少大小时,测试方法的使用者需要假设材料对于摩擦或静电放电有一定敏感度。因此,在磨压之前,要对材料进行适当的测试。对于一些不清楚其危险度的材料,在准备材料时,应该使用适当的保护设备。如果有材料安全数据表的话,在处理未知材料之前,应该进行研究或学习。

6.2.7 如果被测材料在加热时可能产生对人体或设备有害或腐蚀性气体的,应该采用排烟设备来处理掉这些排弃气体。

# 6.3 推荐测试条件

6.3.1 样品质量:  $5 \mathrm{mg}$ 。如果材料性质不明,可以减少至  $1 \mathrm{mg}$ 。

注:对于含能物质,建议样品量不超过  $1.0 \mathrm{mg}$ 。

6.3.2 加热速率:  $10^{\circ}\mathrm{C} / \mathrm{min} \sim 20^{\circ}\mathrm{C} / \mathrm{min}$ 。

注1:起始温度受加热速率的影响。所以只有在相同的加热速率的情况下得到的值才具有可比性。

注2:当质量发生复杂的变化时,建议使用较低的加热速率  $(1^{\circ}\mathrm{C} / \mathrm{min} \sim 10^{\circ}\mathrm{C} / \mathrm{min})$ 。

注3:对于含能材料,建议使用较低的加热速率  $(1^{\circ}\mathrm{C} / \mathrm{min} \sim 10^{\circ}\mathrm{C} / \mathrm{min})$ 。对于爆炸品,建议加热速率不能超过  $3^{\circ}\mathrm{C} / \mathrm{min}$ 。

6.3.3 温度范围:温度范围为室温至  $600^{\circ}\mathrm{C}$ 。

# 6.4 校准

6.4.1 采用ASTM E2040或者生产商仪器准则及详细记录对质量信号进行校准。

6.4.2 根据ASTM E1582校准熔炉的温度,采用相同的加热速率,吹扫气体,气流速率,温度传感器,这

样也方便以后的样品试验。

# 6.5 测定步骤

6.5.1 准备一个空的干净的样品容器,称重调零。

6.5.2 将重量在量程的  $10\%$  之内的样品放置于调零好的容器内,称重。

注:粉末和颗粒样品应均匀分布于样品容器内,使得暴露面积最大化。

6.5.3 在室温状态下,把样品和容器放到TGA里。

6.5.4 以  $10^{\circ}\mathrm{C} / \mathrm{min}$  的恒定速率对样品进行加热,并且记录在TG曲线上。持续加热,直到质量不发生变化,或者温度远远大于受试物质的有效温度范围。

注:可以使用其他加热速率,但是需要报告。

6.5.5 试验完成后,冷却装置到室内温度,清理容器,并更换新的容器。

6.5.6 描绘TG和DTG曲线。

6.5.7 在TG曲线上,将初始质量随着温度升高外推建立基准线。

6.5.8 在TG曲线上选择最先发现与基线偏离的点作为初始温度  $(T_{0})$  。

注1:将TG曲线质量变化  $1\% \sim 2\%$  区域放大,选择起始温度(见图2)。

注2:起始温度也可以通过DTG曲线得到,然而,只有同一方法得到的结果具有可比性。

6.5.9 初始温度时样品质量减去加热后质量变化平台期样品质量,得到样品反应或分解的质量变化。

注:建议重复试验,特别是对于不拘一格样品,计算两次试验起始温度和质量变化的平均值和标准偏差。

# 7 精密度和偏差

7.1 该试验方法的精密度和偏差可由2008年的实验室间测试得到。13个实验室使用来自6个制造商10种型号的热重分析仪对聚乙烯对苯二甲酯(PET)进行了检测。检测指标为TG起始温度、TG质量变化和DTG起始温度。每个实验室重复5次,并报道起始温度和质量变化。最终,根据ASTM E691进行数据分析。

7.2 实验室内的变化可以使用重复性标准差乘以2.8得到的重复性限  $(r)$  来表示。在重复性条件下,

两次测试结果之差的绝对值不超过重复性限的概率为  $95\%$  。即如果实验室内两个检测值间差异大于重复性限,则结果可疑。TG 起始温度重复性标准差为  $6^{\circ} \mathrm{C}$  。TG 质量变化重复性标准差为  $0.6\%$  。DTG 起始温度重复性标准差为  $5^{\circ} \mathrm{C}$  。

7.3 实验室间的变化可以使用再现性标准差乘以 2.8 得到的再现性限  $(K)$  来表示。在再现性条件下,两次测试结果之差的绝对值不超过再现性限的概率为  $95\%$  。即如果实验室间两个检测值差异大于再现性限,则结果可疑。TG 起始温度再现性标准差为  $54^{\circ} \mathrm{C}$  。TG 质量变化再现性标准差为  $2.3\%$  。DTG 起始温度再现性标准差为  $18^{\circ} \mathrm{C}$  。

7.4 偏差是指测试结果和参考值之间的差值。因为没有聚乙烯对苯二甲酯热稳定性的参考值,故不能提供偏差的信息。在  $10^{\circ} \mathrm{C} / \min$  加热速率下,聚乙烯对苯二甲酯的平均 TG 起始温度、平均 TG 质量变化和平均 DTG 起始温度分别为:  $304^{\circ} \mathrm{C}$  、  $- 87.0\%$  和  $335^{\circ} \mathrm{C}$  。
