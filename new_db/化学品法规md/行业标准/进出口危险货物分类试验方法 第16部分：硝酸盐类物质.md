# 氧化性固体 oxidizing solid

在与某一种可燃物质完全混合时可以增加该可燃物质的燃烧速度或燃烧强度的固体物质。

# 4试验要求

4.1 应检查将用于运输形式的物质是否含有直径小于  $500\mu \mathrm{m}$  的颗粒。如果直径小于  $500\mu \mathrm{m}$  的粉末占总质量的  $10\%$  以上，或者该物质是易碎的，则在进行试验前应将全部试验样品磨成粉末，以便照顾到在装卸和运输过程中货物粒度减小的情况。

4.2实验需要有一定程度的通风、但气流速度为不大于  $0.5\mathrm{m / s}$  的通风橱或其他通风区域进行，排烟系统应适合于吸收有毒的烟气。

4.3 固体氧化性试验在常压、环境温度  $20^{\circ}C\pm 5^{\circ}C$  下进行。

# 5试验

# 5.1 试验项目

氧化性固体试验。

# 5.2 样品数量

从待检货物中随机抽取代表性物质  $500\mathrm{g}$  ，用于危险特性试验。

# 5.3 试验准备

# 5.3.1 溴酸钾参考物质

5.3.1 溴酸钾参考物质过筛, 但不应研磨, 粒径  $0.15 \mathrm{mm} \sim 0.30 \mathrm{mm}$ , 工业纯。在  $65^{\circ} \mathrm{C}$  下干燥至恒重 (至少  $12 \mathrm{~h}$  ), 然后放到干燥器内 (带干燥剂), 冷却后备用。

# 5.3.2 纤维

5.3.2 纤维纤维素丝, 长度  $50 \mu \mathrm{m} \sim 250 \mu \mathrm{m}$ , 平均直径  $25 \mu \mathrm{m}$  。将干纤维素丝做成厚度不大于  $25 \mathrm{mm}$  的薄层, 于  $105^{\circ} \mathrm{C}$  下干燥至恒重 (至少  $4 \mathrm{~h}$  ), 然后放到干燥器内 (带干燥剂), 冷却后备用。含水率 (以干重计) 应小于  $0.5\%$ , 必要时可延长干燥时间。

# 5.3.3 点火源

即与电源联接的惰性金属线（如镍/铬），应满足如下特性：

a) 长度:  $30 \mathrm{~cm} \pm 1 \mathrm{~cm}$ ; 
b) 直径:  $0.60 \mathrm{~mm} \pm 0.05 \mathrm{~mm}$ ; 
c) 电阻:  $6.0 \Omega / \mathrm{m} \pm 0.5 \Omega / \mathrm{m}$ ; 
d) 金属线耗电功率:  $150 \mathrm{~W} \pm 7 \mathrm{~W}$ ; 
e) 金属线见附录A中图A1所示的形状。

# 5.4 试验设备

# 5.4.1 玻璃漏斗

一端封闭、内直径  $70~\mathrm{mm}$  的  $60^{\circ}$  玻璃漏斗。

# 5.4.2 试验平板

试验平板应能防渗透并满足如下要求：

a) 长度:  $150 \mathrm{~mm}$ ; 
b) 宽度:  $150 \mathrm{~mm}$ ; 
c) 厚度:  $6 \mathrm{~mm}$ ; 
d) 导热率  $(0^{\circ} \mathrm{C}$  时):  $0.23 \mathrm{~W}(\mathrm{~m} \cdot \mathrm{K})$  。

# 5.4.3 天平

可精确至  $0.01\mathrm{g}$  0

# 5.5 试验步骤

5.5.1  $30.0 \mathrm{~g} \pm 0.1 \mathrm{~g}$  的参考物质和纤维混合物按照溴酸钾对纤维素的质量比  $3: 7, 2: 3$  和  $3: 2$  配置。  $30.0 \mathrm{~g} \pm 0.1 \mathrm{~g}$  的待试验物质 (其粒度为将用于运输的粒度) 和纤维素混合物按样品对纤维素的质量比  $4: 1$  和  $1: 1$  配置, 每一份混合物应以机械方法不过分用力地尽可能彻底混合。

5.5.2使用玻璃漏斗将混合物做成底部直径  $70~\mathrm{mm}$  的截头圆锥体，将此圆锥体样品放在平放于低导热平板的环形点火金属线上。

5.5.3点火金属线接通电源并在试验期间内保持通电，如混合物不起火和燃烧则保持通电  $3\mathrm{min}$  。记录的燃烧时间是从电源接通到主要反应(例如火焰，灼热或无焰燃烧)结束。在主要反应之后的间歇反应，如火花或嘴啪作响应不予考虑。如果加热金属线在试验期间断裂，应重新试验。对于每一样品应进

行5次平行试验。
