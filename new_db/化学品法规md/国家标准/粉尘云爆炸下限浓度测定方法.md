# 粉尘云爆炸下限浓度测定方法

# 1范围

本标准规定了粉尘- 空气混合物爆炸下限浓度测定的试验装置、试验程序、其他可替代的试验方法、安全措施和试验报告。

本标准适用于依赖空气中的氧维持其氧化反应的可燃粉尘。

本标准不适用于火炸药或不依赖空气中的氧即可燃烧爆炸的物质。

# 4试验装置

# 4.1概述

本试验装置适用于测定粒度不超过  $75\mu \mathrm{m}$  和水分不超过  $5\%$  的可燃粉尘的爆炸下限浓度。实际上，如果粒度较大或水分较高的粉尘能在爆炸罐中有效地扩散，则可用此装置进行测定，受试粉尘的粒度分布和水分应能代表使用物质的粒度分布和水分。

# 4.2装置

装置由容积为  $20L$  的球形不锈钢爆炸罐构成，示意图如图1所示。罐体设计承压  $\geq 2.0\mathrm{MPa}$  。爆炸罐下部安有粉尘扩散器，扩散器通过管路与储尘罐相连通，在相连通道上安有电磁阀。储尘罐的容积为  $0.6L$  。爆炸罐壁上安有压力传感器，传感器与记录仪相连。

点火源是总能量为  $2.0\mathrm{kJ}$  的烟火点火具，其点火剂质量为  $0.48\mathrm{g}$ ，由  $40\%$  锆粉、  $30\%$  硝酸钡和  $30\%$  过氧化钡组成。点火源位于罐体中心由一电引火头点燃。点火源通过线路与数据采集系统相连。

# 5 试验程序

# 5.1 试验条件及要求

试验在常温常压条件下进行。在储尘罐中放入已知量的粉尘，然后将储尘罐密闭。把爆炸罐抽真空到  $0.04\mathrm{MPa}$  的绝对压力，将储尘罐加压到  $2.1\mathrm{MPa}$  的绝对压力。启动压力记录仪，开启喷尘电磁阀，滞后  $60\mathrm{ms}$  引燃点火源，对爆炸压力进行测定记录。在每次试验后应彻底清扫爆炸罐和储尘罐。

# 5.2 爆炸下限浓度的测定

爆炸下限浓度  $C_{\mathrm{min}}$  需通过一定范围不同浓度粉尘的爆炸试验来确定。初次试验时按  $10\mathrm{g / m^3}$  的整数倍确定试验粉尘浓度，如测得的爆炸峰值压力等于或大于  $0.15\mathrm{MPa}$  的绝对压力，则以  $10\mathrm{g / m^3}$  的级差减小粉尘浓度继续试验，直至连续3次同样试验所测峰值压力值均小于  $0.15\mathrm{MPa}$  的绝对压力。如测得的爆炸峰值压力小于  $0.15\mathrm{MPa}$  的绝对压力，则以  $10\mathrm{g / m^3}$  的整数倍增加粉尘浓度试验，至峰值压力值等于或大于  $0.15\mathrm{MPa}$  的绝对压力，然后，以  $10\mathrm{g / m^3}$  的级差减小粉尘浓度继续试验，直至连续3次同样试验所测峰值压力均小于  $0.15\mathrm{MPa}$  的绝对压力。将连续3次试验压力峰值均小于  $0.15\mathrm{MPa}$  绝对压力的最高粉尘浓度定为  $C_1$ ，连续3次试验压力峰值均等于或大于  $0.15\mathrm{MPa}$  绝对压力的最低粉尘浓度

定为  $C_2$  ，所测粉尘试样爆炸下限浓度  $C_{\mathrm{min}}$  则介于  $C_1$  和  $C_2$  之间，即：

$$
C_1< C_{\mathrm{min}}< C_2
$$

当所试验的粉尘浓度超过  $100\mathrm{g / m^3}$  时，按  $20\mathrm{g / m^3}$  的级差增减试验浓度。

# 5.3 试验方法的检验

用平均粒度为  $(30\pm 5)\mu \mathrm{m}$  的石松子粉对试验方法进行检验。在进行检验前，把石松子粉在  $50^{\circ}C$  的温度下干燥  $24\mathrm{h}$  。对石松子粉所测得的爆炸下限浓度  $C_{\mathrm{min}}$  应为：

$$
20\mathrm{g / m^3}< C_{\mathrm{min}}< 40\mathrm{g / m^3}
$$

# 6 其他可替代试验方法

如果经证实，采用其他的试验方法所测结果与用石松子粉对  $20\mathrm{L}$  球形爆炸试验装置进行检验的结果一致，且这些结果还与至少其他4种粉尘的测定结果相当  $(\pm 30\%)$ ，则可用这种试验方法来测定可燃粉尘- 空气混合物的爆炸下限浓度。

# 7 安全措施

7.1 对粉尘进行处理前，应考虑粉尘的毒性，如果粉尘具有毒性或刺激性的特点，应采取相应的安全措施。

7.2 在试验前，应该对所有的垫圈和连接件进行物理检查，以防止泄漏。

7.3 试验采取  $2.0\mathrm{kJ}$  烟火点火具作为点火源（参见4.2），在处理和使用过程中应注意安全，佩戴相应的防护设施。

7.4 试验装置应可靠接地。

7.5 所有测试应先取少量的样品进行，以防止由于高能量物质产生的超压。

# 8 试验报告

试验报告应包括下述内容：

a）试样名称；b）试样来源；c）试样粒度分布；d）试样水分含量；e）试验环境气压、温度；f）试验测定结果  $C_1,C_2$  值；g）试验采用标准（本标准编号）；h）试验日期、试验人员（签名）。
