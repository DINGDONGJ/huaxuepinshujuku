# 🚀 AI化学品兼容性分析 - 快速开始

## ⚡ 立即体验（3步）

### 第1步：启动Web应用

```bash
cd new_db
python app.py
```

### 第2步：打开浏览器

访问：`http://localhost:5001`

### 第3步：测试AI分析

1. 点击**"多个化学品比较搜索"**按钮
2. 输入框1：输入"甲醛"，从候选列表选择"甲醛溶液"
3. 输入框2：输入"丙醇"，从候选列表选择"1-丙醇"
4. 点击**"开始比较搜索"**
5. 查看基础分析报告
6. 点击**"🤖 AI深度分析报告"**按钮
7. 等待5-10秒，查看AI生成的智能报告！

---

## 📊 测试案例

### 案例1：甲醛 + 丙醇
- **预期结果**：极高风险
- **原因**：均为易燃液体，甲醛有毒性
- **建议**：严格分开存储

### 案例2：甲醇 + 乙醇
- **预期结果**：低风险
- **原因**：同为醇类，性质相近
- **建议**：可共存但注意防火

### 案例3：硫酸 + 硝酸
- **预期结果**：中等风险
- **原因**：均为强酸，但可能产生氧化反应
- **建议**：分开存储更安全

## 🎥 功能演示

### 基础分析（规则引擎）
- ⚡ **速度**：即时（<1秒）
- 💰 **成本**：免费
- 📋 **内容**：基于文本匹配的禁忌分析

### AI深度分析
- ⚡ **速度**：5-10秒
- 💰 **成本**：~¥0.0005/次（不到1分钱）
- 📋 **内容**：
  - 化学品异同对比
  - 风险等级评分（0-100）
  - 详细的不相容原因
  - 具体风险说明
  - 专业的存储/操作/应急建议

## 🔧 故障排查

### 问题1：AI分析失败

**检查项：**
```bash
# 测试API连接
cd new_db
python ai_analyzer.py
```

**预期输出：**
```
✅ API连接成功！
📝 响应: 我是Qwen，由阿里云开发的大型语言模型...
```

### 问题2：数据库连接失败

**检查数据库配置：**
```python
# ai_analyzer.py 或 test_ai_analysis.py
DB_CONFIG = {
    'host': 'localhost',
    'user': 'root',
    'password': '1234',  # 确认密码正确
    'database': '危化品简化数据库'
}
```

### 问题3：找不到化学品

**确保数据库中有数据：**
```sql
SELECT COUNT(*) FROM 化学品;
SELECT COUNT(*) FROM MSDS文档;
```
